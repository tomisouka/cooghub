Matrix Inverses
Elimination · Cramer's Rule · State which method
▶
Problem
Find the inverse if it exists. State your method.
\[ \textbf{(a)}\quad A = \begin{pmatrix}1&1\\1&4\end{pmatrix} \qquad\qquad \textbf{(b)}\quad B = \begin{pmatrix}0&1&1\\1&0&3\\1&1&5\end{pmatrix} \]
Part A — 2×2 Matrix
1
Compute determinant
\[ \det(A)=(1)(4)-(1)(1)=3 \]
2
Apply 2×2 shortcut
\[ A^{-1}=\frac{1}{3}\begin{pmatrix}4&-1\\-1&1\end{pmatrix} \]
✓ Solution\[ A^{-1}=\begin{pmatrix}\tfrac{4}{3}&-\tfrac{1}{3}\\[4pt]-\tfrac{1}{3}&\tfrac{1}{3}\end{pmatrix} \]
Concept
[0x01] MATRICES & SYSTEMS[0x04] DETERMINANTS
▶

The inverse undoes a transformation. \(A\cdot A^{-1}=I\). The determinant is the gatekeeper — \(\det(A)=0\) means no inverse exists.
