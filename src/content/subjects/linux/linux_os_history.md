                    THE ANCIENT ERA (1950s-1960s)
                    ══════════════════════════════

1950s │ 🎴 PUNCH CARDS & BATCH PROCESSING
      │ ┌────────────────────────────────────────┐
      │ │ No OS! Programs loaded manually        │
      │ │ One program at a time                  │
      │ │ If it crashed, start over!             │
      │ └────────────────────────────────────────┘
      │
1956  │ ⚙️  GM-NAA I/O (General Motors)
      │    First real "operating system"
      │    Automated job-to-job transitions
      │
1961  │ 🏢 CTSS (Compatible Time-Sharing System) - MIT
      │    First time-sharing system!
      │    Multiple users could use computer simultaneously
      │    Revolutionary concept: sharing is possible!
      │
1964  │ 🖥️  IBM System/360 & OS/360
      │    First OS family to run on multiple hardware types
      │    Concept of "portable" OS born
      │
1965  │ 🔬 MULTICS (MIT, Bell Labs, GE)
      │    "MULTiplexed Information and Computing Service"
      │    ┌────────────────────────────────────┐
      │    │ Revolutionary ideas:               │
      │    │ • Hierarchical file system         │
      │    │ • Dynamic linking                  │
      │    │ • Multi-level security             │
      │    │ • Online reconfiguration           │
      │    │                                    │
      │    │ Problem: Too ambitious, too slow   │
      │    └────────────────────────────────────┘
      │


                    THE UNIX REVOLUTION (1969-1980s)
                    ═════════════════════════════════

1969  │ 🌟 UNIX BORN (Bell Labs)
      │    ┌────────────────────────────────────────────┐
      │    │ Ken Thompson & Dennis Ritchie             │
      │    │                                            │
      │    │ Started as a "failed" MULTICS → Unix      │
      │    │ "Unics" = joke on "Multics" (simpler)     │
      │    │                                            │
      │    │ Written initially in assembly              │
      │    │ For DEC PDP-7 minicomputer                 │
      │    └────────────────────────────────────────────┘
      │
1971  │ 📝 First Edition Unix released
      │
1973  │ 💎 UNIX REWRITTEN IN C
      │    ═══════════════════
      │    Dennis Ritchie creates C language
      │    Unix rewritten in C (previously assembly)
      │    
      │    🚀 GAME CHANGER: Now portable to other hardware!
      │    This made Unix different from everything else
      │
1975  │ 🏛️  Unix Version 6 released to universities
      │    Spreads through academia
      │    Students start learning Unix
      │
1977  │ 📚 BSD Unix (Berkeley Software Distribution)
      │    UC Berkeley creates their own Unix variant
      │    Bill Joy adds vi editor, C shell
      │    Becomes foundation for modern BSD systems
      │
1979  │ 📑 Unix Version 7 - "The most important Unix"
      │    Bourne shell, awk, lint, make
      │    
      │    🔀 THE GREAT FORK:
      │    ├─ AT&T System V (commercial)
      │    └─ BSD (academic/free)
      │


        THE PERSONAL COMPUTER ERA (1970s-1980s)
        ═══════════════════════════════════════

1973  │ 🖱️  Xerox Alto (Xerox PARC)
      │    First computer with GUI!
      │    Mouse, windows, icons - all invented here
      │    Never sold commercially (internal use only)
      │
1977  │ 🍎 Apple II with Apple DOS
      │    Steve Wozniak & Steve Jobs
      │    First successful personal computer
      │
1981  │ 💻 IBM PC & PC-DOS (Microsoft)
      │    ┌────────────────────────────────────┐
      │    │ IBM creates "PC"                   │
      │    │ Microsoft provides DOS             │
      │    │ (Bought from Seattle Computer)     │
      │    │                                    │
      │    │ C:\> DIR                           │
      │    │ C:\> COPY FILE.TXT A:              │
      │    │                                    │
      │    │ Text-based, command line only      │
      │    └────────────────────────────────────┘
      │
1981  │ 💾 MS-DOS 1.0 (Microsoft)
      │    Same as PC-DOS but sold separately
      │    Microsoft's path to dominance begins
      │
1982  │ ☀️  SunOS (Sun Microsystems)
      │    BSD-based Unix for workstations
      │    "The Network is the Computer"
      │
1983  │ 🆓 GNU PROJECT ANNOUNCED
      │    ═════════════════════
      │    Richard Stallman (MIT)
      │    "GNU's Not Unix"
      │    
      │    Goal: Create a completely free Unix-like OS
      │    Starts writing: gcc, bash, emacs, coreutils...
      │    Everything except... the kernel!
      │
1984  │ 🖼️  Mac OS (System 1.0)
      │    ┌────────────────────────────────────┐
      │    │ First commercial GUI OS!           │
      │    │ Based on Xerox PARC ideas          │
      │    │ [🗑️] [📁] [💾]                     │
      │    │                                    │
      │    │ Changed computing forever:         │
      │    │ • Point and click                  │
      │    │ • Visual metaphors                 │
      │    │ • Accessible to non-techies        │
      │    └────────────────────────────────────┘
      │
1985  │ 🪟 Windows 1.0 (Microsoft)
      │    Not really an OS - runs on top of DOS
      │    Clunky, slow, not very successful
      │    But Microsoft is patient...
      │
1986  │ 🔧 MINIX 1.0 (Andrew Tanenbaum)
      │    Educational Unix-like OS
      │    Microkernel design
      │    Came with textbook, source code
      │    Cost: $69
      │    Would inspire a certain Finnish student...
      │
1987  │ 🎨 Windows 2.0
      │    Still not great, but improving
      │    Overlapping windows!
      │

│                    KEY INSIGHTS                                 │
└─────────────────────────────────────────────────────────────────┘

📊 UNIX WON
   Every major OS today is either:
   - Unix-based (macOS, iOS, Linux, Android, BSD)
   - Unix-influenced (Windows NT borrowed many ideas)

🐧 LINUX IS EVERYWHERE
   From phones to supercomputers
   Powers the Internet
   Free, open source, constantly improving

🍎 APPLE'S UNIX RENAISSANCE  
   macOS/iOS: Beautiful UI + Unix stability
   Proved Unix could be user-friendly

🪟 WINDOWS: STILL DOMINANT ON DESKTOP
   But lost mobile completely
   Now embracing Linux (WSL)
   Azure runs more Linux than Windows

🌍 THE INTERNET EFFECT
   Cloud computing changed everything
   OS matters less (web apps run everywhere)
   Mobile-first world (iOS/Android dominate)

🔮 THE FUTURE?
   - Containerization (Docker, Kubernetes)
   - WebAssembly (run anything in browser)
   - Cloud-native OSes
   - AI-integrated OSes
   - Maybe OS becomes invisible?
