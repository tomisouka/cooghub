Q1 Diagonalization — 12 points 12 pts ▼
(a) In one sentence, define the diagonalization principle.

(b) Given infinite binary strings s₁=01010101…, s₂=11001100…, s₃=00000000…, s₄=10101010…, use diagonalization to construct t guaranteed not to appear in the list.
Part (a)
Student's Answer

"Set up a matrix, pick a pivot, and reduce"

Correct Answer

The diagonalization principle constructs an object that differs from every element in a given enumerable list by disagreeing with the n-th element on the n-th "coordinate," ensuring the constructed object cannot appear anywhere in the list.

Feedback

The student confused diagonalization with Gaussian elimination (a linear algebra technique). Diagonalization in this context is Cantor's diagonal argument — about constructing objects that differ from every listed element.

Part (b) — Diagonal Construction
Correct Diagonalization

Read the diagonal: sᵢ[i] for each position i. Flip each bit.

Diagonal bits (sᵢ[i]): s₁[1]=0, s₂[2]=1, s₃[3]=0, s₄[4]=0, … t[i] = flip(sᵢ[i]): t[1]=1, t[2]=0, t[3]=1, t[4]=1, … Therefore: t = 1011… Why t ∉ list: t differs from sᵢ in position i for every i. So t ≠ s₁ (differs at pos 1), t ≠ s₂ (differs at pos 2), etc. □
Q2 Proof by Induction: Σ(2i−1) = n² — 10 points 10 pts ▼
Prove by mathematical induction that for all n ≥ 1: 1 + 3 + 5 + … + (2n−1) = n².
Student's Approach vs. Complete Proof
Student's Attempt

Had the right idea (inductive step with k≥1), but used k where n was needed and the algebra was incomplete. Showed LHS = RHS conceptually but not rigorously.

Complete Correct Proof

Full three-part induction with base case, IH, and step.

BASE CASE (n = 1): LHS = 2(1) − 1 = 1 RHS = 1² = 1 LHS = RHS ✓ INDUCTIVE HYPOTHESIS: Assume for some k ≥ 1: Σᵢ₌₁ᵏ (2i−1) = k² INDUCTIVE STEP: Show for k+1: Σᵢ₌₁ᵏ⁺¹ (2i−1) = [Σᵢ₌₁ᵏ (2i−1)] + (2(k+1)−1) = k² + (2k + 1) [by IH] = k² + 2k + 1 = (k + 1)² ✓ By mathematical induction, Σᵢ₌₁ⁿ (2i−1) = n² for all n ≥ 1. □
Q3 Pigeonhole Principle — Socks — 8 points 8 pts ▼
In a drawer there are six pairs of socks of six different colors. What is the minimum number of socks you must draw to guarantee two of the same color? You cannot see them as you pull them out.
Student's Answer

"You have to pull out all the socks [12] to guarantee a pair."

Correct Answer: 7

By the Pigeonhole Principle: with 6 colors (pigeonholes), drawing 6 socks could give one of each color (worst case, no pair). The 7th sock must match one already drawn.

Common Mistake

Pulling all 12 socks would certainly give pairs, but we want the minimum to guarantee at least one pair. Worst case: 6 socks, one each color. The 7th guarantees a pair. Answer = 7.

Pigeonholes = 6 colors Pigeons = socks drawn Worst case: 6 socks drawn, one of each color — no pair yet. 7th sock → must go in one of the 6 color buckets → PAIR GUARANTEED Minimum = 6 + 1 = 7

Q5 Binary Relation that is a Function on S — 8 points 8 pts ▼
Let S be the set of students in this course. Define a binary relation on S such that it is also a function. How do you know it is a function? Justify carefully.
Correct Answer

Example relation (Identity): Define R = {(s, s) | s ∈ S}, i.e., the identity relation where each student maps to themselves.

Or (PSID map): R = {(s, PSID(s)) | s ∈ S} where PSID(s) is the student's unique ID number.

A binary relation f on S is a function if: 1. It is total: every s ∈ S has at least one pair (s, y) ∈ f 2. It is single-valued: if (s, y) ∈ f and (s, z) ∈ f, then y = z For identity f(s) = s: Total: every s maps to itself ✓ Single-valued: f(s) = s is unique for each s ✓ → f is a function ✓
Q6 Equivalence Relation on E — 10 points 10 pts ▼
Define a relation on E = {0, 2, 4, 6, …} and prove or disprove that it is an equivalence relation.
Correct Definition + Proof

Define: x R y ⟺ 4 | (x − y) (x and y are equivalent mod 4).

This gives two equivalence classes: {0,4,8,12,…} and {2,6,10,14,…}.

REFLEXIVE: x − x = 0, and 4 | 0 → x R x ✓ SYMMETRIC: If 4|(x−y), then x−y = 4k → y−x = −4k = 4(−k) → 4|(y−x) ✓ TRANSITIVE: If 4|(x−y) and 4|(y−z): x−y = 4j, y−z = 4k x−z = (x−y) + (y−z) = 4j + 4k = 4(j+k) → 4|(x−z) ✓ R is an equivalence relation on E. □
Q7 Probability — Coin & Die — 11 points 11 pts ▼
(a) Probability of at least one head in 3 tosses of a fair coin.
(b) Probability of an even number from a 6-sided die AND a tail from the coin (one toss each).
Student's Answers

(a) Student computed something like 2/6 → 1/3 — WRONG

(b) Student got 1/12 — WRONG

Correct Answers

(a) 7/8

(b) 1/4

Part (a): P(at least one H in 3 tosses) Complement method (easier): P(at least one H) = 1 − P(no heads at all) P(no heads) = P(TTT) = (1/2)³ = 1/8 P(at least one H) = 1 − 1/8 = 7/8 Part (b): P(even die AND tail) Events are independent: P(even die) = 3/6 = 1/2 (die shows 2, 4, or 6) P(tail) = 1/2 P(both) = P(even) × P(tail) = (1/2) × (1/2) = 1/4
