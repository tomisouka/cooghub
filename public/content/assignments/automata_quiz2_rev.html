NFA Design & Subset Construction
ε-TRANSITIONS · NFA→DFA · ε-CLOSURE · 15 PTS
▶
Problem
Let \(\Sigma = \{a,b\}\). Consider the language \(L = \{w \in \{a,b\}^* \mid w \text{ consists of 0 or more patterns of the form } ab \text{ or } aba\}\).
a
Build an NFA for \(L\) with at most 3 states and exactly one \(\varepsilon\)-transition. Give the state diagram and the transition table (including the \(\varepsilon\) column). (8 pts)
b
Convert your NFA to an equivalent DFA using subset construction. Show the \(\varepsilon\)-closures, the resulting transition table, and clearly indicate the start state, accept states, and any dead states. (7 pts)
Part A — NFA Design
Key Insight
L = (ab ∪ aba)*star → ε back-loop
▶
\[ L = (ab \cup aba)^* \]
The star means zero or more repetitions of either ab or aba. The ε-transition carries the "0 repetitions" (empty string) and the loop-back after each accepted pattern.
NFA formal definition▶
An NFA is a 5-tuple \((Q, \Sigma, \delta, q_0, F)\) where \(\delta: Q \times \Sigma_\varepsilon \to \mathcal{P}(Q)\). Unlike a DFA, each state can have 0, 1, or many exits per symbol, and \(\varepsilon\)-transitions consume no input. An NFA accepts if any computation path reaches an accept state.
1
Observe the language structure
\(L = (ab \cup aba)^*\). The empty string is in \(L\) (zero repetitions). After reading each complete pattern, we can start another one. This calls for a loop-back — use an \(\varepsilon\)-transition from an intermediate state back to the start.
2
Design with 3 states
\(q_0\): start/accept — ready to begin a new pattern or done.
\(q_1\): just read \(a\) — could end with \(b\) (giving \(ab\)) or continue with \(ba\) (giving \(aba\)).
\(q_2\): just read \(ab\) — if we read \(a\) here we complete \(aba\).

The single \(\varepsilon\)-transition: \(q_2 \xrightarrow{\varepsilon} q_0\) — after reading \(ab\), nondeterministically jump back to start (completing the \(ab\) pattern) while also staying to possibly read one more \(a\).
3
NFA transition table
State\(a\)\(b\)\(\varepsilon\)
\(q_0\)\(\{q_1\}\)\(\emptyset\)\(\emptyset\)
\(q_1\)\(\emptyset\)\(\{q_0, q_2\}\)\(\emptyset\)
\(q_2\)\(\{q_0\}\)\(\emptyset\)\(\{q_0\}\)
Red dashed = ε-transition · Double circle = accept state · Arrow = start state
✓ NFA: 3 states, exactly 1 ε-transition (q₂ → q₀) Accept states: \(\{q_0, q_2\}\). Start: \(q_0\). Recognizes \((ab \cup aba)^*\).

Part B — Subset Construction (NFA → DFA)
Subset Construction
DFA state = subset of NFA statesε-closure first
▶
\[ \delta'(R, a) = \varepsilon\text{-closure}\!\left(\bigcup_{r \in R} \delta(r, a)\right) \]
Each DFA state is a set of NFA states. Start: ε-closure of NFA start. Accept: any DFA state containing an NFA accept state.
ε-closure definition▶
\(\varepsilon\text{-closure}(R)\) = all NFA states reachable from any state in \(R\) by following zero or more \(\varepsilon\)-transitions (including \(R\) itself). Compute it before and after every transition.
1
Compute ε-closures
\[\varepsilon\text{-closure}(\{q_0\}) = \{q_0\}\] \[\varepsilon\text{-closure}(\{q_1\}) = \{q_1\}\] \[\varepsilon\text{-closure}(\{q_2\}) = \{q_2, q_0\} \quad \leftarrow q_2 \xrightarrow{\varepsilon} q_0\] \[\varepsilon\text{-closure}(\{q_0, q_2\}) = \{q_0, q_2\}\]
2
DFA start state
\[S_0 = \varepsilon\text{-closure}(\{q_0\}) = \{q_0\}\]
3
Expand all reachable DFA states
\[\delta'(\{q_0\}, a) = \varepsilon\text{-closure}(\{q_1\}) = \{q_1\}\] \[\delta'(\{q_0\}, b) = \varepsilon\text{-closure}(\emptyset) = \emptyset \quad\text{(dead state)}\] \[\delta'(\{q_1\}, a) = \varepsilon\text{-closure}(\emptyset) = \emptyset\] \[\delta'(\{q_1\}, b) = \varepsilon\text{-closure}(\{q_0, q_2\}) = \{q_0, q_2\}\] \[\delta'(\{q_0,q_2\}, a) = \varepsilon\text{-closure}(\{q_1\} \cup \{q_0\}) = \{q_0, q_1\}\] \[\delta'(\{q_0,q_2\}, b) = \varepsilon\text{-closure}(\emptyset) = \emptyset\] \[\delta'(\{q_0,q_1\}, a) = \varepsilon\text{-closure}(\{q_1\}) = \{q_1\}\] \[\delta'(\{q_0,q_1\}, b) = \varepsilon\text{-closure}(\{q_0,q_2\}) = \{q_0,q_2\}\]
DFA State\(a\)\(b\)Notes

\(\{q_1\}\)\(\emptyset\)\(\{q_0,q_2\}\)

✓ DFA: 5 states (including dead state) Start: \(\{q_0\}\). Accept: \(\{q_0\},\ \{q_0,q_2\},\ \{q_0,q_1\}\). Dead: \(\emptyset\).
Accept state rule: a DFA state (subset) is an accept state iff it contains at least one NFA accept state. Here \(F_{NFA} = \{q_0, q_2\}\), so any DFA state containing \(q_0\) or \(q_2\) is accepting.

Concept
[SIPSER 1.2] NFA[SIPSER 1.2] SUBSET CONSTRUCTION
▶

NFA = DFA in disguise. Every NFA has an equivalent DFA (Theorem 1.39, Sipser). The DFA may have up to \(2^k\) states for a \(k\)-state NFA, but unreachable states can be pruned away.

ε-closures are computed first. The start state of the DFA is \(\varepsilon\text{-closure}(\{q_0\})\), not \(\{q_0\}\) itself. Every transition then requires computing the ε-closure of the resulting set.

Dead state = ∅. When no NFA state can be reached on a given input, the DFA goes to ∅, which is a non-accepting trap. It must be included to make the DFA complete (total transition function).

Non-Regularity via Closure
COMPLEMENT · UNION · CLOSURE PROPERTIES · 12 PTS
▶
Problem
Prove that \(L = \{a^m b^n \mid m \neq n\}\) is not regular. Hint: write the complement of \(A = \{a^n b^n \mid n \geq 0\}\) as the union of \(L\) and a regular language, then complete the proof.
—
Full proof using closure properties. (12 pts)
Full Proof — Closure Properties Argument
Strategy
Assume L regular → contradictionUse closure under union + complement
▶
If regular languages are closed under union and complement, and \(L\) were regular, then we could construct \(A = \{a^n b^n\}\) as regular — but we know \(A\) is not.
Key known fact: \(A = \{a^n b^n \mid n \geq 0\}\) is not regular (classic pumping lemma result, Sipser Example 1.73).
Closure properties of regular languages▶
The class of regular languages is closed under: union, concatenation, star, complement, and intersection. This means if \(L_1\) and \(L_2\) are regular, so are \(L_1 \cup L_2\), \(\overline{L_1}\), and \(L_1 \cap L_2\). We exploit this to derive contradictions.
1
Identify the key decomposition
Observe that \(\overline{A}\) (the complement of \(A = \{a^nb^n \mid n \geq 0\}\) over \(\{a,b\}^*\)) consists of all strings that are NOT of the form \(a^nb^n\). These are:
\[ \overline{A} = L \;\cup\; R \] where \(L = \{a^mb^n \mid m \neq n\}\) and \(R = \{w \in \{a,b\}^* \mid w \text{ is not of the form } a^*b^*\}\).
2
Show \(R\) is regular
\[ R = \{a,b\}^* \setminus a^*b^* \]
\(a^*b^*\) is described by the regular expression \(a^*b^*\), so it is regular. The complement of a regular language is regular (closure under complement). Therefore \(R = \overline{a^*b^*}\) is regular.
3
Assume for contradiction that \(L\) is regular
Suppose \(L\) is regular. Since \(R\) is regular and the class of regular languages is closed under union:
\[ L \cup R = \overline{A} \text{ would be regular.}\]
4
Apply closure under complement again
\[ \overline{\overline{A}} = A \text{ would then be regular.}\]
But \(A = \{a^nb^n \mid n \geq 0\}\) is not regular — this is a well-known result provable by the pumping lemma. Contradiction.
5
Conclude
Our assumption that \(L\) is regular must be false. Therefore \(L = \{a^mb^n \mid m \neq n\}\) is not regular. \(\blacksquare\)
✓ Proof complete \(L\) regular \(\Rightarrow\) \(L \cup R\) regular \(\Rightarrow\) \(\overline{A}\) regular \(\Rightarrow\) \(A\) regular. Contradiction since \(A = \{a^nb^n\}\) is not regular. \(\blacksquare\)
Fig 3 — P2 closure argument: assuming L regular leads to A = {aⁿbⁿ} regular — contradiction
Concept
[SIPSER 1.2] CLOSURE[SIPSER 1.4] NON-REGULARITY
▶

Closure arguments are cleaner than the pumping lemma when the language has a nice complement structure. The template: assume \(L\) is regular, construct a known non-regular language using only closed operations, get contradiction.

Regular languages closed under: union, intersection, complement, concatenation, star, reversal, homomorphism. If combining \(L\) with any of these would produce a language known to be non-regular, then \(L\) cannot be regular.

Max(L) is Regular
CLOSURE · DFA CONSTRUCTION · MAX STRINGS · 12 PTS
▶
Problem
Prove that \(\text{Max}(L)\) is regular for any regular language \(L\), where \(\text{Max}(L) = \{w \in L \mid wy \notin L \text{ for any string } y \neq \varepsilon\}\). In other words, \(\text{Max}(L)\) is all maximal strings in \(L\) that cannot be extended nontrivially.
—
Full proof. (12 pts)
Proof — DFA Construction + Closure
Key Observation
w ∈ Max(L) iff w ∈ L and no extension stays in L
▶
\[ \text{Max}(L) = L \setminus \{w \mid \exists y \neq \varepsilon,\, wy \in L\} = L \cap \overline{L \cdot \Sigma^+} \]
\(L \cdot \Sigma^+\) is all strings that are a prefix of some string in \(L\) (followed by at least one more symbol). \(\text{Max}(L)\) excludes exactly these.
Why L · Σ⁺ is regular▶
If \(L\) is regular, then \(\Sigma^+\) is regular (it equals \(\Sigma^*\) minus \(\varepsilon\), and both \(\Sigma^*\) and \(\{\varepsilon\}\) are regular). The class of regular languages is closed under concatenation, so \(L \cdot \Sigma^+\) is regular.
1
Express Max(L) using set operations
\[ \text{Max}(L) = L \cap \overline{L \cdot \Sigma^+} \]
\(w \in \text{Max}(L)\) iff (1) \(w \in L\) and (2) \(w\) cannot be extended — meaning \(w \notin L \cdot \Sigma^+\).
2
\(L \cdot \Sigma^+\) is regular
\(L\) is regular (given). \(\Sigma^+ = \Sigma\Sigma^*\) is regular. Regular languages are closed under concatenation, so \(L \cdot \Sigma^+\) is regular.
3
\(\overline{L \cdot \Sigma^+}\) is regular
Regular languages are closed under complement. So \(\overline{L \cdot \Sigma^+}\) is regular.
4
\(\text{Max}(L) = L \cap \overline{L \cdot \Sigma^+}\) is regular
Regular languages are closed under intersection. Both \(L\) and \(\overline{L \cdot \Sigma^+}\) are regular, so their intersection \(\text{Max}(L)\) is regular. \(\blacksquare\)
✓ Max(L) is regular \[\text{Max}(L) = L \cap \overline{L \cdot \Sigma^+}\] Each operation (concatenation, complement, intersection) preserves regularity. \(\blacksquare\)
Fig 4 — P3 Max(L): strings in L with no proper extension still in L
Concept
[SIPSER 1.2] CLOSURE[SIPSER 1.3] REGULAR OPS
▶

Closure proofs follow a formula: express the target language as a combination of known regular languages using closed operations, then cite each closure property. Every step must be justified.

\(L \cdot \Sigma^+\) = "proper extensions of L". It contains exactly the strings that have a prefix in \(L\) followed by at least one more symbol. Complementing it gives "strings with no proper extension in \(L\)" — which, intersected with \(L\), yields \(\text{Max}(L)\).

Thompson Construction
REGEX → NFA · BUILD UP FROM SUBEXPRESSIONS · 9 PTS
▶
Problem
Let \(\Sigma = \{a,b\}\). Consider the regular expression \(R = (ab+b)^*a\).
—
Construct an NFA for \(R\) using the standard Thompson construction — build NFAs for symbols, then combine using concatenation, union, and star. Your work must include NFAs for all intermediate expressions. Clearly label start/accept states and all \(\varepsilon\)-transitions. (9 pts)
Thompson Construction — Step by Step
Thompson Templates
symbol · union · concat · star
▶
Symbol \(a\): \(\to q_i \xrightarrow{a} q_f\) (one arrow, one accept state)
Union \(R_1 \cup R_2\): new start → \(\varepsilon\) to start of \(R_1\) and \(R_2\); accepts of \(R_1,R_2\) → \(\varepsilon\) to new accept
Concat \(R_1 R_2\): accepts of \(R_1\) → \(\varepsilon\) to start of \(R_2\)
Star \(R_1^*\): new start/accept → \(\varepsilon\) to start of \(R_1\); accepts of \(R_1\) → \(\varepsilon\) back to start of \(R_1\) and to new accept
1
Parse the expression
\(R = (ab+b)^*a\)
\(= \big((a \cdot b^+) \cup b\big)^* \cdot a\)
\(= \big((a \cdot b \cdot b^*) \cup b\big)^* \cdot a\)

Build order: \(a\) symbol → \(b\) symbol → \(b^*\) → \(b \cdot b^* = b^+\) → \(a \cdot b^+\) → union with \(b\) → star → concat with \(a\).
2
NFA for \(a\) and \(b\)
Each symbol gets: one start state \(\to\) symbol arrow \(\to\) one accept state.
3
NFA for \(b^+\) = \(b \cdot b^*\) (concat of \(b\) and \(b^*\))
First build \(b^*\): new start/accept, ε to \(b\)-NFA start, ε from \(b\)-NFA accept back and to new accept. Then concatenate with \(b\): ε from first \(b\)'s accept to \(b^*\) NFA's start.
4
NFA for \(ab^+\) (concat)
ε from \(a\)-NFA accept to \(b^+\)-NFA start.
5
NFA for \(ab^+ \cup b\) (union)
New start \(q_s\) with ε to start of \(ab^+\)-NFA and start of \(b\)-NFA. New accept \(q_a\) with ε from both accepts.
6
NFA for \((ab^+ \cup b)^*\) (star)
New start/accept \(q_0\). ε from \(q_0\) to union-NFA start. ε from union-NFA accept back to union-NFA start (loop) and to \(q_0\) (accept empty). \(q_0\) is both start and accept.
7
Final: concat with trailing \(a\)
ε from star-NFA accept to the start of the final \(a\)-NFA. The final \(a\)-NFA's accept state is the overall accept. Start state is \(q_0\) from step 6.
✓ Final NFA accepts \((ab^+b)^*a\) Start: \(q_0\) (from star construction). Accept: accept state of the trailing \(a\)-NFA. All intermediate NFAs built bottom-up via Thompson templates.
Thompson guarantees: every intermediate NFA has exactly one start and one accept state, and the accept state has no outgoing transitions. This makes concatenation and union clean — you always know exactly where to attach ε-arrows.
Fig 5 — P4 Thompson construction parse tree for R = (ab⁺ ∪ b)*a
Fig 8 — P4 Final NFA for R = (ab⁺∪b)*a  ·  Thompson construction result
Concept
[SIPSER 1.3] REGEX→NFA[SIPSER 1.55] THOMPSON
▶

Thompson construction (Lemma 1.55, Sipser) converts any regular expression to an NFA inductively on expression structure. Base cases: single symbols, ε, ∅. Inductive cases: union, concatenation, star.

Always parse first. Write out the full parse tree of the regex before drawing anything. Build leaf NFAs, then combine bottom-up. Never skip intermediate steps on an exam — each subexpression is worth partial credit.

Star NFA invariant: always add a fresh start state (also an accept state) rather than modifying the existing one. This prevents unwanted ε-loops from breaking other parts of the construction.

DFA Language & Regex via State Elimination
L(D) DESCRIPTION · DFA→GNFA→REGEX · STATE RIPPING · 15 PTS
▶
Problem
Consider DFA \(D = (Q, \Sigma, \delta, q_0, F)\) over \(\Sigma = \{a,b\}\) with \(Q = \{q_0, q_1, q_2\}\), \(F = \{q_0, q_1\}\), and transition table:
—
State\(a\)\(b\)
\(q_0\)\(q_1\)\(q_0\)
\(q_1\)\(q_2\)\(q_0\)
\(q_2\)\(q_2\)\(q_2\)
a
Describe in plain English the language \(L(D)\). (6 pts)
b
Construct a regular expression for \(L(D)\) using the algorithm discussed in class (DFA → GNFA → regex via state elimination). (9 pts)
Part A — Plain English Description
1
Trace the DFA behavior
\(q_0\) (accept): start state. Reads \(b\) → stays at \(q_0\). Reads \(a\) → goes to \(q_1\).
\(q_1\) (accept): just read one \(a\) from \(q_0\). Reads \(b\) → back to \(q_0\). Reads \(a\) → goes to \(q_2\).
\(q_2\) (trap/dead): read two consecutive \(a\)s. All transitions stay at \(q_2\). Never accept again.
2
Characterize accepting paths
The machine accepts iff it never reads two consecutive \(a\)s. The \(b\)s are irrelevant — they just reset back to \(q_0\). Once two \(a\)s appear in a row, the machine is trapped in \(q_2\) forever.
✓ L(D) in plain English All strings over \(\{a,b\}\) that do not contain two consecutive \(a\)s (i.e., the substring \(aa\) never appears).
Part B — State Elimination (DFA → GNFA → Regex)
State Ripping Formula
(R1)(R2)*(R3) ∪ R4
▶
When ripping state \(q_{rip}\) from a GNFA, the new label from \(q_i\) to \(q_j\) becomes: \[ (R_1)(R_2)^*(R_3) \cup R_4 \] where \(R_1 = q_i \to q_{rip}\), \(R_2 = q_{rip} \to q_{rip}\), \(R_3 = q_{rip} \to q_j\), \(R_4 = q_i \to q_j\) (direct).
GNFA setup procedure▶
Step 1: Add new start state \(q_s\) with ε to old start \(q_0\).
Step 2: Add new accept state \(q_{acc}\) with ε from all old accept states.
Step 3: Replace multi-label arrows with unions. Add ∅ on missing arrows.
Then: Rip out all intermediate states one by one until only \(q_s\) and \(q_{acc}\) remain. The label on the final arrow is the regex.
1
Set up GNFA from DFA
Add \(q_s \xrightarrow{\varepsilon} q_0\). Add \(q_0 \xrightarrow{\varepsilon} q_{acc}\) and \(q_1 \xrightarrow{\varepsilon} q_{acc}\) (both were accept states). \(q_2\) is the trap — not an accept state, no ε to \(q_{acc}\).
2
Rip \(q_2\) (trap state — easiest first)
\(q_2\) has self-loop \(a \cup b\). It receives \(a\) from \(q_1\), \(a\) from \(q_2\) (self). No path from \(q_2\) to \(q_{acc}\) (since \(q_2\) was not accept). So ripping \(q_2\) adds nothing to other transitions — any path through \(q_2\) never reaches \(q_{acc}\). After ripping: \(q_0\) and \(q_1\) transitions to \(q_2\) simply disappear.
3
GNFA after ripping \(q_2\)
\[q_s \xrightarrow{\varepsilon} q_0 \xrightarrow{b} q_0, \quad q_0 \xrightarrow{a} q_1, \quad q_1 \xrightarrow{b} q_0\] \[q_0 \xrightarrow{\varepsilon} q_{acc}, \quad q_1 \xrightarrow{\varepsilon} q_{acc}\]
4
Rip \(q_1\)
\(R_1 = q_0 \to q_1 = a\). \(R_2 = q_1 \to q_1 = \emptyset\) (no self-loop). \(R_3 = q_1 \to q_0 = b\). \(R_4 = q_0 \to q_0 = b\) (direct self-loop).
New \(q_0 \to q_0\) label: \((a)(\emptyset)^*(b) \cup b = ab \cup b = (a\cup\varepsilon)b\).
Also: \(q_1 \xrightarrow{\varepsilon} q_{acc}\) means path \(q_0 \xrightarrow{a} q_1 \xrightarrow{\varepsilon} q_{acc}\). New \(q_0 \to q_{acc}\): \((a)(\emptyset)^*(\varepsilon) \cup \varepsilon = a \cup \varepsilon\).
5
Rip \(q_0\)
\(R_1 = q_s \to q_0 = \varepsilon\). \(R_2 = q_0 \to q_0 = (a\cup\varepsilon)b\). \(R_3 = q_0 \to q_{acc} = a \cup \varepsilon\). \(R_4 = q_s \to q_{acc} = \emptyset\).
New \(q_s \to q_{acc}\) label:
\[ (\varepsilon)\big((a\cup\varepsilon)b\big)^*(a\cup\varepsilon) \cup \emptyset = \big((a\cup\varepsilon)b\big)^*(a\cup\varepsilon) \]
✓ Regular Expression for L(D) \[ R = \bigl((a\cup\varepsilon)b\bigr)^*(a\cup\varepsilon) \] Equivalently: \((b \cup ab)^*(\varepsilon \cup a)\) — all strings of \(b\)s and \(ab\)-pairs, optionally ending in \(a\). No two consecutive \(a\)s ever appear.
Fig 9 — P5 DFA D with Q={q₀,q₁,q₂}, F={q₀,q₁}  ·  no two consecutive a's
Fig 6 — P5 State elimination: DFA → GNFA → rip q₂ → rip q₁ → rip q₀ → regex
Fig 10 — P5 GNFA state ripping detail: each stage shown with regex labels on arrows
Concept
[SIPSER 1.3] GNFA[SIPSER 1.60] DFA→REGEX
▶

State elimination (Lemma 1.60, Sipser) converts any DFA to a regex via a GNFA intermediate. The GNFA has exactly one start and one accept, with regex labels on every arrow. Rip states one by one — order matters for simplicity but not correctness.

Strategy: rip trap/dead states first (their absence paths contribute nothing to the regex since they never reach the accept state). Then rip intermediate states. The final label from \(q_s\) to \(q_{acc}\) is the answer.

Diagonalization — L ≠ L(Dᵢ)
CANTOR DIAGONALIZATION · COUNTABILITY · NON-REGULARITY · 12 PTS
▶
Problem
Suppose we list all DFAs over alphabet \(\{0,1\}\) as \(D_1, D_2, D_3, \ldots\) Let \(w_1, w_2, w_3, \ldots\) be all binary strings in lexicographic order. Define \(L = \{w_i \mid w_i \notin L(D_i)\}\).
a
Show that \(L \neq L(D_i)\) for every \(i\). (6 pts)
b
What does this imply about whether \(L\) is regular? Justify your answer. (6 pts)
Part A — L ≠ L(Dᵢ) for Every i
Cantor diagonalization intuition▶
The diagonal argument constructs a new object that differs from every listed object in at least one position. Here: \(L\) is defined so that it differs from \(L(D_i)\) on the string \(w_i\) — by flipping membership.
1
Fix any \(i\) and consider \(w_i\)
By definition of \(L\): \(w_i \in L \iff w_i \notin L(D_i)\). So \(L\) and \(L(D_i)\) disagree on exactly the string \(w_i\).
2
Case 1: \(w_i \in L(D_i)\)
\[w_i \in L(D_i) \implies w_i \notin L \implies L \neq L(D_i) \quad \checkmark\]
3
Case 2: \(w_i \notin L(D_i)\)
\[w_i \notin L(D_i) \implies w_i \in L \implies L \neq L(D_i) \quad \checkmark\]
4
Conclude
In both cases \(L \neq L(D_i)\). Since \(i\) was arbitrary, \(L \neq L(D_i)\) for every \(i\). \(\blacksquare\)
✓ L differs from every L(Dᵢ) on the string wᵢ \(w_i \in L \iff w_i \notin L(D_i)\), so \(L\) and \(L(D_i)\) always disagree on \(w_i\), hence \(L \neq L(D_i)\). \(\blacksquare\)
Part B — Implication for Regularity
1
Every regular language is recognized by some DFA
By definition: a language is regular iff some DFA recognizes it. Our enumeration \(D_1, D_2, D_3, \ldots\) lists all DFAs over \(\{0,1\}\).
2
Suppose \(L\) were regular
Then some DFA \(D_k\) in our list would satisfy \(L = L(D_k)\). But Part A shows \(L \neq L(D_i)\) for every \(i\) — in particular for \(i = k\). Contradiction.
3
Conclude
\(L\) cannot be regular. There is no DFA that recognizes it.
✓ L is not regular \(L\) is not regular because it differs from every \(L(D_i)\), so no DFA in the complete enumeration recognizes it. Since every regular language has a DFA, \(L\) cannot be regular.
Fig 7 — P6 Cantor diagonalization: L flips the diagonal — guaranteed to differ from every L(Dᵢ)
The deeper point: this argument shows the set of regular languages is countable (enumerable by DFAs), but the set of all languages over \(\{0,1\}\) is uncountable. So most languages are not regular — and \(L\) is one specific non-regular language constructed by diagonalization.
Concept
[SIPSER 4.2] DIAGONALIZATION[SIPSER 4.1] COUNTABILITY
▶

Cantor's diagonal argument proves uncountability by construction: build an object that disagrees with every listed object on its own "diagonal" entry. The constructed object is therefore not on the list.

Regular languages are countable. There are countably many DFAs (each is a finite object), so there are countably many regular languages. But there are uncountably many languages over \(\{0,1\}\) — so almost all languages are not regular.

This same argument shows that non-regular languages exist without needing the pumping lemma. It's a counting argument, not a structural one.
