P3 Recursive Algorithm: "Good" Arrays (Even Number of 1s) — 40 pts
3a Describe a recursive algorithm (pseudocode) to determine if A[1..n] is good 20 pts 0 pts ▼
An array A of 0s and 1s is good if it has an even number of 1s. Describe a recursive algorithm (pseudocode) to determine if A[1,…,n] is good.
isGood(A, n) = isGood(A, n−1) XOR (A[n] == 1)
Base: isGood(A, 0) = True | A[n]=0 preserves parity; A[n]=1 flips it
D&C variant: isGood(A, lo, hi) = (isGood(A, lo, mid) == isGood(A, mid+1, hi))
Parity is additive: good(full) = good(left) XNOR good(right) = (good(left) == good(right))
Student's Answer

Correct Recursive Algorithms
-- APPROACH 1: Simple Linear Recursion (reduce from right) isGood(A, n): if n == 0: return True -- 0 ones → even → good (base case) else: subResult = isGood(A, n−1) -- is A[1..n-1] good? if A[n] == 0: return subResult -- adding a 0 doesn't change parity else: -- A[n] == 1 return NOT subResult -- adding a 1 flips the parity
-- APPROACH 2: Divide and Conquer isGood(A, lo, hi): if lo == hi: return (A[lo] == 0) -- single element: good iff it's 0 if lo > hi: return True -- empty: 0 ones → good mid = floor((lo + hi) / 2) leftGood = isGood(A, lo, mid) rightGood = isGood(A, mid+1, hi) return (leftGood == rightGood) -- XNOR: both even OR both odd → sum is even -- Call as: isGood(A, 1, n)
Correctness Intuition

Parity of 1s is additive: count_1s(A) = count_1s(left) + count_1s(right). Sum is even iff both have even count OR both have odd count → good(A) = (good(left) XNOR good(right)) = (good(left) == good(right)).
