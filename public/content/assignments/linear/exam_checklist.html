■ pivot cols: x₁, x₃  |  ■ free cols: x₂, x₄

Reading the solution
  1. 1.Identify pivot columns vs. free columns. Free columns → assign parameters. Let x₂ = α, x₄ = β.
  2. 2.Back-substitute each pivot row, expressing pivot variables in terms of α, β, and constants.
  3. 3.Write as a vector sum: particular part + α·(direction) + β·(direction).
Reading row 1:   x₁ + 2x₂ + 0·x₃ + 0·x₄ = 1
x₁ = 1 − 2x₂ = 1 − 2α
Reading row 2:   x₃ + x₄ = 2
x₃ = 2 − x₄ = 2 − β
x₁ = 1 − 2α
x₂ = α
x₃ = 2 − β
x₄ = β  ⟹  x = [1, 0, 2, 0]ᵀ + α[−2, 1, 0, 0]ᵀ + β[0, 0, −1, 1]ᵀ
The two direction vectors [−2,1,0,0]ᵀ and [0,0,−1,1]ᵀ form a basis for the null space of A.

Subspace Tests · Closure Conditions

A subset S ⊆ ℝⁿ is a subspace iff all three hold:

1. Contains zero vector
0 ∈ S
2. Closed under addition
If u, v ∈ S, then u + v ∈ S
3. Closed under scalar multiplication
If u ∈ S and c ∈ ℝ, then cu ∈ S
Fastest disproof: Find one counterexample to any condition. Most common failure: not closed under addition, or doesn't contain 0.
Classic non-subspace

S = {x ∈ ℝ² : x₁ + x₂ = 1} — doesn't contain 0, not closed under addition. ✗

True / False · Key Definitions
FALSE
"A spanning set for a vector space is a basis."
A basis must also be linearly independent. A spanning set can have redundant vectors. Basis = spanning + linearly independent. Example: {[1,0], [0,1], [1,1]} spans ℝ² but is not a basis (dependent).
TRUE
"A basis is a spanning set."
By definition, a basis spans the space. True, but the converse fails (see above).
FALSE
"If a system has more unknowns than equations, it must have infinitely many solutions."
It could still be inconsistent (no solution). More unknowns than equations guarantees at most that if a solution exists, there are infinitely many.
TRUE
"The null space of a matrix A is a subspace of ℝⁿ."
Nul(A) = {x : Ax = 0}. Contains 0, closed under addition and scalar multiplication — all three conditions hold automatically.
FALSE
"Every linearly independent set is a basis."
It must also span the space. {[1,0]} is linearly independent in ℝ² but doesn't span ℝ².
TRUE
"If Ax = b is consistent and has a free variable, it has infinitely many solutions."
Each free variable can take any real value → uncountably many solutions. This is the standard HW2 pattern.
