📚 Background: The Strange Space S²

Same underlying set as \(\mathbb{R}^2\) but with custom operations:

\[\alpha \mathbf{x} \equiv \begin{pmatrix}\alpha(x_1-1)+1\\\alpha(x_2-1)+1\end{pmatrix}, \qquad \mathbf{x}+\mathbf{y} \equiv \begin{pmatrix}x_1+y_1-1\\x_2+y_2-1\end{pmatrix}\]

Key facts:   additive identity \(\mathbf{0} = \begin{pmatrix}1\\1\end{pmatrix}\),   additive inverse \(\mathbf{x}' = \begin{pmatrix}2-x_1\\2-x_2\end{pmatrix}\).

📚 Background: Polynomial Space Pₙ

Real polynomials of degree \(\leq n\) with pointwise operations. Standard basis \(\{1, x, \ldots, x^n\}\), \(\dim(P_n)=n+1\). Key theorem: if \(\dim(\text{span}S) = \dim(V)\) and \(\text{span}S \subseteq V\), then \(\text{span}S = V\).

Problem 1

Abstract Vector Space Properties

(a) Uniqueness of Additive Identity
Suppose \(\mathbf{0}\) and \(\mathbf{0}'\) are both additive identities. Show \(\mathbf{0}' = \mathbf{0}\).
Solution
\(\mathbf{0} + \mathbf{0}' = \mathbf{0}\)  (since \(\mathbf{0}'\) is an additive identity)
\(\mathbf{0}' + \mathbf{0} = \mathbf{0}'\)  (since \(\mathbf{0}\) is an additive identity)
\(\mathbf{0} + \mathbf{0}' = \mathbf{0}' + \mathbf{0}\)  (commutativity, a-2)
Combining: \(\mathbf{0} = \mathbf{0}'\). ✓
(b) \(0\mathbf{x} = \mathbf{0}\) for any \(\mathbf{x}\)
Let \(0\) be the scalar zero and \(\mathbf{0}\) the vector zero. Show \(0\mathbf{x} = \mathbf{0}\).
Solution — Chain of Equalities

Let \(\mathbf{x}'\) be \(\mathbf{x}\)'s additive inverse. Then:

\(\mathbf{0} = \mathbf{x} + \mathbf{x}' = \mathbf{x}' + \mathbf{x} = \mathbf{x}' + 1\mathbf{x}\)  (a-4, a-2, m-2)
\(= \mathbf{x}' + (1+0)\mathbf{x} = \mathbf{x}' + (1\mathbf{x} + 0\mathbf{x})\)  (scalars, d-2)
\(= \mathbf{x}' + (\mathbf{x} + 0\mathbf{x}) = (\mathbf{x}' + \mathbf{x}) + 0\mathbf{x}\)  (m-2, a-1)
\(= \mathbf{0} + 0\mathbf{x} = 0\mathbf{x}\)  (a-4, a-3)
Therefore \(0\mathbf{x} = \mathbf{0}\). ✓
(c) Uniqueness of Additive Inverse
Suppose \(\mathbf{x}'\) and \(\mathbf{x}''\) are both additive inverses of \(\mathbf{x}\). Show \(\mathbf{x}'' = \mathbf{x}'\).
Solution
\((\mathbf{x}+\mathbf{x}') + \mathbf{x}'' = \mathbf{0}+\mathbf{x}'' = \mathbf{x}''\)  (a-4, a-3)
\(= \mathbf{x}+(\mathbf{x}'+\mathbf{x}'') = \mathbf{x}+(\mathbf{x}''+\mathbf{x}')\)  (a-1, a-2)
\(= (\mathbf{x}+\mathbf{x}'') + \mathbf{x}' = \mathbf{0}+\mathbf{x}' = \mathbf{x}'\)  (a-1, a-4, a-3)
So \(\mathbf{x}'' = \mathbf{x}'\). ✓
(d) \((-1)\mathbf{x} = \mathbf{x}'\)
Show that multiplying by the scalar \(-1\) gives the additive inverse.
Solution
\(\mathbf{x}' = \mathbf{x}' + \mathbf{0} = \mathbf{x}' + 0\mathbf{x}\)  (a-3, part b)
\(= \mathbf{x}' + (1+(-1))\mathbf{x} = \mathbf{x}' + (1\mathbf{x}+(-1)\mathbf{x})\)  (d-2)
\(= \mathbf{x}' + (\mathbf{x}+(-1)\mathbf{x}) = (\mathbf{x}'+\mathbf{x})+(-1)\mathbf{x}\)  (m-2, a-1)
\(= \mathbf{0}+(-1)\mathbf{x} = (-1)\mathbf{x}\)  (a-4, a-3)
Therefore \((-1)\mathbf{x} = \mathbf{x}'\). ✓
Problem 2

Verifying Properties of S²

(a) Find \(\mathbf{0}\) and \(\mathbf{x}'\) in S²
Explicitly compute the additive identity and inverse in S².
Solution

Additive Identity: Need \(\mathbf{x}+\mathbf{0}=\mathbf{x}\):

\[\begin{pmatrix}x_1+0_1-1\\x_2+0_2-1\end{pmatrix}=\begin{pmatrix}x_1\\x_2\end{pmatrix} \implies 0_1=1,\ 0_2=1\]

\(\mathbf{0} = \begin{pmatrix}1\\1\end{pmatrix}\)

Additive Inverse: Need \(\mathbf{x}+\mathbf{x}'=\mathbf{0}\):

\[\begin{pmatrix}x_1+x_1'-1\\x_2+x_2'-1\end{pmatrix}=\begin{pmatrix}1\\1\end{pmatrix} \implies x_1'=2-x_1,\ x_2'=2-x_2\]

\(\mathbf{x}' = \begin{pmatrix}2-x_1\\2-x_2\end{pmatrix}\)
(b) S² satisfies (d-2): \((\alpha+\beta)\mathbf{x} = \alpha\mathbf{x}+\beta\mathbf{x}\)
Solution

\[(\alpha+\beta)\mathbf{x} = \begin{pmatrix}(\alpha+\beta)(x_1-1)+1\\(\alpha+\beta)(x_2-1)+1\end{pmatrix}\]

\[\alpha\mathbf{x}+\beta\mathbf{x} = \begin{pmatrix}\alpha(x_1-1)+1\\\alpha(x_2-1)+1\end{pmatrix}+\begin{pmatrix}\beta(x_1-1)+1\\\beta(x_2-1)+1\end{pmatrix}\]

Applying S² addition (subtract 1 from sum of each component):

\[= \begin{pmatrix}\alpha(x_1-1)+\beta(x_1-1)+1\\\alpha(x_2-1)+\beta(x_2-1)+1\end{pmatrix} = (\alpha+\beta)\mathbf{x}. \checkmark\]

(c) Confirm \(0\mathbf{x}=\mathbf{0}\) and \((-1)\mathbf{x}=\mathbf{x}'\) in S²
Solution — Direct Calculation

\[0\mathbf{x} = \begin{pmatrix}0(x_1-1)+1\\0(x_2-1)+1\end{pmatrix} = \begin{pmatrix}1\\1\end{pmatrix} = \mathbf{0}. \checkmark\]

\[(-1)\mathbf{x} = \begin{pmatrix}(-1)(x_1-1)+1\\(-1)(x_2-1)+1\end{pmatrix} = \begin{pmatrix}2-x_1\\2-x_2\end{pmatrix} = \mathbf{x}'. \checkmark\]

Problem 3

A Basis for S²

Vectors: \(\mathbf{0}=\begin{pmatrix}1\\1\end{pmatrix}\), \(\mathbf{x}=\begin{pmatrix}2\\1\end{pmatrix}\), \(\mathbf{y}=\begin{pmatrix}4\\2\end{pmatrix}\).

(a) \(\{\mathbf{x},\mathbf{y}\}\) is independent in S²
Show \(\alpha\mathbf{x}+\beta\mathbf{y}=\mathbf{0}\) implies \(\alpha=\beta=0\).
Solution

Compute using S² operations:

\[\alpha\begin{pmatrix}2\\1\end{pmatrix}+\beta\begin{pmatrix}4\\2\end{pmatrix} = \begin{pmatrix}\alpha+1\\1\end{pmatrix}+\begin{pmatrix}3\beta+1\\\beta+1\end{pmatrix} = \begin{pmatrix}\alpha+3\beta+1\\\beta+1\end{pmatrix}\]

Set equal to \(\mathbf{0}=\begin{pmatrix}1\\1\end{pmatrix}\):

\[\beta+1=1 \Rightarrow \beta=0, \qquad \alpha+3(0)=0 \Rightarrow \alpha=0.\]

\(\alpha=\beta=0\), so \(\{\mathbf{x},\mathbf{y}\}\) is linearly independent. ✓
(b) \(\text{span}\{\mathbf{x},\mathbf{y}\} = S^2\)
Solution

For any \(\mathbf{z}=\begin{pmatrix}z_1\\z_2\end{pmatrix}\), from part (a):

\[\alpha\mathbf{x}+\beta\mathbf{y} = \begin{pmatrix}\alpha+3\beta+1\\\beta+1\end{pmatrix} = \begin{pmatrix}z_1\\z_2\end{pmatrix}\]

Solve: \(\beta = z_2-1\), \(\alpha = z_1-3(z_2-1)-1 = z_1-3z_2+2\).

These are finite real numbers for any \((z_1,z_2)\), so every vector in S² is reachable.

\(\text{span}\{\mathbf{x},\mathbf{y}\} = S^2\). Together with independence, \(\{\mathbf{x},\mathbf{y}\}\) is a basis for S². ✓
Problem 4

A Dependent Set in S²

Vectors: \(\mathbf{x}=\begin{pmatrix}2\\1\end{pmatrix}\), \(\mathbf{y}=\begin{pmatrix}3\\1\end{pmatrix}\).

(a) \(\{\mathbf{x},\mathbf{y}\}\) is dependent in S²
Solution

Compute \(2\mathbf{x}\) in S²:

\[2\mathbf{x} = \begin{pmatrix}2(2-1)+1\\2(1-1)+1\end{pmatrix} = \begin{pmatrix}3\\1\end{pmatrix} = \mathbf{y}.\]

So \(2\mathbf{x} + (-1)\mathbf{y} = \mathbf{0}\) with \((2,-1)\neq(0,0)\).

\(\{\mathbf{x},\mathbf{y}\}\) is dependent. ✓
(b) Describe \(\text{span}\{\mathbf{x},\mathbf{y}\}\)
Solution

Since \(\mathbf{y}=2\mathbf{x}\) in S², any combination \(\alpha\mathbf{x}+\beta\mathbf{y} = \alpha\mathbf{x}+\beta(2\mathbf{x}) = (\alpha+2\beta)\mathbf{x}\).

Let \(\tilde{\alpha} = \alpha+2\beta\) range over all reals:

\[\text{span}\{\mathbf{x},\mathbf{y}\} = \left\{\tilde{\alpha}\begin{pmatrix}2\\1\end{pmatrix}:\tilde{\alpha}\in\mathbb{R}\right\} = \left\{\begin{pmatrix}\tilde\alpha+1\\1\end{pmatrix}:\tilde\alpha\in\mathbb{R}\right\}.\]

A one-parameter family — a "line" through \(\mathbf{0}\) in S², parallel to \(\mathbf{x}\).
In S², scalar multiples of \(\mathbf{x}\) don't look like a line in the usual sense — the structure is shifted.
Problem 5

Standard Basis of Pₙ is Independent

Show: \(\alpha_0 + \alpha_1 x + \cdots + \alpha_n x^n = 0\) for all \(x\) implies all \(\alpha_k = 0\).
Solution — Differentiation Trick

From calculus: \(\dfrac{d^k}{dx^k}x^m = m(m-1)\cdots(m-k+1)\,x^{m-k}\) for \(k\leq m\), and \(= 0\) for \(k>m\), and \(= k!\) when \(k=m\).

Let \(p(x) = \alpha_0 + \alpha_1 x + \cdots + \alpha_n x^n = 0\) for all \(x\).

Take the \(k\)-th derivative (\(0 \leq k \leq n\)) and set \(x=0\):

\[\frac{d^k p}{dx^k}\bigg|_{x=0} = \alpha_k \cdot k! = 0 \implies \alpha_k = 0.\]

Doing this for each \(k = 0, 1, \ldots, n\):

\(\alpha_0 = \alpha_1 = \cdots = \alpha_n = 0\), so \(\{1, x, \ldots, x^n\}\) is independent. ✓
Problem 6

Lagrange Basis for P₂ (General)

Let \(x_0, x_1, x_2\) be three distinct real numbers.

(a) Independence of the Lagrange Basis
Show \(\{(x-x_1)(x-x_2),\,(x-x_0)(x-x_2),\,(x-x_0)(x-x_1)\}\) is independent.
Solution — Evaluation at Nodes

Let \(b(x) = \alpha_0(x-x_1)(x-x_2) + \alpha_1(x-x_0)(x-x_2) + \alpha_2(x-x_0)(x-x_1) = 0\).

Set \(x=x_0\): \(\alpha_0(x_0-x_1)(x_0-x_2) = 0 \Rightarrow \alpha_0 = 0\) (since \(x_i\) distinct)
Set \(x=x_1\): \(\alpha_1(x_1-x_0)(x_1-x_2) = 0 \Rightarrow \alpha_1 = 0\)
Set \(x=x_2\): \(\alpha_2(x_2-x_0)(x_2-x_1) = 0 \Rightarrow \alpha_2 = 0\)
All scalars are zero → set is independent. ✓
(b) Write any \(p(x)\in P_2\) in the Lagrange basis
Solution — Lagrange Interpolation Formula

Set \(x=x_0, x_1, x_2\) successively to read off coefficients:

\(\alpha_0 = \dfrac{p(x_0)}{(x_0-x_1)(x_0-x_2)}\),   \(\alpha_1 = \dfrac{p(x_1)}{(x_1-x_0)(x_1-x_2)}\),   \(\alpha_2 = \dfrac{p(x_2)}{(x_2-x_0)(x_2-x_1)}\).

\[p(x) = p(x_0)\frac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)} + p(x_1)\frac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)} + p(x_2)\frac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}\]
This is the Lagrange interpolation formula — the unique polynomial of degree ≤ 2 passing through \((x_0,p(x_0))\), \((x_1,p(x_1))\), \((x_2,p(x_2))\).
Problem 7

Classify Sets in P₂ — Independent or Dependent?

(a) \(\{1,\ (x-0),\ (x-0)(x-1)\}\)
Solution

Suppose \(\alpha_0 + \alpha_1 x + \alpha_2 x(x-1)=0\) for all \(x\).

\(x=0\): \(\alpha_0 = 0\)
\(x=1\): \(\alpha_0+\alpha_1=0 \Rightarrow \alpha_1=0\)
\(x=2\): \(\alpha_0+2\alpha_1+2\alpha_2=0 \Rightarrow \alpha_2=0\)
✅ INDEPENDENT
(b) \(\{2x+1,\ x^2,\ (x+1)^2\}\)
Solution

Expand: \((x+1)^2 = x^2 + 2x + 1 = x^2 + (2x+1)\).

So: \(-1\cdot(2x+1) + (-1)\cdot x^2 + 1\cdot(x+1)^2 = 0\) for all \(x\).

Nontrivial combination (not all zero) sums to zero.

❌ DEPENDENT
Problem 8

Coordinates in the Basis \(\{x-1,\ x+1,\ x^2+2\}\)

Write \(p(x) = \alpha_0(x-1)+\alpha_1(x+1)+\alpha_2(x^2+2)\). Expanding into standard basis gives the system:

\[\alpha_2 = [\text{coeff of }x^2],\quad \alpha_0+\alpha_1 = [\text{coeff of }x],\quad -\alpha_0+\alpha_1+2\alpha_2 = [\text{const}].\]

(a) \(p(x) = 1\)
Solution

\(\alpha_2=0\), \(\alpha_0+\alpha_1=0\), \(-\alpha_0+\alpha_1=1\) → \(\alpha_0=-\tfrac{1}{2}\), \(\alpha_1=\tfrac{1}{2}\).

\(\alpha_0=-\tfrac{1}{2},\ \alpha_1=\tfrac{1}{2},\ \alpha_2=0\)  →  \(1 = -\tfrac{1}{2}(x-1)+\tfrac{1}{2}(x+1)\)
(b) \(p(x) = x\)
Solution

\(\alpha_2=0\), \(\alpha_0+\alpha_1=1\), \(-\alpha_0+\alpha_1=0\) → \(\alpha_0=\alpha_1=\tfrac{1}{2}\).

\(\alpha_0=\tfrac{1}{2},\ \alpha_1=\tfrac{1}{2},\ \alpha_2=0\)  →  \(x = \tfrac{1}{2}(x-1)+\tfrac{1}{2}(x+1)\)
(c) \(p(x) = x^2\)
Solution

\(\alpha_2=1\), \(\alpha_0+\alpha_1=0\), \(-\alpha_0+\alpha_1+2=0\) → \(\alpha_0=1\), \(\alpha_1=-1\).

\(\alpha_0=1,\ \alpha_1=-1,\ \alpha_2=1\)  →  \(x^2 = (x-1)-(x+1)+(x^2+2)\)
(d) \(p(x) = x^2+3x+4\)
Solution — Use Linearity with (a), (b), (c)

\(x^2+3x+4 = x^2 + 3\cdot x + 4\cdot 1\)

Substitute representations from (a), (b), (c) and collect:

\[= \left[1+\tfrac{3}{2}-2\right](x-1) + \left[-1+\tfrac{3}{2}+2\right](x+1) + [1+0+0](x^2+2)\]

\(\alpha_0=\tfrac{1}{2},\ \alpha_1=\tfrac{5}{2},\ \alpha_2=1\)  →  \(x^2+3x+4 = \tfrac{1}{2}(x-1)+\tfrac{5}{2}(x+1)+(x^2+2)\)
Check: \(\tfrac{1}{2}(x-1)+\tfrac{5}{2}(x+1)+(x^2+2) = \tfrac{x-1+5x+5}{2}+x^2+2 = 3x+2+x^2+2 = x^2+3x+4\). ✓
