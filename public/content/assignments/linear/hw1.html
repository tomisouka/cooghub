Problem 03 Prove \((A+B)C = AC + BC\) when either side is defined
Setup. Let \(A\in\mathbb{R}^{m_A\times n_A}\), \(B\in\mathbb{R}^{m_B\times n_B}\), \(C\in\mathbb{R}^{m_C\times n_C}\).

Direction 1 (LHS defined → RHS equal):

  • \(A+B\) defined \(\Rightarrow m_A=m_B=m,\quad n_A=n_B=\ell\)
  • \((A+B)C\) defined \(\Rightarrow m_C=\ell\)
  • So \(A,B\in\mathbb{R}^{m\times\ell},\; C\in\mathbb{R}^{\ell\times n_C}\). Both \(AC\) and \(BC\) are defined.

For each \(1\le i\le m,\; 1\le j\le n_C\):

\[ \bigl((A+B)C\bigr)_{ij} = \sum_{k=1}^{\ell}(A+B)_{ik}C_{kj} = \sum_{k=1}^{\ell}(A_{ik}+B_{ik})C_{kj} = \sum_{k=1}^{\ell}A_{ik}C_{kj}+\sum_{k=1}^{\ell}B_{ik}C_{kj} = (AC)_{ij}+(BC)_{ij} \]

Direction 2 (RHS defined → LHS equal):

  • \(AC\) defined \(\Rightarrow n_A=m_C=\ell\)
  • \(BC\) defined \(\Rightarrow n_B=m_C=\ell\)
  • \(AC+BC\) defined \(\Rightarrow m_A=m_B=m\)
  • Same index argument (reversed) shows \((AC+BC)_{ij}=((A+B)C)_{ij}\) \(\checkmark\)

\( A+B = \begin{pmatrix}3&2\\5&7\\3&2\end{pmatrix},\quad (A+B)C = \begin{pmatrix}3+4\\5+14\\3+4\end{pmatrix} = \begin{pmatrix}7\\19\\7\end{pmatrix} \)

Problem 05 Solve the linear system via Gaussian elimination
\[ x_1 - 2x_2 + x_3 = 0,\quad 2x_1 + x_2 - 3x_3 = 5,\quad 4x_1 - 7x_2 + x_3 = -1 \]
(a) Matrix equation AX = B
\( \begin{pmatrix}1&-2&1\\2&1&-3\\4&-7&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=\begin{pmatrix}0\\5\\-1\end{pmatrix} \)
(b) Augmented matrix → triangular form
\[ \left[\begin{array}{ccc|c}1&-2&1&0\\2&1&-3&5\\4&-7&1&-1\end{array}\right] \xrightarrow{R_2\to R_2-2R_1} \xrightarrow{R_3\to R_3-4R_1} \left[\begin{array}{ccc|c}1&-2&1&0\\0&5&-5&5\\0&1&-3&-1\end{array}\right] \] \[ \xrightarrow{R_2\to R_2/5} \left[\begin{array}{ccc|c}1&-2&1&0\\0&1&-1&1\\0&1&-3&-1\end{array}\right] \xrightarrow{R_3\to R_3-R_2} \left[\begin{array}{ccc|c}1&-2&1&0\\0&1&-1&1\\0&0&-2&-2\end{array}\right] \xrightarrow{R_3\to R_3/(-2)} \left[\begin{array}{ccc|c}1&-2&1&0\\0&1&-1&1\\0&0&1&1\end{array}\right] \]
(c) Back substitution
  • \(x_3 = 1\)
  • \(x_2 - x_3 = 1 \Rightarrow x_2 = 2\)
  • \(x_1 - 2(2) + 1 = 0 \Rightarrow x_1 = 3\)
Solution\( x_1 = 3,\quad x_2 = 2,\quad x_3 = 1 \)
Problem 06 Solve the linear system via Gaussian elimination
\[ 2x_1 - x_2 + 3x_3 = 5,\quad 2x_1 + 2x_2 + 3x_3 = 7,\quad -2x_1 + 3x_2 = -3 \]
(a) Matrix equation AX = B
\( \begin{pmatrix}2&-1&3\\2&2&3\\-2&3&0\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=\begin{pmatrix}5\\7\\-3\end{pmatrix} \)
(b) Row reduction
\[ \left[\begin{array}{ccc|c}2&-1&3&5\\2&2&3&7\\-2&3&0&-3\end{array}\right] \xrightarrow{R_2\to R_2-R_1,\;R_3\to R_3+R_1} \left[\begin{array}{ccc|c}2&-1&3&5\\0&3&0&2\\0&2&3&2\end{array}\right] \xrightarrow{R_3\to 3R_3-2R_2} \left[\begin{array}{ccc|c}2&-1&3&5\\0&3&0&2\\0&0&9&2\end{array}\right] \]
(c) Back substitution
  • \(9x_3 = 2 \Rightarrow x_3 = \tfrac{2}{9}\)
  • \(3x_2 = 2 \Rightarrow x_2 = \tfrac{2}{3}\)
  • \(2x_1 - \tfrac{2}{3} + 3\cdot\tfrac{2}{9} = 5 \Rightarrow x_1 = \tfrac{5}{2}\)
Solution\( x_1 = \tfrac{5}{2},\quad x_2 = \tfrac{2}{3},\quad x_3 = \tfrac{2}{9} \)
Problem 07 Solve the linear system (infinite solutions)
\[ 3x_1 - 4x_2 + 5x_3 = 7,\quad -3x_1 + 4x_2 - 2x_3 = -1,\quad 6x_1 - 8x_2 + x_3 = -4 \]
(a) Matrix equation
\( \begin{pmatrix}3&-4&5\\-3&4&-2\\6&-8&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=\begin{pmatrix}7\\-1\\-4\end{pmatrix} \)
(b) Row reduction
\[ \left[\begin{array}{ccc|c}3&-4&5&7\\-3&4&-2&-1\\6&-8&1&-4\end{array}\right] \xrightarrow{R_2\to R_2+R_1,\;R_3\to R_3-2R_1} \left[\begin{array}{ccc|c}3&-4&5&7\\0&0&3&6\\0&0&-9&-18\end{array}\right] \] \[ \xrightarrow{R_2\to R_2/2;\; R_3\to R_3+3R_2} \left[\begin{array}{ccc|c}3&-4&5&7\\0&0&1&2\\0&0&0&0\end{array}\right] \]

Zero row → \(x_2\) is a free variable.

(c) Solution (one-parameter family)
  • \(x_3 = 2\)
  • \(x_2 = \alpha\) (free)
  • \(3x_1 = 7 + 4\alpha - 10 \Rightarrow x_1 = \tfrac{4}{3}\alpha - 1\)
Solution\( x_1 = \tfrac{4}{3}\alpha-1,\quad x_2 = \alpha,\quad x_3 = 2,\quad \alpha\in\mathbb{R} \)

Problem 09 Row echelon form — 3 equations, 4 unknowns
\( \begin{pmatrix}1&2&1&2\\1&2&4&3\\2&4&-4&4\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\\x_4\end{pmatrix}=\begin{pmatrix}1\\2\\2\end{pmatrix} \)
Augmented matrix → row echelon form
\[ \left[\begin{array}{cccc|c}1&2&1&2&1\\1&2&4&3&2\\2&4&-4&4&2\end{array}\right] \xrightarrow{R_2-R_1,\;R_3-2R_1} \left[\begin{array}{cccc|c}1&2&1&2&1\\0&0&3&1&1\\0&0&-6&0&0\end{array}\right] \] \[ \xrightarrow{R_3\to R_3+2R_2} \left[\begin{array}{cccc|c}1&2&1&2&1\\0&0&3&1&1\\0&0&0&2&2\end{array}\right] \xrightarrow{R_2/3,\;R_3/2} \left[\begin{array}{cccc|c}1&2&1&2&1\\0&0&1&\tfrac{1}{3}&\tfrac{1}{3}\\0&0&0&1&1\end{array}\right] \]
Back substitution — free variable: \(x_2 = \alpha\)
  • \(x_4 = 1\)
  • \(x_3 + \tfrac{1}{3}x_4 = \tfrac{1}{3} \Rightarrow x_3 = 0\)
  • \(x_1 + 2\alpha + 0 + 2 = 1 \Rightarrow x_1 = -1-2\alpha\)
Solution\( x_1=-1-2\alpha,\quad x_2=\alpha,\quad x_3=0,\quad x_4=1,\quad \alpha\in\mathbb{R} \)
Problem 10 Row echelon form — 4 equations, 4 unknowns
\( \begin{pmatrix}1&1&2&1\\1&-1&1&-1\\3&-1&4&-5\\2&0&3&0\end{pmatrix}\begin{pmatrix}x_1\\x_2\\x_3\\x_4\end{pmatrix}=\begin{pmatrix}3\\2\\7\\5\end{pmatrix} \)
Row reduction
\[ \left[\begin{array}{cccc|c}1&1&2&1&3\\1&-1&1&-1&2\\3&-1&4&-5&7\\2&0&3&0&5\end{array}\right] \xrightarrow{R_2-R_1,\;R_3-3R_1,\;R_4-2R_1} \left[\begin{array}{cccc|c}1&1&2&1&3\\0&-2&-1&-2&-1\\0&-4&-2&-8&-2\\0&-2&-1&-2&-1\end{array}\right] \] \[ \xrightarrow{R_3-2R_2,\;R_4-R_2} \left[\begin{array}{cccc|c}1&1&2&1&3\\0&-2&-1&-2&-1\\0&0&0&-4&0\\0&0&0&0&0\end{array}\right] \]
Back substitution — free variable: \(x_3 = \alpha\)
  • \(-4x_4 = 0 \Rightarrow x_4 = 0\)
  • \(-2x_2 - \alpha - 0 = -1 \Rightarrow x_2 = \tfrac{1-\alpha}{2}\)
  • \(x_1 + \tfrac{1-\alpha}{2} + 2\alpha + 0 = 3 \Rightarrow x_1 = \tfrac{5-3\alpha}{2}\)
Solution\( x_1=\tfrac{5-3\alpha}{2},\quad x_2=\tfrac{1-\alpha}{2},\quad x_3=\alpha,\quad x_4=0,\quad \alpha\in\mathbb{R} \)
