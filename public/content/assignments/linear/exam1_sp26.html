ADDITION · SCALAR MULT · MATRIX MULT · 20 PTS

Problem
Given the matrices below, compute the following when defined.
\(A=(1\;2\;3),\quad B=\begin{pmatrix}1&0&1\\0&1&0\end{pmatrix},\quad C=\begin{pmatrix}1&2\\1&2\\1&2\end{pmatrix},\quad D=\begin{pmatrix}2\\1\end{pmatrix},\quad E=\begin{pmatrix}0&1&0\\1&0&1\end{pmatrix}\)
a
\(B + 2E\)
b
\(D + E\) — state if defined
c
\(AC\)
d
\(CD\)
Part A — B + 2E
1
Check dimensions: B is 2×3, E is 2×3 — compatible ✓
Scale E first, then add entry-by-entry.
2
Compute 2E
\[2E = 2\begin{pmatrix}0&1&0\\1&0&1\end{pmatrix} = \begin{pmatrix}0&2&0\\2&0&2\end{pmatrix}\]
3
Add
\[B+2E = \begin{pmatrix}1&0&1\\0&1&0\end{pmatrix}+\begin{pmatrix}0&2&0\\2&0&2\end{pmatrix} = \begin{pmatrix}1&2&1\\2&1&2\end{pmatrix}\]
✓ Answer\[B+2E=\begin{pmatrix}1&2&1\\2&1&2\end{pmatrix}\]
Part B — D + E
1
Check dimensions
\(D\) is \(2\times 1\); \(E\) is \(2\times 3\). The dimensions do not match — addition requires identical dimensions.
✗ Undefined\(D+E\) is undefined: \(D\) is \(2\times1\) and \(E\) is \(2\times3\).
Part C — AC
1
Check dimensions: A is 1×3, C is 3×2 → result is 1×2
2
Compute entries
\[ AC = \begin{pmatrix}1&2&3\end{pmatrix}\begin{pmatrix}1&2\\1&2\\1&2\end{pmatrix} \]
\[ \begin{aligned} (1,1):&\quad 1(1)+2(1)+3(1)=6\\ (1,2):&\quad 1(2)+2(2)+3(2)=12 \end{aligned} \]

Part D — CD
1
Check dimensions: C is 3×2, D is 2×1 → result is 3×1
2
Compute entries
\[ CD = \begin{pmatrix}1&2\\1&2\\1&2\end{pmatrix}\begin{pmatrix}2\\1\end{pmatrix} \]
\[ \begin{aligned} \text{row 1:}&\quad 1(2)+2(1)=4\\ \text{row 2:}&\quad 1(2)+2(1)=4\\ \text{row 3:}&\quad 1(2)+2(1)=4 \end{aligned} \]

Concept
DIMENSION RULEMATRIX MULT
▶

Addition: Defined only when both matrices have identical dimensions (\(m\times n\)). Every entry adds independently.

Multiplication \(A_{m\times n}\cdot B_{n\times p}\): Inner dimensions must match; result is \(m\times p\). Entry \((i,j)=\) row \(i\) of \(A\) dotted with column \(j\) of \(B\).

02
Gaussian Elimination
AUGMENTED MATRIX · ROW OPS · ALL SOLUTIONS · 20 PTS
▶
Problem
Write as an augmented matrix, reduce to echelon form, determine all solutions.
a
\(2x_1+2x_2+2x_3+4x_4=6,\quad x_1+2x_2+x_3+2x_4=1,\quad x_1+2x_2+x_3+3x_4=2\)
b
\(x_1+2x_2+x_3=8,\quad 2x_1+x_2+2x_3=10,\quad x_1+x_2+2x_3=9\)
Part A — 3 equations, 4 unknowns
Key Insight
fewer eqns than unknownsexpect free variable(s)
▶
3 equations, 4 unknowns. Even if fully consistent, at least one free variable — infinitely many solutions.
After simplification we may find redundant rows too, increasing the number of free variables.
1
Augmented matrix
\[\left[\begin{array}{cccc|c}2&2&2&4&6\\1&2&1&2&1\\1&2&1&3&2\end{array}\right]\]
2
R1 ← R1 ÷ 2
\[\left[\begin{array}{cccc|c}1&1&1&2&3\\1&2&1&2&1\\1&2&1&3&2\end{array}\right]\]
3
R2 ← R2 − R1 ; R3 ← R3 − R1
\[\left[\begin{array}{cccc|c}1&1&1&2&3\\0&1&0&0&-2\\0&1&0&1&-1\end{array}\right]\]
4
R3 ← R3 − R2
\[\left[\begin{array}{cccc|c}1&1&1&2&3\\0&1&0&0&-2\\0&0&0&1&1\end{array}\right]\]
Pivots in columns 1, 2, 4. Free variable: \(x_3 = t\).
5
Back-substitute
\[ \begin{aligned} x_4 &= 1\\ x_2 &= -2\\ x_1 &= 3 - x_2 - x_3 - 2x_4 = 3-(-2)-t-2 = 3-t \end{aligned} \]
✓ Infinitely many solutions (free variable x₃ = t ∈ ℝ) \[x_1 = 3-t,\quad x_2 = -2,\quad x_3 = t,\quad x_4 = 1\]
Part B — 3 equations, 3 unknowns
1
Augmented matrix
\[\left[\begin{array}{ccc|c}1&2&1&8\\2&1&2&10\\1&1&2&9\end{array}\right]\]
2
R2 ← R2 − 2R1 ; R3 ← R3 − R1
\[\left[\begin{array}{ccc|c}1&2&1&8\\0&-3&0&-6\\0&-1&1&1\end{array}\right]\]
3
R2 ← R2 ÷ (−3)
\[\left[\begin{array}{ccc|c}1&2&1&8\\0&1&0&2\\0&-1&1&1\end{array}\right]\]
4
R3 ← R3 + R2
\[\left[\begin{array}{ccc|c}1&2&1&8\\0&1&0&2\\0&0&1&3\end{array}\right]\]
Three pivots → unique solution. Back-substitute.
5
Back-substitute
\[ \begin{aligned} x_3 &= 3\\ x_2 &= 2\\ x_1 &= 8 - 2(2) - 3 = 1 \end{aligned} \]
✓ Unique solution \[x_1 = 1,\quad x_2 = 2,\quad x_3 = 3\]
Concept
ECHELON FORMPIVOTS & FREE VARS
▶

Three outcomes after row reduction: (1) Inconsistent row \([0\cdots 0\mid b],\,b\neq0\) → no solution. (2) Pivot in every column → unique solution. (3) Free column(s) → infinitely many solutions.

Free variable rule: Assign parameter \(t\) to each non-pivot column, then express pivot variables in terms of \(t\).

03
Span & Linear Combinations
SPAN TEST · CONSISTENCY · LINEAR COMBO · 20 PTS
▶
Problem
If true, express the vector as a linear combination of the spanning vectors. Show all work.
a
Is \(\begin{pmatrix}1\\1\\0\end{pmatrix}\in\operatorname{span}\!\left\{\begin{pmatrix}1\\1\\1\end{pmatrix},\begin{pmatrix}0\\1\\1\end{pmatrix}\right\}\)?
b
Is \(\begin{pmatrix}1\\1\\1\\1\end{pmatrix}\in\operatorname{span}\!\left\{\begin{pmatrix}1\\2\\1\\2\end{pmatrix},\begin{pmatrix}2\\1\\2\\1\end{pmatrix}\right\}\)?
Method — span membership = consistency of [v₁ v₂ | b] ▶
\(\mathbf{b}\in\operatorname{span}\{\mathbf{v}_1,\mathbf{v}_2\}\) iff the system \(c_1\mathbf{v}_1+c_2\mathbf{v}_2=\mathbf{b}\) is consistent. Form \([\mathbf{v}_1\;\mathbf{v}_2\mid\mathbf{b}]\) and row-reduce.
\[\text{Consistent} \implies \mathbf{b}\in\operatorname{span};\quad\text{Inconsistent row}\implies \mathbf{b}\notin\operatorname{span}\]
Part A — (1,1,0)ᵀ in ℝ³
1
Augmented matrix
\[\left[\begin{array}{cc|c}1&0&1\\1&1&1\\1&1&0\end{array}\right]\]
2
R2 ← R2 − R1 ; R3 ← R3 − R1
\[\left[\begin{array}{cc|c}1&0&1\\0&1&0\\0&1&-1\end{array}\right]\]
3
R3 ← R3 − R2
\[\left[\begin{array}{cc|c}1&0&1\\0&1&0\\0&0&-1\end{array}\right]\]
Row 3 reads \(0 = -1\) — inconsistent.
✗ NO — not in span The system is inconsistent. \(\begin{pmatrix}1\\1\\0\end{pmatrix}\notin\operatorname{span}\!\left\{\begin{pmatrix}1\\1\\1\end{pmatrix},\begin{pmatrix}0\\1\\1\end{pmatrix}\right\}.\)
Part B — (1,1,1,1)ᵀ in ℝ⁴
1
Augmented matrix
\[\left[\begin{array}{cc|c}1&2&1\\2&1&1\\1&2&1\\2&1&1\end{array}\right]\]
2
R2←R2−2R1 ; R3←R3−R1 ; R4←R4−2R1
\[\left[\begin{array}{cc|c}1&2&1\\0&-3&-1\\0&0&0\\0&-3&-1\end{array}\right]\]
3
R4 ← R4 − R2
\[\left[\begin{array}{cc|c}1&2&1\\0&-3&-1\\0&0&0\\0&0&0\end{array}\right]\]
Consistent! \(c_2 = \tfrac{1}{3}\), then \(c_1 = 1 - 2\cdot\tfrac{1}{3} = \tfrac{1}{3}\).
✓ YES — linear combination \[\begin{pmatrix}1\\1\\1\\1\end{pmatrix} = \frac{1}{3}\begin{pmatrix}1\\2\\1\\2\end{pmatrix}+\frac{1}{3}\begin{pmatrix}2\\1\\2\\1\end{pmatrix}\]
Concept
SPANLINEAR COMBINATION
▶

Span membership test: Always reduce \([\mathbf{v}_1\;\mathbf{v}_2\mid\mathbf{b}]\). An inconsistent row \([0\;0\mid c]\) with \(c\neq0\) immediately proves the vector is outside the span. Never guess geometrically without the algebra.

04
Subspace Basis & Dimension
STANDARD BASIS · LIN. INDEPENDENCE · DIMENSION · 20 PTS
▶
Problem
For each space, determine its standard basis and its dimension.
a
\(\mathcal{V}_a=\operatorname{span}\!\left\{\begin{pmatrix}1\\2\end{pmatrix},\begin{pmatrix}2\\1\end{pmatrix},\begin{pmatrix}1\\1\end{pmatrix}\right\}\)
b
\(\mathcal{V}_b=\operatorname{span}\!\left\{\begin{pmatrix}1\\2\\1\end{pmatrix},\begin{pmatrix}2\\3\\1\end{pmatrix},\begin{pmatrix}3\\4\\1\end{pmatrix}\right\}\)
Method — place vectors as rows, row-reduce, non-zero rows = basis ▶
The number of non-zero rows after row reduction equals the dimension of the span; those rows form the standard basis.
Part A — V_a ⊆ ℝ²
1
Row-reduce matrix of spanning vectors
\[ \begin{pmatrix}1&2\\2&1\\1&1\end{pmatrix} \xrightarrow{R_2\leftarrow R_2-2R_1,\;R_3\leftarrow R_3-R_1} \begin{pmatrix}1&2\\0&-3\\0&-1\end{pmatrix} \xrightarrow{R_2\leftarrow R_2\div(-3)} \begin{pmatrix}1&2\\0&1\\0&-1\end{pmatrix} \]
2
R3 ← R3 + R2
\[ \begin{pmatrix}1&2\\0&1\\0&0\end{pmatrix} \]
Two non-zero rows. \(\mathcal{V}_a\subseteq\mathbb{R}^2\) and has dimension 2, meaning \(\mathcal{V}_a = \mathbb{R}^2\) itself.
✓ Standard Basis and Dimension \[\mathcal{B}_a=\left\{\begin{pmatrix}1\\2\end{pmatrix},\begin{pmatrix}0\\1\end{pmatrix}\right\},\quad\dim(\mathcal{V}_a)=2\] (The third spanning vector was redundant; \(\mathcal{V}_a=\mathbb{R}^2\).)
Part B — V_b ⊆ ℝ³
1
Row-reduce matrix of spanning vectors
\[ \begin{pmatrix}1&2&1\\2&3&1\\3&4&1\end{pmatrix} \xrightarrow{R_2\leftarrow R_2-2R_1,\;R_3\leftarrow R_3-3R_1} \begin{pmatrix}1&2&1\\0&-1&-1\\0&-2&-2\end{pmatrix} \]
2
R3 ← R3 − 2R2
\[ \begin{pmatrix}1&2&1\\0&-1&-1\\0&0&0\end{pmatrix} \xrightarrow{R_2\leftarrow -R_2} \begin{pmatrix}1&2&1\\0&1&1\\0&0&0\end{pmatrix} \]
Two non-zero rows — the third vector was linearly dependent. \(\dim(\mathcal{V}_b)=2\).
✓ Standard Basis and Dimension \[\mathcal{B}_b=\left\{\begin{pmatrix}1\\2\\1\end{pmatrix},\begin{pmatrix}0\\1\\1\end{pmatrix}\right\},\quad\dim(\mathcal{V}_b)=2\]
Note: Three vectors were given but only two are independent — the third, \((3,4,1)^T\), equals the sum of the first two.
Concept
BASISDIMENSIONLIN. DEPENDENCE
▶

Dimension = number of pivots when spanning vectors are placed as rows and reduced. A zero row means one spanning vector was a linear combination of the others.

Max dimension: A subspace of \(\mathbb{R}^n\) has dimension at most \(n\). If \(\dim=n\), the subspace equals all of \(\mathbb{R}^n\).

05
Null Space & Range Space
KERNEL · COLUMN SPACE · RANK-NULLITY · 20 PTS
▶
Problem
Each \(A\) defines \(\mathcal{L}(\mathbf{x})=A\mathbf{x}\). Find a basis for \(\ker(A)\) and the standard basis for \(\operatorname{col}(A)\).
a
\(A=\begin{pmatrix}1&2&3\\2&5&7\\1&3&4\end{pmatrix}\)
b
\(A=\begin{pmatrix}1&1&1&2\\1&0&1&0\\2&1&0&1\end{pmatrix}\)
Definitions — null space and range (column) space ▶
Null space / kernel: solve \(A\mathbf{x}=\mathbf{0}\); express solution as span of vectors (one per free variable).
Column space / range: the original columns of \(A\) at pivot positions after row-reducing \(A\).
\[\operatorname{rank}(A)+\operatorname{nullity}(A)=n\quad(n=\text{number of columns})\]
Part A — 3×3 Matrix
1
Row-reduce [A | 0]
\[ \left[\begin{array}{ccc|c}1&2&3&0\\2&5&7&0\\1&3&4&0\end{array}\right] \xrightarrow{R_2-2R_1,\;R_3-R_1} \left[\begin{array}{ccc|c}1&2&3&0\\0&1&1&0\\0&1&1&0\end{array}\right] \]
2
R3 ← R3 − R2
\[ \left[\begin{array}{ccc|c}1&2&3&0\\0&1&1&0\\0&0&0&0\end{array}\right] \]
Pivots in cols 1 and 2. Free variable: \(x_3=t\).
3
Null space — solve for pivot vars
\[x_2=-t,\quad x_1=-2(-t)-3t=2t-3t=-t\]
\[\mathbf{x}=t\begin{pmatrix}-1\\-1\\1\end{pmatrix}\]
4
Column space — pivot columns 1 and 2 of original A
\[\operatorname{col}(A)=\operatorname{span}\!\left\{\begin{pmatrix}1\\2\\1\end{pmatrix},\begin{pmatrix}2\\5\\3\end{pmatrix}\right\}\]
Rank = 2, nullity = 1. Check: \(2+1=3\) ✓
✓ Answer (Part A) \[\ker(A)=\operatorname{span}\!\left\{\begin{pmatrix}-1\\-1\\1\end{pmatrix}\right\},\qquad \operatorname{col}(A)=\operatorname{span}\!\left\{\begin{pmatrix}1\\2\\1\end{pmatrix},\begin{pmatrix}2\\5\\3\end{pmatrix}\right\}\]
Part B — 3×4 Matrix
1
Row-reduce [A | 0]
\[ \left[\begin{array}{cccc|c}1&1&1&2&0\\1&0&1&0&0\\2&1&0&1&0\end{array}\right] \xrightarrow{R_2-R_1,\;R_3-2R_1} \left[\begin{array}{cccc|c}1&1&1&2&0\\0&-1&0&-2&0\\0&-1&-2&-3&0\end{array}\right] \]
2
R2 ← −R2 ; R3 ← R3 − R2 (after sign flip)
\[ \left[\begin{array}{cccc|c}1&1&1&2&0\\0&1&0&2&0\\0&-1&-2&-3&0\end{array}\right] \xrightarrow{R_3+R_2} \left[\begin{array}{cccc|c}1&1&1&2&0\\0&1&0&2&0\\0&0&-2&-1&0\end{array}\right] \]
3
R3 ← R3 ÷ (−2)
\[ \left[\begin{array}{cccc|c}1&1&1&2&0\\0&1&0&2&0\\0&0&1&\tfrac{1}{2}&0\end{array}\right] \]
Pivots in cols 1, 2, 3. Free variable: \(x_4=t\).
4
Back-substitute for null space
\[ \begin{aligned} x_3 &= -\tfrac{1}{2}t\\ x_2 &= -2t\\ x_1 &= -x_2 - x_3 - 2t = 2t+\tfrac{1}{2}t-2t = \tfrac{1}{2}t \end{aligned} \]
\[\mathbf{x}=t\begin{pmatrix}\tfrac{1}{2}\\-2\\-\tfrac{1}{2}\\1\end{pmatrix} \;\overset{\times 2}{=}\; s\begin{pmatrix}1\\-4\\-1\\2\end{pmatrix}\]
5
Column space — pivot cols 1, 2, 3 of original A
\[\operatorname{col}(A)=\operatorname{span}\!\left\{\begin{pmatrix}1\\1\\2\end{pmatrix},\begin{pmatrix}1\\0\\1\end{pmatrix},\begin{pmatrix}1\\1\\0\end{pmatrix}\right\}\]
Rank = 3, nullity = 1. Check: \(3+1=4\) ✓
✓ Answer (Part B) \[\ker(A)=\operatorname{span}\!\left\{\begin{pmatrix}1\\-4\\-1\\2\end{pmatrix}\right\},\qquad \operatorname{col}(A)=\operatorname{span}\!\left\{\begin{pmatrix}1\\1\\2\end{pmatrix},\begin{pmatrix}1\\0\\1\end{pmatrix},\begin{pmatrix}1\\1\\0\end{pmatrix}\right\}\]
Concept
RANK-NULLITYNULL SPACECOLUMN SPACE
▶

Rank-Nullity Theorem: \(\operatorname{rank}(A)+\operatorname{nullity}(A)=n\) where \(n\) is the number of columns. Always use this as a sanity check.

Critical rule: For the column space, use the original columns of \(A\) at the pivot positions — not the row-reduced versions. For the null space, use the free-variable parametric vectors from the reduced system.

Scaling tip: Multiply null-space vectors by the LCM of denominators to get clean integer entries — both are valid bases.
