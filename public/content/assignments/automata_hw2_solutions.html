DFA DESIGN §1.1SUBSTRING TRACKINGPARITY DFA
▶

Substring-avoidance DFA: Track the longest suffix of input that is a prefix of the forbidden string. States = prefixes of the forbidden word + 1 dead state. This is essentially building a DFA from the failure function of the KMP algorithm.

Parity DFA: Any property defined by length mod \(k\) needs exactly \(k\) states. Length-parity (mod 2) needs exactly 2 states. Every input symbol flips the parity regardless of its value when \(\Sigma=\{0,1\}\).

Problem

a
\(\{w\in\{a,b,c\}^*\mid |w|\geq 2\) and (the second-to-last symbol is \(b\)) or (every \(a\) in \(w\) is separated from every \(c\) by at least one \(b)\}\) (12 pts)

Part A — Second-to-last is b OR every a separated from every c by b
Design Idea
union via ε-branchescondition 1: second-to-last is bcondition 2: no ac or ca
▶
Use NFA nondeterminism: branch at start with \(\varepsilon\) into two sub-NFAs.
Branch 1 (second-to-last is \(b\)): read \(\Sigma^*\), then guess "we are now at position \(|w|-1\)", read \(b\), read one more symbol.
Branch 2 (no \(a\) adjacent to \(c\) without a \(b\) between): stay in \(\{a,b\}^*\cup\{b,c\}^*\) — equivalently, forbid substring \(ac\) and substring \(ca\). Need \(|w|\geq 2\).
1
Branch 1 NFA — second-to-last symbol is b
States: \(s_0 \xrightarrow{\Sigma} s_0\) (loop reading anything), then nondeterministically guess the second-to-last position: \(s_0 \xrightarrow{b} s_1 \xrightarrow{\Sigma} s_2\) where \(s_2\) is accepting. This forces the \(b\) at position \(|w|-1\) and any symbol at \(|w|\).
2
Branch 2 NFA — every a separated from every c by a b
This means: no \(ac\) and no \(ca\) substring can appear; every \(a\) and every \(c\) must be separated by at least one \(b\). So the string is in \((b^* a b^*)^* \cup (b^* c b^*)^*\) roughly — more precisely, the string may contain both \(a\)'s and \(c\)'s but each \(a\) must be separated from each \(c\) by a \(b\). This is equivalent to: no adjacent pair from \(\{a,c\}\times\{a,c\}\) in the string after removing all \(b\)'s leaves only one of \(\{a,c\}\) — i.e., \(w\) cannot contain both an \(a\) and a \(c\) without a \(b\) between them. One clean encoding: the string, when you remove \(b\)'s, has no \(ac\) or \(ca\). We track "last non-b symbol seen" with states.
3

NFA has a start state \(q_0\) with \(\varepsilon\)-transitions to the start of each branch. Both branches require \(|w|\geq 2\) (at least two characters consumed before accept). The full NFA is given in 1hw2a.jff.

▶

Part A — No Substring "00"
Key insight — 0 must always be followed by 1 or 2 ▶
If "00" is forbidden, then every 0 in the string must be immediately followed by a 1 or 2 (or be at the end). So every 0 is part of the "unit" \(0(1|2)\), except possibly one trailing 0. The string is built from units \(\{1, 2, 01, 02\}\) optionally ending in 0.

Build the expression
Let \(U = (1 \mid 2 \mid 01 \mid 02)\) — a "safe unit" that cannot create "00".
Any string with no "00" is a sequence of such units, possibly ending in a single 0:
R_a = U^* (0 \mid \varepsilon)
Expanding \(U\):
R_a = (1 | 2 | 01 | 02)* (0 | ε)
Verification: "102": 1·02 → \(U^*\) gives ε, unit "1", unit "02" → ✓ accepted.
"100": ends in "00" → 1·0·0 → the trailing 0 of first block would need a 1/2 after it, but next is 0 → "00" → not in \(R_a\). ✓ rejected.
✓ R_a (1 | 2 | 01 | 02)* (0 | ε)

Concept
REGULAR EXPRESSIONS §1.3SIPSER DEF 1.52
▶

Substring avoidance: To avoid "xy", every x must be followed by something that is not y. Form atomic units \(\{x\sigma \mid \sigma\neq y\}\cup(\Sigma\setminus\{x\})\)^* plus optional trailing x.

Even/odd length: \((\Sigma\Sigma)^*\) generates all even-length strings; \(\Sigma(\Sigma\Sigma)^*\) generates all odd-length strings (includes \(\varepsilon\)-free single characters).

Intersection via split: "Contains pattern P AND even length" = split the string at the first P occurrence and enforce parity on prefix+suffix together.

Concept
SUBSET CONSTRUCTION §1.2SIPSER THEOREM 1.39
▶

Subset (powerset) construction: DFA states = subsets of NFA states. Start = ε-closure(q₀). Transition \(\delta'(R,a)=\varepsilon\text{-closure}(\bigcup_{r\in R}\delta(r,a))\). Accept if any NFA accept state is in the subset.

When the NFA is already a DFA: All reachable DFA states are singletons \(\{q\}\) plus possibly ∅ (dead state). The subset construction simply re-labels the NFA.

Thompson's construction (Sipser Lemma 1.55): Every regex \(R\) converts to an NFA \(N\) with \(L(N)=L(R)\). The construction is inductive: base cases for \(\varepsilon\), \(\emptyset\), single symbols; inductive for \(\cup\), concatenation, \(^*\).

GNFA construction (Sipser Lemma 1.60): Convert DFA/NFA to GNFA with new start \(s\) and accept \(f\). Then rip states one at a time using: \(R(q_i,q_j)\leftarrow R(q_i,q_j)\cup R(q_i,q_{rip})\cdot R(q_{rip},q_{rip})^*\cdot R(q_{rip},q_j)\). When only \(s\) and \(f\) remain, the label on the single edge is the regex.

Rip order matters for complexity, not correctness. Rip dead/trap states first — they contribute \(\emptyset\) to all paths and simplify the calculation.

Exam tip: When a state has no outgoing edges to "useful" states (only dead loops), ripping it contributes nothing. Always check before computing.
