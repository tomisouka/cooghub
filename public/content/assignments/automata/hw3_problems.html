Q1 C = {aq | q composite} is not regular · Compute C* ▼
Prove that C = {aq | q is a composite number} is not a regular language. Compute the Kleene closure C*.
Core Idea — always visible

Use the Pumping Lemma. Pump down (i=0) to remove k a's and land on a prime-length string — which is outside C. A DFA cannot distinguish composite from prime lengths with finite memory.

Key Fact — always visible
Pumping down: new length = m − k
Bertrand's Postulate: ∀ n ≥ 1, ∃ prime p with n < p ≤ 2n
→ For large composite m, ∃ prime in [m−p, m−1] → pump down to reach it
Watch Out — read before attempting

Pumping up (i=2) is hard here because the result may still be composite. Pump down to a prime. Choose m carefully so that m−k is prime for some valid k ≤ p.

Part A — C is not regular
1
Assume for contradiction and choose your string
tap to reveal
Assume C is regular. Let p be the pumping length.

Choose s = am where m is composite, m ≥ p. (Use m = p² which is composite for p ≥ 2.)
2
Apply Pumping Lemma — what does y look like?
tap to reveal
By PL, write s = xyz, |xy| ≤ p, |y| = k ≥ 1.

Since |xy| ≤ p ≤ m, xy lies entirely in the a-section → y = ak for some 1 ≤ k ≤ p.
3
Pump down (i=0) and compute new length
tap to reveal
Pump i=0: xz has length m − k. For xz ∉ C we need m−k to be prime (or 1).
4
Why can we always find such an m? (Bertrand's Postulate)
tap to reveal
By Bertrand's Postulate: ∀ n ≥ 1, ∃ prime p' with n < p' ≤ 2n.

For large composite m, ∃ prime p' ∈ [m−p, m−1]. Choose m = p' + k for some k ∈ [1,p] → m−k = p' is prime. Such m can be chosen composite.
5
State the contradiction
tap to reveal
xz = am−k is prime-length → xz ∉ C.
This contradicts PL (xy0z must be in C). So C is not regular.
Conclusion — Part A
C is not regular. Pumping down reaches a prime-length string outside C, violating the Pumping Lemma. □
Part B — Computing C*
1
Define C* precisely
tap to reveal
C* = {an | n = 0 or n is a sum of composite numbers}.
Composite lengths: {4, 6, 8, 9, 10, 12, …}
2
Which small values are NOT in C*?
tap to reveal
n=0: ε ∈ C* ✓ | n=1: not expressible ✗ n=2,3: prime ✗ | n=4: 4 ✓ | n=5: prime ✗ n=6: 6 ✓ | n=7: prime ✗ | n=8: 4+4 ✓ n=9: 9 ✓ | n=10: 4+6 ✓ | n=11: prime ✗ n≥12: always expressible (4s and 9s) ✓
3
State the result and is C* regular?
tap to reveal
C* = {ε} ∪ {an | n ≥ 4, n ∉ {5,7,11}}.

This is cofinite — all but finitely many strings of a*. Cofinite languages are regular.
Conclusion — Part B
C* = {ε} ∪ {an | n ≥ 4, n ∉ {5,7,11}} — regular (cofinite). C is not regular but C* is. Kleene closure does not preserve non-regularity.
Q2 Turing Machine for {ambn | m ≠ n} ▼
Design a deterministic Turing Machine for {ambn | m ≠ n}. Show operation on 3 strings in the language and 3 not in the language.
Core Idea — always visible

Mark a's as X, b's as Y. Cross off one matched pair per pass. If one side runs out while the other has characters remaining → m ≠ n → accept. If both exhaust simultaneously → m = n → reject.

Three Cases — always visible
a's gone, b's remain → m < n → ACCEPT
b's gone, a's remain → m > n → ACCEPT
both exhausted together → m = n → REJECT
Watch Out — read before attempting

When q₀ sees X (all a's marked), enter q₃ to check remaining b's — don't halt here. Also: q₀ seeing blank with no b's means m = n = 0 → reject.

Q3 Every regular language is TM-decidable ▼
Prove every regular language is TM-Decidable. Give one example that is TM-Decidable but not regular. What does this show about the two classes?
Core Idea — always visible

Simulate the DFA on a TM. A DFA always halts after reading the input (reads each symbol exactly once). The TM mirrors this — it always halts, always gives the right answer → it's a decider.

Construction — always visible
Given DFA M = (Q, Σ, δ, q₀, F), build TM T:
Each step: read symbol a, apply δ, move right
On blank: if current state ∈ F → accept, else → reject
Watch Out — read before attempting

Prove two things: (1) T always halts — because DFA processes each symbol once. (2) T accepts exactly L — by the DFA simulation correctness. Both are needed.

Part A — Proof
1
Set up — what do we start with?
tap to reveal
Let L be any regular language. Then ∃ DFA M = (Q, Σ, δ, q₀, F) with L(M) = L.
2
Construct TM T that simulates M
tap to reveal
Construct TM T with states Q ∪ {q_accept, q_reject}.

For each (q, a) with δ(q,a) = q': T writes a, moves right, enters q'.
When T reads ␣: if current state ∈ F → accept, else → reject.
3
Prove T always halts
tap to reveal
T reads each input symbol exactly once and moves right. After |w| steps it reads blank and halts — always. T is a decider.
4
Prove T accepts exactly L
tap to reveal
T accepts w iff after reading w, TM state ∈ F
iff δ*(q₀, w) ∈ F
iff w ∈ L(M) = L

Therefore L(T) = L — T decides L.
Conclusion — Proof
Every regular language is TM-decidable. DFA simulation is a valid decider: always halts, accepts exactly L. □
Part B — Example and Class Relationship
1
Give the example language
tap to reveal
L = { 0ⁿ1ⁿ | n ≥ 0 }
2
Why is it not regular?
tap to reveal
By PL: choose s = 0p1p. Pumping the 0-section produces unequal counts. A DFA can't count arbitrarily large n with finite states → not regular.
3
Why is it TM-decidable?
tap to reveal
A TM crosses off matching 0-1 pairs (same strategy as Q2). Always halts. Accepts iff all matched → TM-decidable.
4
State the class relationship
tap to reveal
Regular ⊊ TM-Decidable — inclusion is strict.

Hierarchy: Regular ⊊ Context-Free ⊊ TM-Decidable ⊊ TM-Recognizable
Conclusion
Regular ⊊ TM-Decidable. Regular languages are limited by finite memory; TMs have unbounded tape enabling counting impossible for DFAs.
Q4 L = {anbm | n = m²} is not regular — Pumping Lemma ▼
Prove L = {anbm | n = m², n,m ≥ 1} is not regular using the Pumping Lemma. Choose a string where the number of a's exceeds the pumping length p.
Core Idea — always visible

Choose s = ap²bp. Since p² > p, xy lies entirely in the a-section. Pumping up adds k extra a's. The gap from p² to the next valid a-count (p+1)² = p²+2p+1 is 2p+1, but k ≤ p < 2p+1 — you can never bridge the gap.

The Gap Argument — always visible
After pumping up: a-count = p²+k, b-count = p
Valid: need a-count = p² (impossible, k≥1) or (p+1)² = p²+2p+1
But k ≤ p < 2p+1 → can never reach next valid count → contradiction
Watch Out — read before attempting

The b-count never changes when pumping — only a-count grows. Check: does the new a-count equal (b-count)² = p²? No — it's p²+k for k≥1. Does it equal (p+1)²? No — that needs k=2p+1>p.

Proof Steps
1
Assume for contradiction and choose your string
tap to reveal
Assume L is regular. Let p be the pumping length.

Choose s = ap²bp. Check: p² = p² ✓, so s ∈ L. |s| = p²+p ≥ p ✓. Number of a's = p² > p ✓ (exceeds p as required).
2
Apply PL — what does y look like?
tap to reveal
Write s = xyz, |xy| ≤ p, |y| = k ≥ 1.

Since |xy| ≤ p ≤ p², xy lies entirely in the a-section → y = ak for some 1 ≤ k ≤ p.
3
Pump up (i=2) and check if it's in L
tap to reveal
Pump i=2: xy²z = ap²+kbp.

For this to be in L: need p²+k = p² → k = 0. But k ≥ 1. Contradiction.
4
Check whether count could match the next perfect square
tap to reveal
Could p²+k = (p+1)² = p²+2p+1?

Requires k = 2p+1. But k ≤ p < 2p+1. Impossible.

So p²+k is between p² and (p+1)² — not a perfect square → xy²z ∉ L.
5
State contradiction and conclusion
tap to reveal
PL guarantees xy²z ∈ L, but xy²z ∉ L. Contradiction.

Therefore L is not regular.
Conclusion
L is not regular. Gap between consecutive squares (2p+1) always exceeds max pump size (p) — pumping always breaks the n = m² constraint. □
Q5 Right Quotient: L/a is regular if L is regular ▼
L/a = { w ∈ Σ* | wa ∈ L }. Prove that if L is regular, then L/a is also regular.
Core Idea — always visible

w ∈ L/a iff reading w lands in some state q where δ(q,a) ∈ F. Build M' identical to M but change accept states to F' = all states one-a-step away from F.

New Accept States — always visible
F' = { q ∈ Q | δ(q, a) ∈ F }
M' = (Q, Σ, δ, q₀, F') — same DFA, only F changes
Q finite → F' computable → M' is a valid DFA
Watch Out — read before attempting

F' ≠ F. F' contains states that are "one a away" from F — may include non-accepting states of M. Don't use F. Also: F' = ∅ is fine (means L/a = ∅, which is regular).

Proof Steps
1
Set up — start with DFA for L
tap to reveal
Let L be regular. Then ∃ DFA M = (Q, Σ, δ, q₀, F) with L(M) = L.
2
Construct M' — what changes?
tap to reveal
Construct M' = (Q, Σ, δ, q₀, F') where F' = { q ∈ Q | δ(q, a) ∈ F }.

Same Q, Σ, δ, q₀ — only the accept states change.
3
Prove M' is a valid DFA
tap to reveal
Q is finite → F' ⊆ Q is finite and computable. All other components unchanged → M' is a valid DFA.
4
Prove L(M') = L/a (correctness chain)
tap to reveal
M' accepts w
iff δ*(q₀, w) ∈ F'
iff δ( δ*(q₀, w), a ) ∈ F
iff δ*(q₀, wa) ∈ F
iff wa ∈ L(M) = L
iff w ∈ L/a
5
State the conclusion
tap to reveal
L(M') = L/a, and M' is a DFA. Therefore L/a is regular.
Conclusion
L/a is regular. Same DFA, only accept states change to F' = {q | δ(q,a) ∈ F}. The new DFA recognizes exactly L/a. □
Key Insight for the Exam
This technique — modifying only accept states — generalizes to any fixed-suffix operation. The transition function never changes because reading w is identical in both machines. Only the "what counts as done" question changes.
