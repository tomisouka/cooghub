Part 3 — Regular Expressions
Q3a Regex: no substring "00" over {0,1,2} 8 pts ▼
{w ∈ {0,1,2}* | w does not contain the substring 00}
Solution

Between any two 0's there must be at least one non-zero character (1 or 2). A 0 can only appear if it is immediately followed by a 1 or 2 (or end of string).

Structure: start with zero or more non-zero chars, then repeatedly: a 0 followed by one or more non-zeros, ending with an optional 0.

(1|2|0(1|2))*(ε|0)
Justification

Each "block" is either a non-zero character (1|2) or a 0 that is immediately followed by a non-zero (0(1|2)). After all complete blocks, we can optionally end with a single 0. This ensures no two 0's are adjacent.

Q3b Regex: contains "01" and is of even length 12 pts ▼
{w ∈ {0,1,2}* | w contains the substring 01 and is of even length}
Solution

Let Σ = (0|1|2). A string is even-length if it can be split into pairs. The substring "01" starts at some position; that position is either at an even index (0-based) or an odd index.

Let P = (ΣΣ)* = even-length strings Let Σ = (0|1|2) Case 1: "01" starts at even position: P · 01 · P Case 2: "01" starts at odd position: P · Σ · 01 · Σ · P
((0|1|2)(0|1|2))*·01·((0|1|2)(0|1|2))* | ((0|1|2)(0|1|2))*(0|1|2)·01·(0|1|2)((0|1|2)(0|1|2))*
Q3c Regex: no substring "11" OR odd length 12 pts ▼
{w ∈ {0,1,2}* | w does not contain the substring 11 or is of odd length}
Solution (Union of two languages)

L = L₁ ∪ L₂ where:

L₁ = strings with no "11": Between any two 1's there must be a non-1. Regex: (0|2|1(0|2))*(1|ε)

L₂ = strings of odd length: (0|1|2)((0|1|2)(0|1|2))*

(0|2|1(0|2))*(1|ε) | (0|1|2)((0|1|2)(0|1|2))*

Part 5 — Regex → NFA (Thompson's Construction)
Q5 Convert regex (1|2|0(1|2))*(ε|0) to NFA 8 pts ▼
Thompson's Construction Steps

Step 1: NFA for 1: s₁ →1→ a₁

Step 2: NFA for 2: s₂ →2→ a₂

Step 3: NFA for (1|2) — union: new start s, ε to s₁ and s₂; new accept a, ε from a₁ and a₂

Step 4: NFA for 0: s₃ →0→ a₃

Step 5: NFA for 0(1|2) — concatenate NFA(0) with NFA(1|2)

Step 6: NFA for (1|2|0(1|2)) — union of NFA(1|2) and NFA(0(1|2))

Step 7: Apply Kleene star: add ε back-loop from accept to start; make start also accept (for zero repetitions)

Step 8: NFA for (ε|0) — union of empty string (ε-path) and single 0

Step 9: Concatenate step 7 and step 8 results

Total states: ~14 states using standard Thompson's construction Start: s_new Accept: a_final (after optional 0) Key structure: s_new --ε--> [star block start] [star block] handles (1|2|0(1|2)) with ε back-loop [star block accept] --ε--> s_opt0 s_opt0 --ε--> a_final (ε path for no trailing 0) s_opt0 --0--> a_final (0 path for trailing 0)
Part 6 — NFA → Regex (GNFA Elimination)
Q6 Convert NFA from Q5 back to regex using GNFA elimination 12 pts ▼
GNFA Method — State Elimination

Setup: Add new start state q_s with ε to original start, and new accept state q_f with ε from original accept states.

Elimination rule: When removing state q_rip with incoming states Qᵢ and outgoing states Qⱼ, for each pair (qᵢ, qⱼ):

R(qᵢ → qⱼ) := R(qᵢ → qⱼ) ∪ R(qᵢ → q_rip) · R(q_rip → q_rip)* · R(q_rip → qⱼ)

Eliminate states one by one (in any order). After all internal states are removed, the single edge from q_s to q_f carries the final regular expression.

Result: Since the NFA was constructed from (1|2|0(1|2))*(ε|0), the GNFA elimination (when fully carried out) recovers:

(1|2|0(1|2))*(ε|0)
Full Step-by-Step Trace

1. Add q_s →ε→ s_new, q_f ←ε← a_final
2. Eliminate a_final: merge ε-path into q_s → q_f edge
3. Eliminate s_opt0: produces (ε|0) on the surviving edge
4. Eliminate star-block states one by one; each elimination re-derives the union structure
5. Final edge label: (1|2|0(1|2))*(ε|0) □
