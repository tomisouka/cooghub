Q 01 Matrix Operations ➕
Concepts addition scalar multiplication matrix product
Problem

Given matrices \(A, B, C, D, E\) (all \(2\times2\)), compute when defined: \((a)\ D+E \quad (b)\ A+2C \quad (c)\ AB \quad (d)\ DC\).

General Method
  • Check size compatibility: addition needs identical dimensions; multiplication needs \(\#\text{cols}_\text{first} = \#\text{rows}_\text{second}\).
  • For addition / scalar multiplication — operate entry-wise.
  • For product \(AB\): \((AB)_{ij} = \sum_k A_{ik}B_{kj}\).
📌 Illustrative Example — 2×2 matrices
\[A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\; B=\begin{bmatrix}5&6\\7&8\end{bmatrix},\; C=\begin{bmatrix}9&10\\11&12\end{bmatrix},\; D=\begin{bmatrix}13&14\\15&16\end{bmatrix},\; E=\begin{bmatrix}17&18\\19&20\end{bmatrix}\]

(a) \(D+E\)

\[D+E = \begin{bmatrix}30 & 32\\34 & 36\end{bmatrix}\]

(b) \(A+2C\)

\[2C = \begin{bmatrix}18&20\\22&24\end{bmatrix},\quad A+2C = \begin{bmatrix}19 & 22\\25 & 28\end{bmatrix}\]

(c) \(AB\)

\[AB = \begin{bmatrix}1\cdot5+2\cdot7 & 1\cdot6+2\cdot8\\3\cdot5+4\cdot7 & 3\cdot6+4\cdot8\end{bmatrix} = \begin{bmatrix}19 & 22\\43 & 50\end{bmatrix}\]

(d) \(DC\)

\[DC = \begin{bmatrix}13\cdot9+14\cdot11 & 13\cdot10+14\cdot12\\15\cdot9+16\cdot11 & 15\cdot10+16\cdot12\end{bmatrix} = \begin{bmatrix}271 & 298\\311 & 342\end{bmatrix}\]
✓
Answers

(a) \(\begin{bmatrix}30&32\\34&36\end{bmatrix}\)   (b) \(\begin{bmatrix}19&22\\25&28\end{bmatrix}\)   (c) \(\begin{bmatrix}19&22\\43&50\end{bmatrix}\)   (d) \(\begin{bmatrix}271&298\\311&342\end{bmatrix}\)

Q 02 Gaussian Elimination ⚙️
Concepts linear systems row echelon form back-substitution
Problem

Write the given linear system as an augmented matrix, reduce to echelon form by Gaussian elimination, and find all solutions (if any).

General Method
  • Build augmented matrix \([A \mid \mathbf{b}]\).
  • Use row operations (swap · scale · add multiple) to reach upper triangular form.
  • Back-substitute. A row \([0\cdots0 \mid c],\ c\neq0\) means the system is inconsistent.
📌 Illustrative Example — 2 equations, 2 unknowns
\[\begin{cases}x + 2y = 3\\4x + 5y = 6\end{cases} \quad\Rightarrow\quad \left[\begin{array}{cc|c}1&2&3\\4&5&6\end{array}\right]\]

\(R_2 \leftarrow R_2 - 4R_1\):

\[\left[\begin{array}{cc|c}1&2&3\\0&-3&-6\end{array}\right]\]

From row 2: \(-3y = -6 \Rightarrow y = 2\). Substitute back: \(x + 4 = 3 \Rightarrow x = -1\).

✓
Answer

\(x = -1,\quad y = 2\)

Q 03 Linear Combinations 🔗
Concepts span linear combination
Problem

If true, write the given vector as a linear combination of the two spanning vectors. Show all work.

General Method
  • Set up \(c_1\mathbf{v}_1 + c_2\mathbf{v}_2 = \mathbf{w}\).
  • Solve the resulting linear system for \(c_1, c_2\).
  • If a solution exists, express \(\mathbf{w} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2\); otherwise state impossible.
📌 Illustrative Example
\[\mathbf{v}_1 = \begin{bmatrix}1\\2\end{bmatrix},\quad \mathbf{v}_2 = \begin{bmatrix}3\\4\end{bmatrix},\quad \mathbf{w} = \begin{bmatrix}5\\6\end{bmatrix}\]

Need \(c_1\begin{bmatrix}1\\2\end{bmatrix} + c_2\begin{bmatrix}3\\4\end{bmatrix} = \begin{bmatrix}5\\6\end{bmatrix}\), giving the system:

\[\begin{cases}c_1 + 3c_2 = 5\\2c_1 + 4c_2 = 6\end{cases}\]

From row 1: \(c_1 = 5-3c_2\). Substituting: \(-2c_2 = -4 \Rightarrow c_2 = 2,\ c_1 = -1\).

Check: \(-1\begin{bmatrix}1\\2\end{bmatrix}+2\begin{bmatrix}3\\4\end{bmatrix} = \begin{bmatrix}5\\6\end{bmatrix}\) ✓

✓
Answer

\(\mathbf{w} = -1\,\mathbf{v}_1 + 2\,\mathbf{v}_2\)

Q 04 Subspaces — Basis & Dimension 🧩
Concepts standard basis dimension span null space description
Problem

For each of the two given subspaces, determine its standard basis and state its dimension.

General Method
  • If given as a span — form a matrix with those vectors as columns and row-reduce; pivot columns of the original matrix form the basis.
  • If given as a solution set — solve the homogeneous system; write the solution in terms of free variables to find basis vectors.
  • Dimension = number of basis vectors.
📌 Two Subspaces of ℝ³

Subspace \(S_1\): \(\text{span}\left\{\begin{bmatrix}1\\0\\1\end{bmatrix},\begin{bmatrix}0\\1\\0\end{bmatrix},\begin{bmatrix}1\\1\\1\end{bmatrix}\right\}\)

\[\begin{bmatrix}1&0&1\\0&1&1\\1&0&1\end{bmatrix} \xrightarrow{R_3-R_1} \begin{bmatrix}1&0&1\\0&1&1\\0&0&0\end{bmatrix}\]

Pivot columns 1 and 2 → dim = 2.

Subspace \(S_2\): \(\left\{\begin{bmatrix}x\\y\\z\end{bmatrix}\mid x+y+z=0\right\}\)

\(x = -y-z\) gives \(\begin{bmatrix}-y-z\\y\\z\end{bmatrix} = y\begin{bmatrix}-1\\1\\0\end{bmatrix}+z\begin{bmatrix}-1\\0\\1\end{bmatrix}\) → dim = 2.

✓
Answers

\(S_1\) basis: \(\left\{\begin{bmatrix}1\\0\\1\end{bmatrix},\begin{bmatrix}0\\1\\0\end{bmatrix}\right\}\), dim = 2

\(S_2\) basis: \(\left\{\begin{bmatrix}-1\\1\\0\end{bmatrix},\begin{bmatrix}-1\\0\\1\end{bmatrix}\right\}\), dim = 2

Q 05 Null Space & Range 🧠
Concepts null space column space linear operator
Problem

For matrix \(A\) (defining \(\mathcal{L}(\mathbf{x}) = A\mathbf{x}\)), find a basis for the null space and a basis for the range (column space).

General Method
  • Null space: solve \(A\mathbf{x}=\mathbf{0}\) — reduce augmented matrix, express pivot variables via free variables; those vectors form the basis.
  • Range (column space): reduce \(A\) to echelon form; pivot columns of the original \(A\) give the basis.
📌 Example — A is 2×3
\[A = \begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}\]

Null space: solve \(A\mathbf{x}=0\).

\[\left[\begin{array}{ccc|c}1&2&3&0\\4&5&6&0\end{array}\right] \xrightarrow{R_2-4R_1} \left[\begin{array}{ccc|c}1&2&3&0\\0&-3&-6&0\end{array}\right]\]

\(x_2 = -2x_3,\ x_1 = x_3\) → \(\mathbf{x} = x_3\begin{bmatrix}1\\-2\\1\end{bmatrix}\).

Range: pivots in columns 1 and 2 of original \(A\).

✓
Answers

Null space basis: \(\left\{\begin{bmatrix}1\\-2\\1\end{bmatrix}\right\}\)

Range basis: \(\left\{\begin{bmatrix}1\\4\end{bmatrix},\begin{bmatrix}2\\5\end{bmatrix}\right\}\)
