P 01 Combinatorics 30 pts
Concept Permutations Combinations Arrangements with Repetition

We have \(n\) students and \(k \le n\) movie tickets.

(a) Different movies · at most one ticket per student 8 pts
Informal
You have \(k\) distinct tickets and \(n\) students. Pick which \(k\) students get tickets (\(\binom{n}{k}\) ways), then assign tickets to them (\(k!\) ways). Multiply.
Permutations of \(n\) items taken \(k\) at a time: \[P(n,k) = \frac{n!}{(n-k)!} = n(n-1)\cdots(n-k+1)\]

Informal
Each of the \(k\) tickets can go to any of the \(n\) students independently. \(n\) choices for each ticket → multiply.
Arrangements with repetition (functions from a \(k\)-set to an \(n\)-set): \[n^k\]

(c) Same movie · at most one ticket per student 7 pts
Informal
Tickets are identical — just choose which \(k\) students get one. Order doesn't matter.
Combinations (binomial coefficient): \[\binom{n}{k} = \frac{n!}{k!(n-k)!}\]
✅
Your answer
Correct! Full credit.
(d) Asymptotic ranking for \(k = \lfloor n/2 \rfloor\) 8 pts
Informal
When \(n\) is large: \(\binom{n}{n/2}\) grows like \(2^n\); \(\frac{n!}{(n/2)!}\) grows like \(n^{n/2}\) but slightly smaller; \(n^{n/2}\) is the largest. Slowest → fastest:
\[\binom{n}{n/2} \;\ll\; \frac{n!}{(n/2)!} \;\ll\; n^{n/2}\] \[\binom{n}{n/2} = o\!\left(\frac{n!}{(n/2)!}\right) \quad\text{and}\quad \frac{n!}{(n/2)!} = o\!\left(n^{n/2}\right)\]
❌
Your answer
Gave some equalities but no clear ordering.

4 · Induction step 15 pts
What to prove
If \(6^k - 1\) is divisible by \(5\), then \(6^{k+1} - 1\) is also divisible by \(5\).
\[\begin{aligned} 6^{k+1} - 1 &= 6\cdot 6^k - 1 \\ &= 6(6^k - 1) + 6 - 1 \\ &= 6(6^k - 1) + 5 \\ &= 6(5m) + 5 \quad\text{(by induction hypothesis)}\\ &= 5(6m + 1) \end{aligned}\] Thus \(6^{k+1} - 1\) is a multiple of \(5\). ✓

P 03 Algorithms 40 pts
Concept Recursive Algorithms Recurrence Relations — Pandurangan, Introduction to Algorithms
Array \(A[1..n]\) of 0s and 1s is good if it has an even number of 1s.
(a) Recursive algorithm — pseudocode 20 pts
Informal
Check the last element. If 0, parity same as first \(n-1\). If 1, parity flips. Recurse.
function isGood(A, n):
  if n == 0:
    return True
  else:
    prev = isGood(A, n-1)
    if A[n] == 0:
      return prev
    else:
      return not prev
❌
Your answer
Too vague — "divide and conquer," "split mid".
(b) Proof of correctness by induction 10 pts
Proof
Claim: isGood(A, n) returns True iff first \(n\) elements have an even number of 1s.

Base case \(n=0\): Returns True. Empty array has 0 ones (even). ✓

Inductive hypothesis: For any \(m < n\), isGood(A, m) is correct.

Inductive step: Let \(p = \text{isGood}(A, n-1)\). By hypothesis, \(p\) is True iff first \(n-1\) elements have even ones.
If \(A[n] = 0\): total parity unchanged → return \(p\). ✓
If \(A[n] = 1\): parity flips → return \(\text{not}\ p\). ✓

Thus the algorithm is correct for size \(n\). □
❌
Your answer
No induction proof given.
