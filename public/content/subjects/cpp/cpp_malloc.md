Final mental model

struct = lightweight class

method = function inside class

constructor = auto-called setup method

malloc = raw memory (C)

new = memory + constructor (C++)

heap = runtime flexibility

stack = compile-time safety

Constructor overloading = multiple ways to create the object

public → accessible from outside the object

private → only accessible inside the class

If it’s a class/struct → use new, not malloc

Stack memory is planned at compile time

Heap memory is requested at runtime

Attributes = the details or properties of an object.

“Instance” just means a concrete thing created from a type, whether built-in (int) or user-defined (class/struct).

Built-in types → instance = variable

Class/struct → instance = object
