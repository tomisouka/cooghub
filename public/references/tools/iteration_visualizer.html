# What "O(n)" means formally:

# Find constants c > 0 and n₀ ≥ 1 such that:
# f(n) ≤ c · g(n)  for all n ≥ n₀

# For a single loop doing 1 op each iter:
f(n) = 1·n  (exactly n operations)

# Choose c = 1, n₀ = 1:
  n ≤ 1·n  ✓  for all n ≥ 1

# ∴ f(n) = O(n)  □
Growth: iterations vs n
The line is straight. 2× input = 2× work. That's linear — O(n).

O(n²) — outer loop runs n times; for each, inner runs n times. Total = n × n = n². 
# Counting nested loops:

# Outer:  i = 0, 1, 2, …, n−1  →  n times
# Inner:  j = 0, 1, 2, …, n−1  →  n times
#         per outer iteration

Total = n × n = n²

# Product rule: O(n) × O(n) = O(n²)

# If inner ran m times instead:
Total = n × m  =  O(n·m)
# e.g. 2D array traversal
Growth: operations vs n
Parabola. n=5 → 25 ops. n=10 → 100 ops. Doubling n quadruples the work.

O(log n) — i is halved each step. Starting at n=64, it takes exactly ⌊log₂(64)⌋ = 6 steps. 
# Why halving = log n steps?

# Each division by 2:
step 0: i = n
step 1: i = n/2
step 2: i = n/4
step k: i = n / 2ᵏ

# Loop ends when i ≤ 0:
n / 2ᵏ ≤ 1  →  2ᵏ ≥ n
         →  k ≥ log₂(n)

# Steps = ⌊log₂(n)⌋ + 1 = O(log n)

# Same logic: binary search, tree height
Growth: steps vs n
Barely grows. n=64 → 6 steps. n=1024 → 10 steps. Exponential input increase = tiny step increase.
Pattern 04
Recursive Calls O(2ⁿ) 
def fib(n):
    if n <= 1:              # base case
        return n
    return fib(n-1) + fib(n-2)  # 2 calls!

O(2ⁿ) — each call spawns 2 more. fib(5) makes 15 total calls, even though there are only 6 unique subproblems. 
# The call tree grows exponentially:

T(n) = T(n-1) + T(n-2) + O(1)

level 0:        fib(n)          # 1 node
level 1:     fib(n-1) fib(n-2)  # 2 nodes
level 2:   …   …   …   …       # ≤4 nodes
level k:             …          # ≤2ᵏ nodes

Total nodes ≤ 2⁰ + 2¹ + … + 2ⁿ = 2ⁿ⁺¹ - 1
         = O(2ⁿ)

# Fix: memoization → O(n)
Calls vs n (explodes fast)
n=5 → 15 calls. n=10 → 177 calls. n=20 → 21891 calls. Avoid exponential when possible.
Pattern 05
Divide & Conquer — Merge Sort O(n log n) 
def mergesort(arr):           # T(n) = 2·T(n/2) + O(n)
    if len(arr) <= 1: return arr  # base case: T(1) = O(1)
    mid = len(arr) // 2
    L = mergesort(arr[:mid])      # left half  → T(n/2)
    R = mergesort(arr[mid:])      # right half → T(n/2)
    return merge(L, R)           # merge       → O(n)
