Deterministic Finite Automata (DFA)

A DFA reads input left-to-right, one symbol at a time. Each state-input pair leads to exactly one next state — fully deterministic, no choices, no ε-moves.

Definition 1.5

A finite automaton is a 5-tuple (Q, Σ, δ, q₀, F), where

  1. Q is a finite set called the states, Q = {q₁, q₂, …, qₙ}
  2. Σ is a finite set called the alphabet, Σ = {0, 1}
  3. δ: Q × Σ ⟶ Q is the transition function, δ(q, a) = q'
  4. q₀ ∈ Q is the start state, and q₀ ∈ Q
  5. F ⊆ Q is the set of accept states. F ⊆ Q
Acceptance — Definition 1.16
M accepts string w = w₁w₂…wₙ iff there exist states r₀, r₁, …, rₙ in Q such that:
  (i) r₀ = q₀,  (ii) δ(rᵢ, wᵢ₊₁) = rᵢ₊₁ for i = 0,…,n−1,  (iii) rₙ ∈ F.

L(M) = {w | M accepts w} — the language recognized by M.
A language is regular if and only if some finite automaton recognizes it.

Dead State (Trap State)

A dead state (also called a trap state or sink state) is a non-accepting state from which no accept state is reachable — once the machine enters it, the string is guaranteed to be rejected. Dead states are not part of Sipser's formal definition, but they appear naturally in DFA construction and are essential for keeping δ a total function.

ConceptPlain EnglishFormal Meaning
Dead state qdeadthe reject pitA state qdead ∉ F where δ(qdead, a) = qdead for every a ∈ Σ — all transitions loop back on themselves
Why it's neededδ must be totalSipser's δ: Q × Σ → Q must be defined for every (state, symbol) pair. If no real transition exists, it goes to qdead
Implicit vs. explicitshown or hiddenDiagrams often omit qdead for clarity (implicit). Formal/complete DFAs include it explicitly so δ is total
Complement DFAflip accepts — carefullyWhen complementing a DFA (swapping F and Q \ F), qdead becomes an accept state — it must be included in Q before complementing
L = {w ∈ {a,b}* | w starts with 'ab'}
DFA needs states: q₀ (start), q₁ (saw 'a'), q₂ (saw 'ab', accept), qdead (trap). Any symbol in q₀ other than 'a', or any symbol in q₁ other than 'b', sends the machine to qdead. Once there, it loops forever — the string is rejected regardless of what follows.
Dead State & Complement
To complement a DFA M, swap F and Q \ F. If M was built without an explicit dead state, add qdead first — otherwise strings that were implicitly rejected (missing transitions) would incorrectly become accepted. After the swap, qdead ∈ F, so it becomes an accept state that accepts all strings with no valid path in the original.

Nondeterministic Finite Automata (NFA)

An NFA is a 5-tuple M = (Q, Σ, Δ, s, F), where Δ is a transition relation (not a function) and ε-transitions are allowed via Σε = Σ ∪ {ε}. An NFA accepts if any branch of computation ends in an accept state.

Definition NFA

Notation: Σε = Σ ∪ {ε}. A nondeterministic finite automaton is a 5-tuple M = (Q, Σ, Δ, s, F), where

  1. Q is a finite set of states, Q = {q₁, q₂, …, qₙ}
  2. Σ is the input alphabet, Σ = {0, 1}
  3. s ∈ Q is the initial state, s ∈ Q
  4. F ⊆ Q is the set of final states, F ⊆ Q
  5. Δ ⊆ Q × Σε × Q is the transition relation, Δ ⊆ Q × Σε × Q

If (p, u, q) ∈ Δ, then the NFA in state p can read u and go to q.

NFA Acceptance
M accepts w if we can write w = y₁y₂…yₘ where each yᵢ ∈ Σε and there exist states r₀, r₁, …, rₘ in Q such that:
  (i) r₀ = s,  (ii) (rᵢ, yᵢ₊₁, rᵢ₊₁) ∈ Δ for i = 0,…,m−1,  (iii) rₘ ∈ F.

Theorem 1.39 (Sipser) — NFA = DFA
Every nondeterministic finite automaton has an equivalent deterministic finite automaton. The subset construction converts an NFA with k states to a DFA with at most 2ᵏ states.

Subset Construction (NFA → DFA)

Given NFA M = (Q, Σ, Δ, s, F), build DFA D = (Q', Σ, δ', s₀', F') where: Q' = 𝒫(Q) — each DFA state is a SET of NFA states s₀' = E({s}) — start = ε-closure of NFA start state F' = {R ∈ Q' | R ∩ F ≠ ∅} — accept if any NFA accept state in set δ'(R, a) = E(⋃_{q∈R} {r | (q,a,r) ∈ Δ}) — take all NFA transitions, then ε-close

Closure Properties & Constructions

Definition Closure

A class of languages is closed under an operation if applying the operation to languages in the class always produces a language that is still in the class.

Core Closure Fact
If L₁ and L₂ are regular, then L₁ ∪ L₂ is regular and L₁ ∩ L₂ is regular.
Proof of intersection uses the product construction: simulate both DFAs simultaneously.

Product Construction (Union & Intersection)

Given DFAs M₁ = (Q₁, Σ, δ₁, q₁, F₁) and M₂ = (Q₂, Σ, δ₂, q₂, F₂), build a single DFA that tracks both machines at once.

Product DFA M = (Q, Σ, δ, q₀, F) where: Q = Q₁ × Q₂ — states are PAIRS (r₁, r₂), one from each DFA q₀ = (q₁, q₂) — start in both start states simultaneously δ((r₁,r₂), a) = (δ₁(r₁,a), δ₂(r₂,a)) — step both DFAs on same symbol ┌─────────────────────────────────────────────────────────────┐ │ For INTERSECTION: F = F₁ × F₂ │ │ Accept iff BOTH machines are in an accept state │ │ │ │ For UNION: F = (F₁ × Q₂) ∪ (Q₁ × F₂) │ │ Accept iff AT LEAST ONE machine is in an accept state │ │ │ │ For DIFFERENCE L₁\L₂: F = F₁ × (Q₂ \ F₂) │ │ Accept iff M₁ accepts AND M₂ rejects │ └─────────────────────────────────────────────────────────────┘ Size: |Q₁| · |Q₂| states total
Example: strings over {a,b} that contain "aa" AND end in "b"
Build DFA₁ for "contains aa" (3 states) and DFA₂ for "ends in b" (2 states). Their product DFA has 3×2 = 6 states and accepts (r₁,r₂) pairs where r₁ ∈ F₁ and r₂ ∈ F₂. This is far simpler than constructing the intersection DFA from scratch.

Complement Construction

Complementing a regular language is trivial for DFAs — impossible for NFAs without first converting to DFA.

Given DFA M = (Q, Σ, δ, q₀, F), build complement DFA M̄: M̄ = (Q, Σ, δ, q₀, Q \ F) ← same machine, swap accept/non-accept CRITICAL: M must be a COMPLETE DFA (every (state, symbol) pair has a transition). Add a dead/sink state q_dead if any transitions are missing — otherwise swapping accept states is wrong. q_dead: δ(q_dead, a) = q_dead for all a ∈ Σ (trap state)
Why NFA Complement Is Harder
You cannot complement an NFA by swapping accept states. An NFA accepts if any computation path accepts — swapping accept/reject states on each branch does not invert this OR-logic. You must first convert NFA → DFA (subset construction), then swap accept states on the DFA.

Union via NFA Construction

An alternative to the product construction: build a new NFA that nondeterministically "chooses" which machine to run.

Given NFAs N₁ = (Q₁, Σ, Δ₁, s₁, F₁) and N₂ = (Q₂, Σ, Δ₂, s₂, F₂): Union NFA N = (Q, Σ, Δ, q₀, F): Q = {q₀} ∪ Q₁ ∪ Q₂ — fresh start + all states from both F = F₁ ∪ F₂ — accept if either machine accepts Δ(q₀, ε) = {s₁, s₂} — ε-branch into either machine Δ otherwise inherits Δ₁, Δ₂ — each machine runs independently Size: |Q₁| + |Q₂| + 1 states

Concatenation via NFA Construction

Run N₁ to completion, then nondeterministically start N₂.

Given NFAs N₁ = (Q₁, Σ, Δ₁, s₁, F₁) and N₂ = (Q₂, Σ, Δ₂, s₂, F₂): Concat NFA N = (Q, Σ, Δ, s₁, F₂): Q = Q₁ ∪ Q₂ F = F₂ — only N₂'s accept states are final Δ = Δ₁ ∪ Δ₂ ∪ { (q, ε, s₂) | q ∈ F₁ } — ε-edge from every N₁ accept → N₂ start Intuition: when N₁ has "finished" accepting a prefix, guess the split point and hand off to N₂ via an ε-transition. Size: |Q₁| + |Q₂| states

Kleene Star via NFA Construction

Allow the machine to restart itself after each accepted substring.

Given NFA N₁ = (Q₁, Σ, Δ₁, s₁, F₁): Star NFA N = (Q, Σ, Δ, q₀, F): Q = {q₀} ∪ Q₁ — fresh start state F = {q₀} ∪ F₁ — q₀ accepts ε (zero repetitions) Δ(q₀, ε) = {s₁} — ε-edge to original start Δ = Δ₁ ∪ { (q, ε, s₁) | q ∈ F₁ } — loop back on each accept Why fresh q₀? If s₁ ∈ F₁ and we just made s₁ accept ε, adding loops back to s₁ could break the original machine's behavior. A fresh q₀ avoids this. Size: |Q₁| + 1 states

Reversal Construction

Given DFA M = (Q, Σ, δ, q₀, F), build NFA for Lᴿ: 1. Reverse all edges: if δ(p, a) = q then add (q, a, p) to Δ 2. New start state q₀' with ε-transitions to every q ∈ F 3. New accept state = original q₀ The result is an NFA (may be nondeterministic after reversing). Convert to DFA via subset construction if a DFA is required.

Theorem 1.54 (Sipser) — REGEX = Regular Languages
A language is regular if and only if some regular expression describes it. Proof uses GNFA (Generalized NFA) to convert DFA → regex, and induction on regex structure to convert regex → NFA.

Generalized NFA (GNFA)

A GNFA is like an NFA, but transition labels are regular expressions instead of single symbols. It is the intermediate machine used in Sipser's proof of Theorem 1.54 to mechanically convert any DFA into an equivalent regular expression via state ripping.

Definition 1.64

A generalized nondeterministic finite automaton is a 5-tuple (Q, Σ, δ, qs, qacc), where

  1. Q is a finite set of states
  2. Σ is the input alphabet
  3. δ: (Q \ {qacc}) × (Q \ {qs}) → ℛ is the transition function, where ℛ is the set of all regular expressions over Σ. δ(qi, qj) = R
  4. qs ∈ Q is the start state — unique, with no incoming transitions
  5. qacc ∈ Q is the sole accept state — unique, with no outgoing transitions

GNFA State Naming

SymbolPlain EnglishRoleNotes
qsthe new startNew start stateAdded fresh when converting from DFA. Has ε-transitions to every original state. No incoming edges allowed.
qaccthe new acceptNew sole accept stateAdded fresh. Every original DFA accept state gets an ε-transition into qacc. No outgoing edges allowed.
q₁, q₂, …, qₙthe original statesInterior states (to be ripped)The states from the original DFA. These are removed one at a time during state ripping.

DFA → GNFA Construction

Given DFA M = (Q, Σ, δ, q₀, F), build GNFA G as follows: 1. Add new start state q_s with ε-transition to original q₀ 2. Add new accept state q_acc 3. For every original accept state q ∈ F, add ε-transition q → q_acc 4. For every DFA transition δ(qᵢ, a) = qⱼ, label edge qᵢ → qⱼ with "a" (if multiple symbols lead from qᵢ to qⱼ, combine them with ∪) 5. For any pair (qᵢ, qⱼ) with no transition, add edge labeled ∅ (∅ means "this path is impossible") Result: GNFA with k+2 states where k = |Q|

State Ripping

State ripping removes one interior state at a time, updating the remaining transition labels with a regular expression that absorbs all paths through the ripped state. After ripping all k interior states, only qs and qacc remain, and the single label δ(qs, qacc) is the regular expression for the language.

NotationPlain EnglishMeaning
qripthe state being removedThe interior state selected for ripping in this round
R₁getting into qripLabel on edge qi → qrip (from some state qᵢ to the ripped state)
R₂looping at qripLabel on the self-loop qrip → qrip (∅ if none)
R₃leaving qripLabel on edge qrip → qj (to some state qⱼ)
R₄bypass pathLabel already on edge qi → qj before ripping (∅ if none)
State Ripping Formula
When ripping qrip, replace the label on every remaining edge qi → qj with:

δ'(qᵢ, qⱼ) = R₁(R₂)*R₃ ∪ R₄

Read: "go from qᵢ into qrip via R₁, loop any number of times via R₂, exit to qⱼ via R₃ — OR take the existing bypass R₄."

Apply this for every pair (qᵢ, qⱼ) where qᵢ ≠ qrip and qⱼ ≠ qrip. Then delete qrip and all its edges.
Full DFA → Regex algorithm (Sipser Lemma 1.60): CONVERT(G): if G has only 2 states (q_s and q_acc): return δ(q_s, q_acc) ← this label IS the regex else: pick any interior state q_rip for each pair (qᵢ, qⱼ) with qᵢ ≠ q_rip, qⱼ ≠ q_rip: R₁ = δ(qᵢ, q_rip) R₂ = δ(q_rip, q_rip) R₃ = δ(q_rip, qⱼ) R₄ = δ(qᵢ, qⱼ) δ(qᵢ, qⱼ) ← R₁(R₂)*R₃ ∪ R₄ remove q_rip and all its edges return CONVERT(G) ← recurse on smaller GNFA
Ripping a state with a self-loop
Suppose qᵢ → qrip is labeled a, qrip → qrip is labeled b, qrip → qⱼ is labeled c, and qᵢ → qⱼ already has label d. After ripping: δ'(qᵢ, qⱼ) = ab*c ∪ d. The self-loop b becomes a Kleene star, capturing any number of loops through the ripped state.

Lemma 1.70 — Pumping Lemma for Regular Languages

If A is a regular language, then there is a number p (the pumping length) where if s is any string in A of length at least p, then s may be divided into three pieces s = xyz, satisfying the following conditions:

  1. for each i ≥ 0,  xyiz ∈ A ∀i ≥ 0 : xyiz ∈ A
  2. |y| > 0 y ≠ ε
  3. |xy| ≤ p |xy| ≤ p
String decomposition s = x y z (|s| ≥ p) ┌─────────────────────────────────────────────┐ │ x │░░░░░ y ░░░░░│ z │ └─────────────────────────────────────────────┘ │◄──── |xy| ≤ p ────►│ │◄─ |y| > 0 ─►│ pump up (i=2): x y y z ∈ A pump down (i=0): x z ∈ A (y vanishes → xz) pump up (i=3): x y y y z ∈ A
How to Use — Proving a Language is NOT Regular
Proof by contradiction. Assume A is regular with pumping length p.
  1. Pick s ∈ A with |s| ≥ p — you choose s strategically.
  2. For every valid split s = xyz (|xy| ≤ p, |y| > 0) …
  3. Find some i ≥ 0 such that xyiz ∉ A.
  4. This contradicts the lemma — A is not regular. □

Classic example:  B = {0ⁿ1ⁿ | n ≥ 0}.  Choose s = 0ᵖ1ᵖ.
Since |xy| ≤ p, y = 0ᵏ for some k ≥ 1. Pumping i = 2 gives 0^(p+k) 1ᵖ — unequal counts → ∉ B.

Lemma 2.34 — Pumping Lemma for Context-Free Languages

If A is a context-free language, then there is a number p (the pumping length) where if s is any string in A of length at least p, then s may be divided into five pieces s = uvxyz, satisfying the following conditions:

  1. for each i ≥ 0,  uvixyiz ∈ A ∀i ≥ 0 : uvixyiz ∈ A
  2. |vy| > 0 v ≠ ε or y ≠ ε
  3. |vxy| ≤ p |vxy| ≤ p
String decomposition s = u v x y z (|s| ≥ p) ┌──────────────────────────────────────────────────────┐ │ u │░ v ░│ x │░ y ░│ z │ └──────────────────────────────────────────────────────┘ │◄────── |vxy| ≤ p ───────►│ │◄|v|►│ │◄─|y|─►│ |vy| > 0 (at least one non-empty) pump up (i=2): u v v x y y z ∈ A pump down (i=0): u x z ∈ A (v and y vanish → uxz) pump up (i=3): u v v v x y y y z ∈ A Note: v and y are ALWAYS pumped the same number of times (both i).
How to Use — Proving a Language is NOT Context-Free
Proof by contradiction. Assume A is a CFL with pumping length p.
  1. Pick s ∈ A with |s| ≥ p — choose s strategically.
  2. For every valid split s = uvxyz (|vxy| ≤ p, |vy| > 0) …
  3. Find some i ≥ 0 such that uvixyiz ∉ A.
  4. This contradicts the lemma — A is not a CFL. □

Classic example:  C = {aⁿbⁿcⁿ | n ≥ 0}.  Choose s = aᵖbᵖcᵖ.
Since |vxy| ≤ p, the window vxy cannot span all three symbol regions. So v and y together touch at most two of {a,b,c}. Pumping i = 2 inflates at most two counts while the third stays at p → unequal → ∉ C.

Reading Expressions Aloud

How to say Sipser's notation out loud — essential for exams and discussions.

M = (Q, Σ, δ, q₀, F)
"M is a five-tuple consisting of: Q (the states), Sigma (the alphabet), delta (the transition function), q-zero (the start state), and F (the set of accept states)."
δ(q₁, a) = q₂
"Delta of q-one and a equals q-two." Meaning: in state q₁ reading symbol a, transition to state q₂.
L(M) = {w ∈ Σ* | M accepts w}
"The language of M equals the set of all strings w in Sigma-star such that M accepts w."
S ⇒* aⁿbⁿ
"S derives a-to-the-n b-to-the-n" or "S can produce the string aⁿbⁿ in zero or more derivation steps."
ATM ≤ₘ HALTTM
"A-sub-TM is mapping-reducible to HALT-sub-TM." Meaning: if we could decide HALTTM, we could decide ATM.
∀⟨M, w⟩ ∈ ATM, ∃ c s.t. |c| = O(|w|ᵏ)
"For all encoded pairs M-comma-w in A-TM, there exists a certificate c such that the length of c is Big-O of the k-th power of the length of w."
uq₁abv ⊢ uaq₂bv
"Configuration u q-one a b v yields u a q-two b v in one step." The head moved right after writing a.

Key Theorems — Quick Reference

Chapter 1 — Regular Languages

  • Thm 1.39Every NFA has an equivalent DFA. Subset (powerset) construction. NFA with k states → DFA with ≤ 2ᵏ states.
  • Thm 1.54A language is regular iff it is described by a regular expression. Regex ↔ NFA ↔ DFA — all equivalent.
  • Thm 1.70Pumping Lemma for Regular Languages. All regular languages have a pumping length p. Tool to prove a language is NOT regular.
  • ClosureRegular languages are closed under ∪, ·, *, ∩, complement, reversal, homomorphism, inverse homomorphism.

Chapter 2 — Context-Free Languages

  • Thm 2.20A language is context-free iff some PDA recognizes it. CFG ↔ PDA — both equivalent models.
  • Thm 2.34Pumping Lemma for CFLs. All CFLs have pumping length p. Used to prove a language is NOT context-free (e.g., {aⁿbⁿcⁿ} is not CFL).
  • ClosureCFLs are closed under ∪, ·, *, reversal, intersection with regular. NOT closed under ∩ or complement.

Chapter 3–4 — Computability

  • Thm 3.13Every multitape TM has an equivalent single-tape TM. Multitape is just a convenience; no extra power.
  • Thm 3.16Every nondeterministic TM has an equivalent deterministic TM. NTM = TM in recognizing power; exponential slowdown possible.
  • Thm 3.21A language is Turing-recognizable iff some enumerator enumerates it.
  • Thm 4.11ATM is undecidable. Canonical undecidable language. Proved by diagonalization.
  • Cor 4.23A language is decidable iff it is Turing-recognizable AND co-Turing-recognizable.

Chapter 5 — Reducibility

  • Thm 5.22If A ≤ₘ B and B is decidable, then A is decidable. Contrapositively: if A is undecidable and A ≤ₘ B, then B is undecidable.
  • Rice's ThmEvery non-trivial property of the language of a TM is undecidable. Non-trivial = some TMs have it, some don't.

Chapter 7–8 — Complexity

  • Thm 7.37SAT is NP-complete. Cook-Levin theorem. Every NP language reduces to SAT in polynomial time.
  • Thm 8.5PSPACE = NPSPACE. Savitch's Theorem: nondeterministic space s(n) ⊆ deterministic space s(n)².
  • InclusionsP ⊆ NP ⊆ PSPACE ⊆ EXPTIME. All inclusions known; P ≠ EXPTIME known. P = NP? Unknown.
