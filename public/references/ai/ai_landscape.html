Core Concepts — The Vocabulary

Assistant → Agent Spectrum

Pure assistant (reactive) Hybrid (tools + context) Full agent (autonomous loops)
ChatGPT (chat) Claude (chat) Gemini (chat) GitHub Copilot Cursor (autocomplete) Claude + tools Cursor Agent Claude Code Devin AutoGPT
Key Insight

"Agent" is not a type of model — it's a pattern of use. The same LLM becomes an agent when placed in a loop with tools, memory, and goals. Cursor and Claude Code use the same underlying models as their chat counterparts. The difference is autonomy: the model plans, acts, observes outcomes, and iterates — without a human in the loop at each step.

Products Placed

Claude (chat)
assistant
Anthropic's LLM in conversational mode. Reactive — responds to prompts. Excels at reasoning, writing, and analysis.
Claude Code
agent
Claude in an agentic loop. Terminal access, file editing, multi-step planning. Writes and executes code autonomously.
Cursor (autocomplete)
hybrid
LLM with full codebase context. Suggests and completes — you still drive every decision.
Cursor Agent
agent
Plans tasks, writes files, runs commands autonomously. Same model as autocomplete, different architecture.
ChatGPT
assistant
OpenAI's flagship chat. With plugins and tools it edges toward hybrid. GPT-4o powers vision and voice too.
GitHub Copilot
hybrid
IDE-embedded LLM with repo context. Autocompletes and suggests in-flow, now with agent features in Copilot Workspace.
Devin
agent
Fully autonomous software engineer. Plans, writes, debugs, and deploys. Sets the upper bound on what agents can do today.
Gemini (chat)
assistant
Google's multimodal LLM. Deep integration with Google Workspace. Handles text, images, audio, and video natively.
Midjourney
assistant
Text-to-image diffusion model. Takes a text prompt, returns a high-quality image. Reactive, not agentic.
Whisper (OpenAI)
assistant
Speech-to-text model. Transcribes audio across 99 languages. A narrow, focused deep learning model — not an LLM.
