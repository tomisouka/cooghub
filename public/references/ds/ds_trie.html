Trie.

Prefix Tree · String Data Structure
insert O(m) — m = word length
search O(m)
prefix search O(m)
space O(n × m) total
1 — One Character Per Node
A trie stores strings by breaking them into characters. Each node is one character. Words that share a prefix share the same path — no duplication. The root is always empty.
char character the letter this node represents
Node[26] children one slot per letter a–z (or a hash map)
bool isEnd true if a complete word ends here
2 — Trie Containing: cat, car, card, care, cart, bat, bad
Shared prefixes share nodes. "cat", "car", "card", "care", "cart" all share c→a. End-of-word nodes are highlighted.
Green nodes = end of word marker. car, card, care, cart all share c→a→r before branching. 7 words stored, paths shared wherever prefixes overlap.
3 — Insert, Search, Prefix Search
Insert("care")
Walk character by character. Create nodes that don't exist.
1At root — does child 'c' exist? Yes — move to it.
2At c — does child 'a' exist? Yes — move to it.
3At a — does child 'r' exist? Yes — move to it.
4At r — does child 'e' exist? No — create it.
5Mark new 'e' node as isEnd = true.
Search("card")
Walk the path. Return true only if path exists AND final node is end-of-word.
1Root → 'c' exists ✓
2c → 'a' exists ✓
3a → 'r' exists ✓
4r → 'd' exists ✓
5d → isEnd = true → return true
Prefix("car") → autocomplete
Walk to end of prefix. Don't need isEnd. Then collect all words below.
1Walk c → a → r ✓
2Reached 'r' node — prefix found.
3DFS from 'r' collecting all isEnd nodes below.
4Returns: car, card, care, cart

Key Properties
Character Per Node
Each node holds one character. Words are spelled out along paths from root to an end-of-word marker.
one char per node
Shared Prefixes
"cat", "car", "card" all share c→a. No duplication of common prefixes — efficient for large dictionaries.
prefix compression
O(m) Everything
Insert, search, and prefix search all run in O(m) where m is the length of the string — independent of how many words are stored.
O(m) not O(n)
isEnd Marker
"car" and "card" share c→a→r. The 'r' node has isEnd=true for "car". A 'd' child exists for "card".
marks word boundary
Used In
Autocomplete, spell checkers, search suggestions, IP routing tables, DNA sequence matching.
