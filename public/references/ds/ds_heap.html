1 — The Heap Property
A heap is a complete binary tree where every parent satisfies the heap property — either always greater than its children (max-heap) or always less than its children (min-heap).
Max-Heap
Every parent ≥ its children. Biggest value always at root.
Min-Heap
Every parent ≤ its children. Smallest value always at root.
The heap property only guarantees parent vs children — not left vs right. The heap is not fully sorted. Siblings have no required ordering.
2 — Stored as a Plain Array — No Pointers
Because a heap is a complete binary tree, it maps perfectly to an array. Level by level, left to right. Parent and child positions calculated with simple math.

Node 72 is at index 1. Its left child: 2(1)+1 = index 3 = 55. Its right child: 2(1)+2 = index 4 = 60. Parent: (1−1)/2 = index 0 = 95. No pointers needed.
3 — Insert — Add at End, Bubble Up
Add new value at the end of the array. Then bubble up — swap with parent repeatedly until heap property is restored.
Insert 88 — add at end
→
Bubble up — 88 swaps with 80
95 > 88 — no further swap needed. Done in 1 swap. Worst case bubbles all the way to root: O(log n).
4 — Extract Max — Remove Root, Bubble Down
Remove root (the max). Move the last element to root. Then bubble down — swap with the larger child until heap property is restored.
Remove 95, move last to root
→
Bubble down — 80 swaps up
Extract-max returns 95. 71 goes to root, violates heap property, swaps with 80 (larger child). Check again — 71 > 43, done. O(log n).
Key Properties
Heap Property
Max-heap: every parent ≥ children. Min-heap: every parent ≤ children. Siblings have no required order.
parent ≥ children
Array Storage
Complete binary tree maps perfectly to an array. No pointers. Left child = 2i+1, right = 2i+2, parent = (i−1)/2.
no pointers needed
O(1) Peek
The max (or min) is always at index 0. Access it instantly without any traversal.
root = max or min
Insert + Extract
Insert: add at end, bubble up. Extract: remove root, move last to root, bubble down. Both O(log n).
O(log n) both
