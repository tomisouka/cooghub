1 — The ADT Interface
A Deque (pronounced "deck") is a double-ended queue. Unlike a regular queue (back only for add, front only for remove), a deque lets you add and remove from either end.
Deque ADT — Operations
addFront(val) Add val to the front
addBack(val) Add val to the back
removeFront() Remove and return the front element
removeBack() Remove and return the back element
peekFront() Return front element without removing
peekBack() Return back element without removing
isEmpty() Return true if empty
2 — All Four Operations
Both ends are open. You can push and pop from the front or the back — all in O(1).

3 — Deque Generalizes Stack and Queue
A Stack and a Queue are just restricted deques. Restrict which end you use and you get one of the simpler ADTs.

Deque is the most flexible. Use only back-add + front-remove and you have a queue. Use only front-add + front-remove and you have a stack.
Key Properties
Both Ends Open
Add and remove from either the front or the back. All four operations are O(1).
O(1) both ends
Generalizes Stack + Queue
A stack and a queue are restricted deques. Restrict one end and you get the simpler structure.
most flexible ADT
Implementation
Best implemented with a doubly linked list — O(1) insert and remove at both head and tail. Circular array also works.
doubly linked list
No Middle Access
Like stack and queue — you can only operate on the two ends. No random access to the middle.
ends only
Used In
Sliding window algorithms, undo/redo with history, palindrome checking, browser history (back and forward).
real world
