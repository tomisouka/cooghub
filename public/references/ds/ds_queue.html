1 — The ADT Interface
A Queue is an Abstract Data Type — defines behavior, not implementation. Add to the back, remove from the front. Can be built with an array or linked list.
Queue ADT — Operations
enqueue(val) Add val to the back of the queue
dequeue() Remove and return the front element
peek() Return the front element without removing it
isEmpty() Return true if the queue has no elements
size() Return the number of elements
2 — FIFO — The Line at the Store
Join at the back, leave from the front. First person in line is first person served. No cutting — order is preserved.

3 — Two Implementations, Same Interface
Array uses two indices (front and back). Linked list uses head and tail pointers. Both O(1).
Array-Based (Circular Buffer)
front index points to first element
back index points to next empty slot
enqueue arr[back++ % cap] = val
dequeue return arr[front++ % cap]
wraps around circular — reuses slots
Linked List-Based
front head node
back tail node
enqueue insert at tail
dequeue remove head
overflow dynamic — no resize needed
4 — Array Implementation — Circular Buffer
Two indices track the front and back. When back reaches the end it wraps around using modulo — no shifting needed.

Key Properties
ADT — Not a Structure
Queue defines behavior: enqueue, dequeue, peek. Implemented with array or linked list — same interface either way.
abstraction
FIFO
First In, First Out. The first element enqueued is always the first to be dequeued. Order is preserved.
first in = first out
Two Ends
Unlike a stack (top only), a queue operates at both ends — enqueue at back, dequeue at front.
front + back
Circular Buffer
Array implementation uses modulo wrapping to reuse slots. Avoids shifting by letting front and back indices advance.
% capacity
Used In
BFS traversal, OS process scheduling, print queues, network packet buffers, message queues.
everywhere ordered
