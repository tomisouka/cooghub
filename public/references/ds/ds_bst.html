1 — The One Rule
A BST is a binary tree with an ordering property. At every single node, without exception:
←Left subtree contains only values less than the node
→Right subtree contains only values greater than the node
≠No duplicates — each value appears at most once
Every node in the left subtree (30, 20, 40) is less than 50. Every node in the right subtree (70, 60, 80) is greater. This holds at every node, not just the root.
2 — Search — O(log n)
Searching for 40. At each node compare — go left if smaller, right if larger. Discard half the tree at every step.
3 comparisons to find 40 in a 7-node tree. Faded nodes were never visited — the ordering property eliminated them immediately.
3 — Insert — O(log n)
Inserting 45. Search for where 45 would be — when you fall off the tree, that's where it goes.
Follow the search path — when you need to go right from 40 and there's nothing there, that's the insertion point. Always inserts as a leaf.
4 — Remove — Three Cases
Removal has three cases depending on how many children the target node has.
Case 1 — Leaf Node
No children. Just delete it — set parent's pointer to null.
O(log n)
Case 2 — One Child
Bypass the node — connect its parent directly to its one child.
O(log n)
Case 3 — Two Children
Find the inorder successor (smallest in right subtree). Copy its value here, then delete the successor.
O(log n)
Example: Remove 30 (two children)
Before
After — 40 replaces 30
Inorder successor of 30 is 40 (smallest in right subtree). Copy 40 into 30's position, delete the original 40 leaf. BST property preserved.
5 — The Degenerate Tree Problem
Insert values in sorted order and you get a straight line — height becomes O(n) and you've built a linked list.
Balanced — Insert: 50, 30, 70, 20, 40
Degenerate — Insert: 20, 30, 40, 50, 70
This is why AVL trees and Red-Black trees exist — they self-balance after every insert and remove to keep height at O(log n).
Key Properties
The BST Property
Left subtree < node < right subtree. Holds at every single node in the tree, not just the root.
L < root < R
O(log n) Search

Inorder = Sorted
Inorder traversal of a BST always gives values in ascending sorted order.

Inorder Successor
When removing a node with two children, replace it with the smallest value in its right subtree.
