Key Properties
Node Structure
Each node stores data and a next pointer. That's it. Nodes live anywhere in memory — not contiguous.
2 fields
Head Pointer
The list is just a reference to the first node. Lose the head pointer and you lose the entire list.
O(1) access
No Random Access
Can't jump to index N. Must walk from head, following next pointers until you reach it.
O(n)
Insert / Remove Head
Constant time — just rewire the head pointer. No shifting like arrays.
O(1)
One Direction
You can only traverse forward. To go back you'd need a doubly linked list with a prev pointer.
