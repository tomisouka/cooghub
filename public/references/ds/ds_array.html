Key Properties
Direct Access
Index maps to memory: base + i × size. Jump to any element instantly.
O(1)
Insert / Remove End
Nothing needs to move. Write to last slot, update size.
O(1)
Insert / Remove Middle
Every element after the target must shift. Worst case is index 0.
O(n)
Fixed Capacity
When full, allocate a new larger array and copy all elements. Typically doubles in size.
O(n) resize
