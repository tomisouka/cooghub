Key Properties
3-Field Node
prev | data | next. Each node knows both its predecessor and successor.
3 fields
Head + Tail Pointers
Maintains both ends. O(1) insert and remove at head or tail without any traversal.
O(1) both ends
Clean Removal
Given a node reference, remove it in O(1) — no need to walk to find the predecessor.
O(1) if you have ref
No Random Access
Still must walk from head or tail to reach index N. Just now you can walk from whichever end is closer.
O(n)

Browser history (back/forward), undo/redo stacks, LRU cache, deque implementation.
