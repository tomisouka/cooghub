# Algorithm Categories

**Definitions:**  
- **Iterative:** Solves a problem using loops, repeating steps until a condition is met.  
- **Recursive:** Solves a problem by calling itself on smaller subproblems.  

1. **Sorting Algorithms** – Arrange elements in order. *(Some are recursive: Merge Sort, Quick Sort)*  
2. **Searching Algorithms** – Find or verify elements. *(Some are recursive: Binary Search, DFS)*  
3. **Graph Algorithms** – Solve problems on nodes and edges. *(Often recursive: DFS, some shortest-path algorithms)*  
4. **Tree Algorithms** – Operate on hierarchical data structures. *(Usually recursive: traversals, LCA, height)*  
5. **Dynamic Programming (DP)** – Solve problems using overlapping subproblems with stored results. *(Can be recursive: top-down memoization)*  
6. **Greedy Algorithms** – Make local optimal choices hoping for a global optimum. *(Usually iterative, rarely recursive)*  
7. **Divide & Conquer** – Break problem into smaller parts, solve, and combine. *(Typically recursive)*  
8. **Backtracking** – Explore all possibilities, backtrack when a path fails. *(Always recursive)*
