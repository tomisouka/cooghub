Finite Subsets of ℕ are Countably Infinite
SET THEORY · COUNTABILITY · BIJECTION
▶
Problem
Show that the set of all finite subsets of \(\mathbb{N} = \{0,1,2,\ldots\}\) is countably infinite.
—
Let \(\mathcal{F} = \{S \subseteq \mathbb{N} \mid S \text{ is finite}\}\). Prove \(\mathcal{F}\) is countably infinite.
Proof — Injection into ℕ via Prime Encoding
Strategy
prime encoding bijectioncountable union of countable sets
▶
Method 1 (Injection into ℕ): Map each finite subset \(S = \{n_1 < n_2 < \cdots < n_k\}\) to the natural number \(2^{n_1}\cdot 3^{n_2}\cdots p_k^{n_k}\) (product of distinct prime powers). By unique prime factorization, this map is injective into \(\mathbb{N}\).
Method 2 (below) uses a direct bijection via level sets \(\mathcal{F}_n\).
Definition — countably infinite ▶
A set \(A\) is countably infinite iff there exists a bijection \(f: \mathbb{N} \to A\). Equivalently, \(A\) is infinite and there exists an injection \(g: A \hookrightarrow \mathbb{N}\).
\[A \text{ countably infinite} \iff |A| = |\mathbb{N}| = \aleph_0\]
1
F is infinite
For each \(n\in\mathbb{N}\), the singleton \(\{n\}\in\mathcal{F}\). These are all distinct, so \(\mathcal{F}\) is infinite.
2
Partition F by size
Let \(\mathcal{F}_k = \{S\in\mathcal{F}\mid |S|=k\}\) for \(k=0,1,2,\ldots\) Then:
\[\mathcal{F} = \mathcal{F}_0 \cup \mathcal{F}_1 \cup \mathcal{F}_2 \cup \cdots = \bigcup_{k=0}^{\infty}\mathcal{F}_k\]
3
Each F_k is countable
\(\mathcal{F}_0 = \{\emptyset\}\) — one element, finite. ✓
\(\mathcal{F}_k\) for \(k\geq 1\): each element is a \(k\)-element subset of \(\mathbb{N}\). We can encode any \(S = \{n_1 < \cdots < n_k\}\) as the \(k\)-tuple \((n_1,\ldots,n_k) \in \mathbb{N}^k\). Since \(\mathbb{N}^k\) is countable (Cartesian product of countably many countable sets), and our encoding is injective, \(\mathcal{F}_k\) is countable. ✓
4
Countable union of countable sets is countable
\(\mathcal{F} = \bigcup_{k=0}^{\infty}\mathcal{F}_k\) is a countable union of countable sets. By the standard theorem (Cantor's diagonal enumeration across the \(\mathcal{F}_k\)), \(\mathcal{F}\) is countable.
5
Explicit injection F → ℕ (alternate one-line argument)
Define \(f: \mathcal{F} \to \mathbb{N}\) by:
\[f(\emptyset) = 1, \qquad f(\{n_1,\ldots,n_k\}) = p_1^{n_1+1}\cdots p_k^{n_k+1}\]
where \(p_1 < p_2 < \cdots\) are the primes in increasing order and \(n_1 < \cdots < n_k\). By the Fundamental Theorem of Arithmetic, \(f\) is injective. Since \(\mathcal{F}\) injects into \(\mathbb{N}\), it is countable; since it is infinite, it is countably infinite. \(\blacksquare\)
✓ Conclusion \(\mathcal{F}\) is infinite (contains \(\{0\},\{1\},\{2\},\ldots\)) and countable (via the prime-encoding injection into \(\mathbb{N}\), or by writing \(\mathcal{F}=\bigcup_{k\geq 0}\mathcal{F}_k\) as a countable union of countable sets). Therefore \(\mathcal{F}\) is countably infinite. \(\blacksquare\)
Concept
COUNTABILITYSIPSER §0.2PRIME ENCODING
▶

Countable union of countable sets is countable (Sipser Theorem 0.13): If \(A_1, A_2, \ldots\) are each countable, then \(\bigcup_i A_i\) is countable. Proved by Cantor's diagonal enumeration.

Prime encoding: A powerful general technique — encoding finite tuples/sets as products of prime powers gives an injection into \(\mathbb{N}\) for free.

02
Infinite Subsets of ℕ are Uncountable
DIAGONALIZATION · UNCOUNTABILITY · CANTOR
▶
Problem
Show that the set of all infinite subsets of \(\mathbb{N}\) is uncountable.
—
Let \(\mathcal{I} = \{S \subseteq \mathbb{N} \mid S \text{ is infinite}\}\). Prove \(\mathcal{I}\) is uncountable.
Proof — Diagonalization / Complement Argument
Strategy
complement of finite = infinite𝒫(ℕ) = 𝒻 ∪ 𝒾, 𝒫(ℕ) uncountable
▶
Every subset of \(\mathbb{N}\) is either finite or infinite: \(\mathcal{P}(\mathbb{N}) = \mathcal{F} \sqcup \mathcal{I}\). Since \(\mathcal{P}(\mathbb{N})\) is uncountable (Cantor) and \(\mathcal{F}\) is countable (Problem 1), their difference \(\mathcal{I}\) must be uncountable.
Cantor's Theorem — 𝒫(ℕ) is uncountable ▶
For any set \(A\), \(|A| < |\mathcal{P}(A)|\). In particular \(\mathcal{P}(\mathbb{N})\) is uncountable (proved by diagonalization: any enumeration \(S_0, S_1, S_2, \ldots\) of subsets is incomplete because the diagonal set \(D = \{n \mid n \notin S_n\}\) is not in the list).
1
Key partition
\[\mathcal{P}(\mathbb{N}) = \mathcal{F} \;\sqcup\; \mathcal{I}\]
Every subset of \(\mathbb{N}\) is either finite (in \(\mathcal{F}\)) or infinite (in \(\mathcal{I}\)), and these are disjoint. So \(\mathcal{I} = \mathcal{P}(\mathbb{N}) \setminus \mathcal{F}\).
2
𝒫(ℕ) is uncountable (Cantor diagonal)
Suppose for contradiction \(\mathcal{P}(\mathbb{N})\) is countable: enumerate all subsets as \(S_0, S_1, S_2, \ldots\) Define:
\[D = \{n \in \mathbb{N} \mid n \notin S_n\}\]
Then \(D \subseteq \mathbb{N}\), so \(D \in \mathcal{P}(\mathbb{N})\), yet \(D \neq S_k\) for any \(k\) (they differ on element \(k\)). This contradicts the assumption that the list is complete. Therefore \(\mathcal{P}(\mathbb{N})\) is uncountable.
3
Conclude 𝒾 is uncountable
Suppose for contradiction \(\mathcal{I}\) is countable. Then \(\mathcal{P}(\mathbb{N}) = \mathcal{F} \cup \mathcal{I}\) would be a union of two countable sets, hence countable. But this contradicts Step 2. Therefore \(\mathcal{I}\) is uncountable. \(\blacksquare\)
4
Direct bijection argument (alternative)
Represent each subset \(S \subseteq \mathbb{N}\) by its characteristic (indicator) function \(\chi_S : \mathbb{N} \to \{0,1\}\). Infinite subsets correspond to those \(\chi_S\) that are 1 on infinitely many inputs — i.e., infinite binary sequences with infinitely many 1s. There is an injection from all infinite binary sequences into \(\mathcal{I}\) (any infinite binary sequence can be "padded" into one with infinitely many 1s), and the set of infinite binary sequences has cardinality \(2^{\aleph_0} = |\mathbb{R}|\) — uncountable.
✓ 𝒾 is uncountable Since \(\mathcal{P}(\mathbb{N}) = \mathcal{F} \sqcup \mathcal{I}\), \(\mathcal{P}(\mathbb{N})\) is uncountable (Cantor diagonalization), and \(\mathcal{F}\) is countable (Problem 1): if \(\mathcal{I}\) were countable, \(\mathcal{P}(\mathbb{N})=\mathcal{F}\cup\mathcal{I}\) would be countable — contradiction. Therefore \(\mathcal{I}\) is uncountable. \(\blacksquare\)
Concept
CANTOR DIAGONALIZATIONSIPSER §4.22^ℵ₀ UNCOUNTABLE
▶

Cantor's Theorem: For any set \(A\), \(|\mathcal{P}(A)| > |A|\). The diagonal set \(D=\{n\mid n\notin S_n\}\) witnesses the failure of any enumeration of \(\mathcal{P}(\mathbb{N})\).

Complement trick: If the whole is uncountable and one piece is countable, the other piece must be uncountable. This is a standard technique for establishing uncountability without a direct diagonal argument.

03
Erdős–Szekeres Theorem
PIGEONHOLE · MONOTONE SUBSEQUENCE · COMBINATORICS
▶
Problem
Prove that every sequence of \(n^2+1\) distinct natural numbers contains either a descending subsequence of length \(n+1\) or an ascending subsequence of length \(n+1\).
—
Let \(\langle a_1, a_2, \ldots, a_{n^2+1}\rangle\) be a sequence of distinct naturals. Prove it has a monotone subsequence of length \(\geq n+1\).
Proof — Pigeonhole on Longest Ascending Subsequences
Key Idea
label each element by its LIS lengthpigeonhole on n² + 1 labels
▶
Assign to each \(a_i\) the length \(\ell_i\) of the longest ascending subsequence starting at \(a_i\). If any \(\ell_i \geq n+1\) we're done. Otherwise all \(\ell_i \in \{1,\ldots,n\}\) — with \(n^2+1\) elements and only \(n\) possible values, pigeonhole forces two elements with the same label, from which we extract a descending subsequence.
1
Define the labelling
For each index \(i\) (\(1\leq i\leq n^2+1\)), let \(\ell_i\) be the length of the longest ascending subsequence of \(\langle a_1,\ldots,a_{n^2+1}\rangle\) that begins at position \(i\).
2
Case 1: some ℓᵢ ≥ n+1 → done
If \(\ell_i \geq n+1\) for some \(i\), then there is an ascending subsequence of length \(\geq n+1\) starting at \(a_i\). Done. ✓
3
Case 2: all ℓᵢ ≤ n — apply Pigeonhole
Suppose all \(\ell_i \leq n\). Then each label \(\ell_i\) takes a value in \(\{1, 2, \ldots, n\}\). We have \(n^2+1\) labels and only \(n\) possible values. By the Pigeonhole Principle:
\[\text{At least } \left\lceil\frac{n^2+1}{n}\right\rceil = n+1 \text{ indices share the same label value } \ell\]
4
Extract the descending subsequence
Let \(i_1 < i_2 < \cdots < i_{n+1}\) be \(n+1\) indices all with \(\ell_{i_1} = \ell_{i_2} = \cdots = \ell_{i_{n+1}} = \ell\). We claim \(a_{i_1} > a_{i_2} > \cdots > a_{i_{n+1}}\) (descending).

Proof of claim: Suppose for contradiction \(a_{i_j} < a_{i_{j+1}}\) for some \(j\). Since \(i_j < i_{j+1}\) and \(a_{i_j} < a_{i_{j+1}}\), we could extend the longest ascending subsequence starting at \(a_{i_{j+1}}\) by prepending \(a_{i_j}\). This would give an ascending subsequence starting at \(a_{i_j}\) of length \(\ell_{i_{j+1}} + 1 = \ell + 1 > \ell = \ell_{i_j}\). Contradiction (we defined \(\ell_{i_j}\) as the maximum). Therefore \(a_{i_j} > a_{i_{j+1}}\) for all \(j\), and \(\langle a_{i_1}, a_{i_2}, \ldots, a_{i_{n+1}}\rangle\) is a descending subsequence of length \(n+1\). ✓
5
Conclusion
In both cases, the sequence contains a monotone subsequence of length \(\geq n+1\). \(\blacksquare\)
✓ Proved (Erdős–Szekeres, 1935) Label each \(a_i\) by \(\ell_i =\) length of longest ascending subsequence starting at \(i\). If some \(\ell_i\geq n+1\): ascending subsequence found. Otherwise all \(\ell_i\in\{1,\ldots,n\}\); pigeonhole gives \(n+1\) indices with equal labels, which must form a descending subsequence. \(\blacksquare\)
Example (\(n=2\), sequence of \(5=2^2+1\) elements): \(\langle 3,1,4,1,5\rangle\) — but elements must be distinct, so try \(\langle 5,3,1,4,2\rangle\). Descending subsequence of length 3: \(\langle 5,3,1\rangle\) or \(\langle 5,4,2\rangle\). ✓
Concept
PIGEONHOLE PRINCIPLEERDŐS–SZEKERES 1935
▶

Erdős–Szekeres Theorem: Any sequence of more than \(mn\) distinct real numbers has either an ascending subsequence of length \(>m\) or a descending subsequence of length \(>n\). The bound \(n^2+1\) is tight — there exist sequences of \(n^2\) distinct numbers with no monotone subsequence of length \(n+1\).

Exam tip: The LIS-labelling proof is the canonical approach. Always verify the contradiction step: equal labels + earlier-in-sequence + smaller-value would increase the label — contradiction.

Is Every DFA Also an NFA?
DFA · NFA · DEFINITIONS · SUBSET RELATION
▶
Problem
Is every DFA also an NFA? Justify your answer.
—
Answer yes or no with a formal justification based on the 5-tuple definitions.
Answer — Yes, Every DFA is an NFA
5-tuple definitions of DFA and NFA ▶
DFA: \(M=(Q,\Sigma,\delta,q_0,F)\) where \(\delta: Q\times\Sigma \to Q\) is a total function returning exactly one state.
NFA: \(N=(Q,\Sigma,\delta,q_0,F)\) where \(\delta: Q\times\Sigma_\varepsilon \to \mathcal{P}(Q)\) returns a set of states (possibly empty), and \(\Sigma_\varepsilon = \Sigma\cup\{\varepsilon\}\).
\[\text{DFA: }\delta(q,a)=q' \qquad \text{NFA: }\delta(q,a)\subseteq Q,\;\delta(q,\varepsilon)\subseteq Q\]
1
The answer is YES
Every DFA can be viewed as a special case of an NFA where: (i) every transition returns a singleton set, and (ii) no \(\varepsilon\)-transitions exist.
2
Formal conversion: DFA → NFA
Given DFA \(M=(Q,\Sigma,\delta_{D},q_0,F)\), define NFA \(N=(Q,\Sigma,\delta_{N},q_0,F)\) by:
\[\delta_N(q,a) = \{\delta_D(q,a)\} \;\text{ for all } q\in Q,\; a\in\Sigma\] \[\delta_N(q,\varepsilon) = \emptyset \;\text{ for all } q\in Q\]
\(\delta_N\) maps into \(\mathcal{P}(Q)\) (always a singleton), satisfying the NFA definition. No \(\varepsilon\)-transitions are added.
3
L(N) = L(M)
Since every NFA transition from \(N\) is a singleton \(\{\delta_D(q,a)\}\) (no branching, no \(\varepsilon\)-moves), the NFA \(N\) computes exactly the same language as the DFA \(M\). The NFA acceptance criterion — "at least one computation path reaches an accept state" — reduces to the single path of the DFA.
✓ Yes — every DFA is a special NFA A DFA is an NFA whose transition function always returns singleton sets and has no \(\varepsilon\)-transitions. Formally, given DFA \(\delta_D: Q\times\Sigma\to Q\), define NFA \(\delta_N(q,a)=\{\delta_D(q,a)\}\) and \(\delta_N(q,\varepsilon)=\emptyset\). Then \(L(N)=L(M)\). Therefore \(\mathbf{DFA}\subseteq\mathbf{NFA}\) as a class.
Concept
DFA §1.1NFA §1.2SIPSER THEOREM 1.39
▶

DFA ⊆ NFA ⊆ (same expressive power): Every DFA is an NFA. Conversely, every NFA has an equivalent DFA (subset construction, Sipser Theorem 1.39). So DFAs and NFAs recognize exactly the same class — the regular languages.

Key difference: NFAs are more convenient to design (can guess, branch, use \(\varepsilon\)-moves), but not more powerful. DFAs can be exponentially larger than equivalent NFAs (up to \(2^{|Q_{NFA}|}\) states).

Every n ≥ 20 = 5a + 6b
STRONG INDUCTION · NUMBER THEORY · BASE CASES
▶
Problem
Prove that every integer \(n \geq 20\) can be written in the form \(n = 5a + 6b\) where \(a, b\) are non-negative integers.
—
Full induction proof with explicit base cases.
Proof by Strong Induction
Strategy
5 base casesreduce n to n−5 via strong IH
▶
Establish 5 consecutive base cases \(n=20,21,22,23,24\). For \(n\geq 25\), note \(n-5\geq 20\), so by the inductive hypothesis \(n-5=5a+6b\), giving \(n=5(a+1)+6b\). Since \(a+1\geq 1\geq 0\) and \(b\geq 0\), the representation is valid.
We need 5 consecutive base cases because we subtract 5 in the inductive step — we must cover all residues mod 5.
1
Base Cases: n = 20, 21, 22, 23, 24
\[ \begin{aligned} 20 &= 5(4) + 6(0) & &\checkmark\\ 21 &= 5(3) + 6(1) & &\checkmark\\ 22 &= 5(2) + 6(2) & &\checkmark\\ 23 &= 5(1) + 6(3) & &\checkmark\\ 24 &= 5(0) + 6(4) & &\checkmark \end{aligned} \]
All five cases verified with non-negative \(a, b\). ✓
2
Inductive Hypothesis (Strong)
Assume for some \(n \geq 24\) that every integer \(m\) with \(20 \leq m \leq n\) can be written as \(5a+6b\) with \(a,b\geq 0\). We prove it for \(n+1\).
3
Inductive Step: prove for n+1 ≥ 25
Since \(n+1\geq 25\), we have \((n+1)-5 = n-4 \geq 20\). Also \(n-4\leq n\), so \(n-4\) is in the range \([20,n]\) covered by the inductive hypothesis. Therefore:
\[n-4 = 5a + 6b \quad\text{for some } a,b\geq 0\]
Adding 5 to both sides:
\[n+1 = (n-4)+5 = 5a+6b+5 = 5(a+1)+6b\]
Since \(a+1\geq 1\geq 0\) and \(b\geq 0\), this is a valid representation of \(n+1\). ✓
4
Conclusion
By strong induction, every integer \(n\geq 20\) can be written as \(5a+6b\) with \(a,b\geq 0\). \(\blacksquare\)
✓ Proved by Strong Induction Base cases \(n=20,\ldots,24\) verified directly. For \(n+1\geq 25\): apply IH to \(n-4\geq 20\) to get \(n-4=5a+6b\), then \(n+1=5(a+1)+6b\). \(\blacksquare\)
Why n ≥ 20? The values \(n = 1,\ldots,19\) include integers not representable as \(5a+6b\) with \(a,b\geq 0\) — e.g., \(1,2,3,4,7,8,9,13,14,19\) cannot be so written. 20 is the Frobenius number + 1 for the pair \((5,6)\): since \(\gcd(5,6)=1\), every sufficiently large integer is representable, and the largest non-representable integer is \(5\cdot 6 - 5 - 6 = 19\).
Concept
STRONG INDUCTIONFROBENIUS / COIN PROBLEM
▶

Strong induction: When proving \(P(n+1)\), you may assume \(P(k)\) for all \(k \leq n\) (not just \(P(n)\)). This is equivalent to weak induction but often easier. You need as many base cases as the "step back" in the inductive step.

Frobenius / Chicken McNugget Theorem: For coprime positive integers \(a,b\), the largest integer not representable as \(xa+yb\) (\(x,y\geq 0\)) is \(ab-a-b\). Here: \(5\cdot6-5-6=19\). So every integer \(\geq 20\) is representable.

NFA with ε → Equivalent DFA
ε-CLOSURE · SUBSET CONSTRUCTION · SIPSER §1.3
▶
Problem
Convert the NFA \(M=(Q,\Sigma,\delta,q_0,F)\) to an equivalent DFA via the subset construction.
—
\(Q=\{q_0,q_1,q_2\}\),\; \(\Sigma=\{a,b\}\),\; \(F=\{q_2\}\).
Transitions: \(\delta(q_0,a)=\{q_0\}\), \(\delta(q_0,b)=\{q_0\}\), \(\delta(q_0,\varepsilon)=\{q_1\}\), \(\delta(q_1,a)=\{q_2\}\), \(\delta(q_1,b)=\emptyset\), \(\delta(q_2,a)=\{q_2\}\), \(\delta(q_2,b)=\{q_2\}\).
Step 1 — Compute ε-Closures
Definition — ε-closure ▶
\(\varepsilon\text{-closure}(q)\) = set of all states reachable from \(q\) using zero or more \(\varepsilon\)-transitions.
\[\varepsilon\text{-closure}(R) = \bigcup_{q\in R}\varepsilon\text{-closure}(q) \quad\text{for a set }R\subseteq Q\]
1
ε-closures of individual states
\[ \begin{aligned} \varepsilon\text{-closure}(q_0) &= \{q_0, q_1\} \quad (q_0\xrightarrow{\varepsilon}q_1,\text{ no further }\varepsilon\text{-moves from }q_1)\\ \varepsilon\text{-closure}(q_1) &= \{q_1\} \quad\text{(no }\varepsilon\text{-moves from }q_1\text{)}\\ \varepsilon\text{-closure}(q_2) &= \{q_2\} \quad\text{(no }\varepsilon\text{-moves from }q_2\text{)} \end{aligned} \]
Step 2 — Subset Construction
1
DFA start state
\[Q'_0 = \varepsilon\text{-closure}(q_0) = \{q_0, q_1\}\]
This is the start state of the DFA — label it \(A = \{q_0,q_1\}\).
2
Transitions from A = {q₀, q₁}
\[ \begin{aligned} \delta'(A, a) &= \varepsilon\text{-closure}\!\bigl(\delta(q_0,a)\cup\delta(q_1,a)\bigr)\\ &= \varepsilon\text{-closure}(\{q_0\}\cup\{q_2\})\\ &= \varepsilon\text{-closure}(\{q_0,q_2\})\\ &= \{q_0,q_1\}\cup\{q_2\} = \{q_0,q_1,q_2\} \;\triangleq\; B\\[8pt] \delta'(A, b) &= \varepsilon\text{-closure}\!\bigl(\delta(q_0,b)\cup\delta(q_1,b)\bigr)\\ &= \varepsilon\text{-closure}(\{q_0\}\cup\emptyset)\\ &= \varepsilon\text{-closure}(\{q_0\}) = \{q_0,q_1\} = A \end{aligned} \]
3
Transitions from B = {q₀, q₁, q₂}
\[ \begin{aligned} \delta'(B, a) &= \varepsilon\text{-closure}\!\bigl(\delta(q_0,a)\cup\delta(q_1,a)\cup\delta(q_2,a)\bigr)\\ &= \varepsilon\text{-closure}(\{q_0\}\cup\{q_2\}\cup\{q_2\})\\ &= \varepsilon\text{-closure}(\{q_0,q_2\}) = \{q_0,q_1,q_2\} = B\\[8pt] \delta'(B, b) &= \varepsilon\text{-closure}\!\bigl(\delta(q_0,b)\cup\delta(q_1,b)\cup\delta(q_2,b)\bigr)\\ &= \varepsilon\text{-closure}(\{q_0\}\cup\emptyset\cup\{q_2\})\\ &= \varepsilon\text{-closure}(\{q_0,q_2\}) = \{q_0,q_1,q_2\} = B \end{aligned} \]
No new states. Construction complete.
4
DFA accepting states
A DFA state (subset) is accepting iff it contains an NFA accept state (\(q_2\)).
\(A = \{q_0,q_1\}\): does not contain \(q_2\) → non-accepting
\(B = \{q_0,q_1,q_2\}\): contains \(q_2\) → accepting

Step 5 — Language Recognized
1
What does the DFA accept?
The DFA starts in state \(A\) and moves to \(B\) the first time it reads an \(a\). Once in \(B\), all further \(a\)'s and \(b\)'s keep it in \(B\) (which is accepting). On \(b\) from \(A\), it stays in \(A\) (non-accepting).
2
Language characterization
\[L = \{w \in \{a,b\}^* \mid w \text{ contains at least one } a\}\]
Equivalently, \(L = \Sigma^* \setminus \{b^k \mid k\geq 0\}\). This makes sense: the NFA can non-deterministically go to \(q_1\) via \(\varepsilon\), then read an \(a\) to reach the accept state \(q_2\), staying there on any further input.
✓ Equivalent DFA States: \(\{A, B\}\) where \(A=\{q_0,q_1\}\), \(B=\{q_0,q_1,q_2\}\).
Start: \(A\). Accept: \(\{B\}\).
\(\delta'(A,a)=B,\;\delta'(A,b)=A,\;\delta'(B,a)=B,\;\delta'(B,b)=B\).
Language: all strings over \(\{a,b\}\) containing at least one \(a\).
Concept
SUBSET CONSTRUCTIONε-CLOSURESIPSER THEOREM 1.39
▶

Subset construction (Sipser Theorem 1.39): Given NFA with \(k\) states, the equivalent DFA has at most \(2^k\) states. Many are often unreachable — only trace reachable states from the start.

ε-closure rule: Always compute \(\varepsilon\text{-closure}\) AFTER applying the symbol transition. Formula: \(\delta'(R,a)=\varepsilon\text{-closure}\bigl(\bigcup_{r\in R}\delta(r,a)\bigr)\).

Accept states: A DFA subset-state is accepting iff it contains at least one NFA accept state.

Exam tip: Start from \(\varepsilon\text{-closure}(q_0)\), not from \(\{q_0\}\) alone. Missing the initial \(\varepsilon\)-closure is the most common mistake.
