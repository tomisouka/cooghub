Q1 Countability of All Finite Subsets of ℕ ▼
Show that the set of all finite subsets of the set of natural numbers ℕ = {0, 1, 2, …} is countably infinite.
Solution

Let ℱ denote the set of all finite subsets of ℕ. We must show |ℱ| = |ℕ|.

ℱ is infinite: For each n ∈ ℕ, the singleton {n} ∈ ℱ. The map n ↦ {n} is injective, so ℱ is infinite.

ℱ is countable — encoding argument: Define a function f : ℱ → ℕ by encoding each finite subset as a natural number using binary representation:

For S = {a₁ < a₂ < … < aₖ} ∈ ℱ, define: f(S) = 2^a₁ + 2^a₂ + … + 2^aₖ f(∅) = 0 Examples: f(∅) = 0 f({0}) = 1 f({1}) = 2 f({0,1}) = 3 f({2}) = 4 f({0,2}) = 5 ...

Since binary representations of natural numbers are unique, f is injective: distinct finite subsets map to distinct naturals. So ℱ injects into ℕ, giving |ℱ| ≤ |ℕ|.

Since ℱ is infinite and |ℱ| ≤ |ℕ|, we conclude ℱ is countably infinite. □

□
Q2 Uncountability of All Infinite Subsets of ℕ ▼
Show that the set of all infinite subsets of the set of natural numbers is uncountable.
Solution

Let ℐ denote the set of all infinite subsets of ℕ.

Key facts:

1. The power set 𝒫(ℕ) is uncountable by Cantor's theorem.

2. 𝒫(ℕ) = ℱ ∪ ℐ (every subset is either finite or infinite, and the sets are disjoint).

3. ℱ is countable by Q1.

Proof by contradiction: Suppose ℐ were countable. Then:

𝒫(ℕ) = ℱ ∪ ℐ = (countable) ∪ (countable) [by assumption] = countable [union of countables is countable]

But this contradicts the fact that 𝒫(ℕ) is uncountable. Therefore our assumption is false, and ℐ must be uncountable.

□
Q3 Erdős–Szekeres: Every n²+1 Sequence Has a Monotone Subsequence of n+1 ▼
Prove that every sequence of n² + 1 distinct natural numbers has either a descending subsequence of n + 1 numbers or an ascending subsequence of n + 1 numbers.
Solution — Pigeonhole Argument

Let a₁, a₂, …, a_{n²+1} be a sequence of n² + 1 distinct natural numbers.

Define: For each element aᵢ, let dᵢ = the length of the longest descending subsequence starting at aᵢ.

Assume for contradiction that there is no descending subsequence of length n+1 and no ascending subsequence of length n+1. Then dᵢ ≤ n for all i.

Each dᵢ ∈ {1, 2, …, n} (n possible values) There are n² + 1 elements → by Pigeonhole, two positions share the same dᵢ value: ∃ i < j such that dᵢ = dⱼ

Case analysis on aᵢ vs aⱼ (recall i < j):

Case 1: aᵢ > aⱼ. Then we can prepend aᵢ to the longest descending subsequence starting at aⱼ. This gives a descending subsequence starting at aᵢ of length dⱼ + 1 = dᵢ + 1 — contradicting dᵢ = dⱼ.

Case 2: aᵢ < aⱼ. Then aᵢ, aⱼ begins an ascending pair. By the same argument applied to ascending subsequences (define uᵢ = longest ascending from aᵢ), we derive a contradiction with uᵢ = uⱼ.

Since all cases lead to contradiction, our assumption is false. Therefore every such sequence has a descending subsequence of length n+1 or an ascending one of length n+1.

□
Q4 Is Every DFA Also an NFA? ▼
Is every DFA also an NFA? Justify your answer.
Solution

Yes — every DFA is a special case of an NFA.

Recall the definitions:

DFA M = (Q, Σ, δ, q₀, F) where δ: Q × Σ → Q NFA M = (Q, Σ, δ, q₀, F) where δ: Q × (Σ ∪ {ε}) → 𝒫(Q)

A DFA's transition function δ(q, a) = q' (exactly one next state) can be viewed as an NFA's transition function δ_NFA(q, a) = {q'} (a singleton set).

The NFA definition allows:

• Transitions to a set of states (DFA uses singleton sets) ✓

• ε-transitions (DFA simply has none — all ε-transitions go to ∅) ✓

Key Insight
Every DFA is an NFA where: (1) all transitions go to singleton sets {q'}, and (2) all ε-transitions are δ(q, ε) = ∅. The class of DFAs ⊂ class of NFAs.

Conversely, not every NFA is a DFA — NFAs may have multiple transitions or ε-transitions that DFAs cannot.

□
Q5 Every n ≥ 20 can be written as 5a + 6b ▼
Prove that every integer n ≥ 20 can be written in the form n = 5a + 6b, where a and b are non-negative integers.
Solution — Strong Induction

Base cases (establish n = 20 through 24):

n = 20: 5(4) + 6(0) = 20 ✓ n = 21: 5(3) + 6(1) = 21 ✓ n = 22: 5(2) + 6(2) = 22 ✓ n = 23: 5(1) + 6(3) = 23 ✓ n = 24: 5(0) + 6(4) = 24 ✓

Inductive Hypothesis: Assume every integer from 20 to k (for some k ≥ 24) can be written as 5a + 6b with a, b ≥ 0.

Inductive Step: Show k + 1 can also be written this way.

Since k ≥ 24: k + 1 ≥ 25 → k + 1 − 5 = k − 4 ≥ 20 By the inductive hypothesis applied to (k − 4): k − 4 = 5a + 6b for some a, b ≥ 0 Therefore: k + 1 = (k − 4) + 5 = 5a + 6b + 5 = 5(a+1) + 6b ✓ Since a + 1 ≥ 1 > 0 and b ≥ 0, both are non-negative.

By strong induction, every n ≥ 20 can be written as 5a + 6b.

□
