01
C = {aᵍ | q composite} — Non-regularity & C*
PUMPING LEMMA · KLEENE CLOSURE · NON-REGULAR
▶
Problem
Let \(C = \{a^q \mid q \text{ is composite}\} = \{a^4, a^6, a^8, a^9, a^{10}, \ldots\}\).
—
(i) Prove \(C\) is not regular. (ii) Compute \(C^*\).
Part (i) — C is not Regular
Strategy
pump into prime lengthBertrand's postulate
▶
Pick \(s = a^{(p+1)!}\) (composite, length exceeds \(p\)). Any pumped string is \(a^{(p+1)!+(i-1)\ell}\). Since the arithmetic progression \(\{(p+1)!+(i-1)\ell\}_{i\geq 0}\) with step \(\ell\leq p\) hits prime values (by Bertrand's postulate / Dirichlet's theorem), some pumped string has prime length, landing outside \(C\). Contradiction.
1
Assume C is regular with pumping length p
2
Choose pumping string
\[s = a^{(p+1)!}\]
\((p+1)! = (p+1)\cdot p \cdots 2\) is composite (divisible by 2 and \(> 2\)). So \(s\in C\). Also \(|s|=(p+1)!\geq p\). The number of \(a\)'s is \((p+1)! > p\). ✓
3
Decompose s = xyz with |xy| ≤ p, |y| ≥ 1
Since \(s\) is a string of all \(a\)'s: \(y = a^\ell\) for some \(1\leq \ell\leq p\). The pumped string at index \(i\) is:
\[xy^iz = a^{(p+1)!+(i-1)\ell}\]
4
Find i that gives a prime length — contradiction
For \(i=0\): length \(= (p+1)! - \ell\). Since \(2\leq\ell\leq p\), we have \(\ell\mid(p+1)!\) so \(\ell\mid((p+1)!-\ell)\), meaning \((p+1)!-\ell\) is composite — still in \(C\), no contradiction yet.

For general \(i\): the lengths form the arithmetic sequence \((p+1)!-\ell,\;(p+1)!,\;(p+1)!+\ell,\;(p+1)!+2\ell,\ldots\) By Dirichlet's theorem (primes in arithmetic progressions), since \(\gcd(\ell,\,(p+1)!-\ell)\) may equal 1 for suitable starting point, this sequence contains infinitely many primes. In particular some \(i\geq 0\) gives a prime length \(r\), so \(xy^iz = a^r \notin C\). This contradicts the Pumping Lemma (which requires ALL \(i\geq 0\) to stay in \(C\)). \(\blacksquare\)
✓ C is not regular Pumping \(s=a^{(p+1)!}\) with \(y=a^\ell\) (\(1\leq\ell\leq p\)) produces the arithmetic sequence \(a^{(p+1)!+(i-1)\ell}\). This sequence contains prime values of the exponent (Dirichlet), giving strings not in \(C\). Contradiction with the Pumping Lemma. \(\blacksquare\)
Part (ii) — Computing C*
1
C* = all concatenations of elements of C, plus ε
\(a^n \in C^*\) iff \(n\) can be expressed as a sum of composite numbers (with \(n=0\) giving \(\varepsilon\)).
2
Check small values systematically
Composites available: \(4, 6, 8, 9, 10, 12, \ldots\) Smallest is 4.
3
Which n are NOT achievable?
\(n=1,2,3\): too small (less than 4). ✗
\(n=4\): \(4\in C\). ✓
\(n=5\): \(5-4=1\) (not composite), \(5-6<0\). ✗
\(n=6\): \(6\in C\). ✓
\(n=7\): \(7-4=3\) ✗, \(7-6=1\) ✗. ✗
\(n=8\): \(4+4\). ✓
\(n=9\): \(9\in C\). ✓
\(n=10\): \(10\in C\) or \(4+6\). ✓
\(n=11\): \(11-4=7\) ✗, \(11-6=5\) ✗, \(11-8=3\) ✗, \(11-9=2\) ✗, \(11-10=1\) ✗. ✗
\(n=12\): \(4+8\) or \(6+6\). ✓
\(n=13\): \(4+9\). ✓
\(n\geq 12\): always reachable (since \(4,6\in C\) and every integer \(\geq 12\) is a non-negative integer combination of 4 and 6 — verify: \(12=3\cdot4\), \(13=4+9\), \(14=2\cdot4+6\), \(15=4+4+... \) wait \(15=6+9\), \(16=4\cdot4\), etc. In general for \(n\geq 12\): write \(n = 4k+r\) where \(r\in\{0,1,2,3\}\); absorb the remainder using 6's or 9's.)
4
Final characterization
\[C^* = \{\varepsilon\} \cup \{a^n \mid n\geq 4,\; n\notin\{5,7,11\}\}\]
Equivalently, the only non-reachable positive lengths are \(1, 2, 3, 5, 7, 11\).
✓ C* = {ε} ∪ {aⁿ | n ≥ 4, n ∉ {5,7,11}} \(C^* = \{\varepsilon,\, a^4,\, a^6,\, a^8,\, a^9,\, a^{10},\, a^{12},\, a^{13},\, a^{14},\, a^{15},\, \ldots\}\)
All \(a^n\) with \(n\geq 4\) except \(a^5, a^7, a^{11}\) are in \(C^*\). Note \(C^*\) is regular (it is co-finite over \(\{a\}^*\)).
Remarkable fact: \(C\) is not regular, but \(C^*\) is! A co-finite unary language (missing only finitely many lengths) is always regular — a DFA can hard-code the finite rejection set.
Concept
PUMPING LEMMA §1.3KLEENE CLOSURECO-FINITE = REGULAR
▶

Pumping Lemma (Sipser 1.70): For unary non-regular languages, pick a string whose pumped family hits "forbidden" lengths (primes, non-squares, etc.) via number theory.

Co-finite languages are regular: Any language missing only finitely many strings over \(\Sigma^*\) is regular — build a DFA that rejects exactly those finitely many lengths.

TM §3.1CROSS-OFF TECHNIQUEDECIDABLE
▶

Cross-off TM pattern: To compare counts of two groups, mark one from each per pass. The first to run out determines the comparison result. This gives a decider (always halts).

Always specify \(\Gamma\) and every transition: Missing transitions (even on \(\sqcup\)) are a common source of lost marks on exams.

Regular ⊊ Turing Decidable
CLASS INCLUSION · DFA SIMULATION · STRICT CONTAINMENT
▶
Problem
Prove every regular language is Turing decidable. Give one example of a Turing-decidable but non-regular language. What does this show about the two classes?
—
Proof + example + class diagram.
Proof — Every Regular Language is Turing Decidable
Definitions — DFA and Turing Decider ▶
A language \(L\) is regular iff a DFA \(M=(Q,\Sigma,\delta,q_0,F)\) accepts exactly \(L\).
A language is Turing decidable iff a TM halts on every input, accepting iff the input is in \(L\).
\[\text{Regular}\;\Rightarrow\;\exists\text{DFA}\;\Rightarrow\;\exists\text{TM simulating DFA (always halts)}\;\Rightarrow\;\text{Decidable}\]
1
Setup
Let \(L\) be regular. Then there exists DFA \(M=(Q,\Sigma,\delta,q_0,F)\) with \(L(M)=L\).
2
Construct TM T that simulates M
On input \(w = w_1 w_2\cdots w_n\):
(i) Set current state \(c \leftarrow q_0\).
(ii) For each \(w_i\), compute \(c \leftarrow \delta(c, w_i)\) and move head right.
(iii) When head reads \(\sqcup\): if \(c\in F\) then accept, else reject.
3
T always halts
\(T\) makes exactly \(|w|\) state transitions then halts. No looping. \(T\) is a decider. ✓
4
L(T) = L
\(T\) accepts \(w\) iff DFA simulation ends in \(F\) iff \(w\in L(M)=L\). So \(L(T)=L\). \(\blacksquare\)
✓ Every regular language is Turing decidable The TM \(T\) simulates the DFA step-by-step, then halts and accepts/rejects based on whether the final DFA state is accepting. \(T\) is a decider for \(L\). \(\blacksquare\)
Example and Class Relationship
1
Example: L_eq = {aⁿbⁿ | n ≥ 0}
2
L_eq is NOT regular
Pumping Lemma: take \(s = a^pb^p\). Any decomposition \(s=xyz\) with \(|xy|\leq p\) has \(y=a^k\) inside the \(a\)-block. Then \(xy^2z = a^{p+k}b^p\) with \(p+k\neq p\), so \(xy^2z\notin L_{eq}\). Contradiction. Not regular.
3
L_eq IS Turing decidable
The cross-off TM (Problem 2, modified to accept when \(m=n\) instead of \(m\neq n\)) decides \(L_{eq}\). It always halts.
4
Conclusion
\[\mathbf{REG} \subsetneq \mathbf{DECIDABLE}\]
The containment is proper: every regular language is decidable (proof above) but \(L_{eq}\) is decidable and not regular. Therefore the class of regular languages is a strict subset of the class of Turing-decidable languages.
✓ REG ⊊ DECIDABLE Regular \(\subseteq\) Decidable (every DFA is simulable by a halting TM). Strict because \(\{a^nb^n\}\) is decidable but not regular.
Concept
DECIDABILITY §3.3REG ⊊ CFL ⊊ DEC
▶

Hierarchy: \(\mathbf{REG}\subsetneq\mathbf{CFL}\subsetneq\mathbf{DECIDABLE}\subsetneq\mathbf{RECOGNIZABLE}\subsetneq\mathbf{ALL}\). Each class is strictly larger.

Simulation principle: Any restricted model (DFA, PDA) can be emulated by a TM, so its language class is contained in \(\mathbf{DECIDABLE}\). TMs can use unbounded memory, strictly extending expressive power.

Pumping Lemma: L = {aⁿbᵐ | n = m²}
PUMPING LEMMA · PERFECT SQUARE GAP · NON-REGULAR
▶
Problem
Prove \(L = \{a^n b^m \mid n = m^2,\; n,m\geq 1\}\) is not regular using the Pumping Lemma. Choose a string where the number of \(a\)'s exceeds the pumping length \(p\).
—
Full Pumping Lemma proof.
Proof — L is not Regular
Key Insight
pump in a-blockno perfect square between p² and (p+1)²
▶
Pumping adds \(k\) extra \(a\)'s to get \(a^{p^2+k}b^p\). For this to be in \(L\) we need \(p^2+k\) to be a perfect square. But \(p^2 < p^2+k \leq p^2+p < (p+1)^2\) — strictly between consecutive squares — so no perfect square exists in this range.
1
Assume L is regular with pumping length p
2
Choose pumping string
\[s = a^{p^2} b^p\]
We have \(n=p^2\), \(m=p\), \(n=p^2=m^2\) ✓ so \(s\in L\). Also \(|s|=p^2+p\geq p\) ✓. Number of \(a\)'s \(=p^2>p\) ✓ (as required).
3
Decomposition s = xyz with |xy| ≤ p, |y| ≥ 1
Since \(|xy|\leq p \leq p^2\), the substring \(xy\) lies entirely within the \(a^{p^2}\) block. So \(x=a^r\), \(y=a^k\) with \(k\geq 1\), \(r+k\leq p\), and \(z=a^{p^2-r-k}b^p\).
4
Pump with i = 2
\[xy^2z = a^{p^2+k}b^p\]
The Pumping Lemma requires \(xy^2z\in L\), meaning \(p^2+k\) must be a perfect square.
5
Perfect square gap — contradiction
\[p^2 \;<\; p^2 + k \;\leq\; p^2 + p \;<\; p^2 + 2p + 1 = (p+1)^2\]
The inequalities hold because \(1\leq k\leq p < 2p+1\). Therefore \(p^2+k\) lies strictly between \(p^2\) and \((p+1)^2\) — two consecutive perfect squares with no integers between them that are perfect squares. So \(p^2+k\) is not a perfect square, meaning \(xy^2z\notin L\). This contradicts the Pumping Lemma. \(\blacksquare\)
✓ L is not regular Take \(s=a^{p^2}b^p\in L\). Any valid decomposition gives \(y=a^k\) (\(1\leq k\leq p\)). Pumping yields \(a^{p^2+k}b^p\) where \(p^2 < p^2+k < (p+1)^2\), so \(p^2+k\) is not a perfect square and \(xy^2z\notin L\). Contradiction. \(\blacksquare\)
Concept
PUMPING LEMMA §1.3CONSECUTIVE SQUARE GAP
▶

Gap technique: Languages involving super-linear exponent relationships (squares, cubes, exponentials) are always non-regular. Pumping (linear) always lands in a "gap" between valid exponents.

Consecutive squares: \((n+1)^2 - n^2 = 2n+1\). For large \(n\) there is a gap of \(2n\) integers between \(n^2\) and \((n+1)^2\), none of which are perfect squares. This is the key arithmetic fact used above.

Checklist: (1) \(s\in L\)? (2) \(|s|\geq p\)? (3) Decomposition in the right block? (4) Pumped string exits \(L\)? Missing any loses credit.

05
Right Quotient L/a is Regular
CLOSURE · DFA MODIFICATION · QUOTIENT OPERATION
▶
Problem
Let \(L\) be a language over \(\Sigma\) and \(a\in\Sigma\). Define: \[L/a \;=\; \{\,w\in\Sigma^*\mid wa\in L\,\}\] Prove: if \(L\) is regular then \(L/a\) is regular.
—
Prove by constructing a DFA for \(L/a\) from a DFA for \(L\).
Proof — Constructing a DFA for L/a
Key Insight
same DFAnew accept statesone-step look-ahead
▶
\(w\in L/a\) iff \(wa\in L\) iff after reading \(w\) the DFA is in some state \(q\) such that reading one more \(a\) leads to an accept state. New accept set: \(F' = \{q\in Q \mid \delta(q,a)\in F\}\). No new states or transitions needed.
Extended transition notation ▶
Write \(\hat\delta(q,w)\) for the state reached from \(q\) after reading string \(w\):
\[\hat\delta(q,\varepsilon)=q,\qquad \hat\delta(q,ua)=\delta(\hat\delta(q,u),a)\]
1
Setup
Let \(M=(Q,\Sigma,\delta,q_0,F)\) be a DFA with \(L(M)=L\).
2
Define new DFA M' for L/a
\[M' = (Q,\;\Sigma,\;\delta,\;q_0,\;F') \quad\text{where}\quad F' = \{\,q\in Q \mid \delta(q,a)\in F\,\}\]
\(M'\) is identical to \(M\) except for the accepting set. Since \(F'\subseteq Q\) and all other components are unchanged, \(M'\) is a valid DFA.
3
Prove L(M') = L/a
\[ \begin{aligned} w \in L(M') &\iff \hat\delta(q_0,w)\in F'\\[4pt] &\iff \delta\!\bigl(\hat\delta(q_0,w),\,a\bigr)\in F \quad\text{(definition of }F'\text{)}\\[4pt] &\iff \hat\delta(q_0,\,wa)\in F \quad\text{(extended transition)}\\[4pt] &\iff wa\in L(M) = L\\[4pt] &\iff w\in L/a \end{aligned} \]
4
Conclusion
\(M'\) is a DFA with \(L(M')=L/a\). Therefore \(L/a\) is regular. \(\blacksquare\)
✓ L/a is regular Construct \(M'=(Q,\Sigma,\delta,q_0,F')\) where \(F'=\{q\in Q\mid\delta(q,a)\in F\}\). Then \(w\in L(M')\iff\hat\delta(q_0,w)\in F'\iff\hat\delta(q_0,wa)\in F\iff wa\in L\iff w\in L/a\). So \(M'\) is a DFA for \(L/a\), proving \(L/a\) is regular. \(\blacksquare\)
Intuition: \(L/a\) = "strings that need one more \(a\) to be in \(L\)." In the DFA this means: accept any state that is one \(a\)-transition away from a (former) accept state. No new infrastructure needed — just relabel the accept states.
Concept
QUOTIENT CLOSUREDFA MODIFICATIONSIPSER §1.2
▶

Regular languages are closed under right quotient: \(L/a\) is always regular when \(L\) is, achieved by a simple DFA modification (same states and transitions, new accept set).

General quotient: \(L/L' = \{w \mid \exists x\in L': wx\in L\}\) is also regular when \(L,L'\) are both regular. The proof unions the one-step quotient construction over all strings in \(L'\).

Exam pattern for closure proofs: (1) Name the DFA for the given regular language. (2) Describe the new machine explicitly. (3) Prove \(L(\text{new machine}) = \text{target}\) using a biconditional chain. \(\blacksquare\)
