   ┌─────────────────────────────────────────┐
   │  Linux Kernel:           ~15-20%        │ ██

   │  GNU Tools & Utilities:  ~25-30%        │ ███
   ├─────────────────────────────────────────┤
   │  X.org/Wayland (Display): ~10%          │ █
   ├─────────────────────────────────────────┤
   │  Desktop Environment:     ~15-20%       │ ██
   ├─────────────────────────────────────────┤
   │  Applications:            ~20-30%       │ ███
   ├─────────────────────────────────────────┤
   │  Libraries & Dependencies: ~10%         │ █
   └─────────────────────────────────────────┘

   ╔════════════════════════════════════════════════════════════╗
