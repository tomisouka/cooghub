# Stack vs Heap: Memory vs Data Structures

## Stack - Related ✅

**Stack Memory:** Call stack, local variables (LIFO)  
**Stack ADT:** LIFO collection (push/pop)

**Why same name:** Both use LIFO principle - makes sense!

---

## Heap - Unrelated ❌

**Heap Memory:** Dynamic memory allocation, unorganized pile  
**Heap Tree:** Ordered binary tree with heap property (min/max)
Just refer to it as Binary Heap

Binary Heap
    ├── Min-Heap (parent ≤ children)
    └── Max-Heap (parent ≥ children)

**Why same name:** Unfortunate coincidence - ZERO relation!

---

## Quick Reference

| Term | Memory | Data Structure | Related? |
|------|--------|---------------|----------|
| Stack | LIFO call stack | LIFO collection | ✅ YES |
| Heap | Random pile | Ordered tree | ❌ NO |

---

## Context Clues

- "allocate on the heap" → memory
- "call stack" → memory  
- "max heap" → data structure
- "push to stack" → usually data structure

---
