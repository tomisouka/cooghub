Q 01 Diagonalization
Medium-Hard12 pts
Concept Diagonalization — Sipser §4.2
Part (a) · Your Answer
"set up a natrice [matrix], pick a point, and reduce"
Formal Definition
Diagonalization Principle: Given a list \(s_1, s_2, s_3, \dots\) of infinite binary strings, construct \(t\) such that \(t_i \neq (s_i)_i\) for every \(i\). Then \(t\) is guaranteed not to appear anywhere in the list.
Informal
Look at diagonal entries (1st bit of \(s_1\), 2nd bit of \(s_2\), …). Flip each one. The result differs from every listed string at its diagonal position — so it can't be in the list.
✓
Answer (a)
The diagonalization principle constructs an element not in a given list by flipping diagonal entries — the new string differs from every listed string at at least one position.
Part (b) · Construction of \(t\)
Cantor's Diagonal Argument: \[t_i = \text{NOT}\big((s_i)_i\big) \quad \text{for all } i \in \mathbb{N}\]
StringPositionDiagonal bit\(t_i\) flipped
\(s_1 = 010101\ldots\)1st01
\(s_2 = 11001100\ldots\)2nd10
\(s_3 = 00000000\ldots\)3rd01
\(s_4 = 10101010\ldots\)4th10
✓
Answer (b)

\(t = 1010\ldots\)   For any \(s_i\), \(t\) differs at position \(i\) by construction, so \(t \neq s_i\) for all \(i\).

Q 02 Proof by Induction
Easy10 pts
ConceptMathematical Induction
Statement: \(\displaystyle\sum_{i=1}^{n}(2i-1)=n^2\) for all \(n\ge1\)   (i.e., \(1+3+5+\cdots+(2n-1)=n^2\))
Method
  1. Base case: Show \(P(1)\) is true.
  2. Inductive hypothesis: Assume \(P(k)\) is true for some \(k\ge1\).
  3. Inductive step: Prove \(P(k+1)\) using \(P(k)\).
Informal
Like dominoes — show the first falls, then show each domino knocks down the next.
Solution
(a) Base case \(n=1\): LHS \(=1\), RHS \(=1^2=1\) ✓

(b) Inductive hypothesis: Assume \(\sum_{i=1}^{k}(2i-1)=k^2\).

(c) Inductive step: \[\sum_{i=1}^{k+1}(2i-1)=k^2+(2(k+1)-1)=k^2+2k+1=(k+1)^2\]
✓
Answer

The formula \(\sum_{i=1}^{n}(2i-1)=n^2\) is proven true for all \(n\ge1\) by mathematical induction.

Q 03 Pigeonhole Principle
Easy8 pts
ConceptPigeonhole Principle
6 pairs of socks (6 colors, 2 each). Minimum draws to guarantee a matching pair?
Your Answer
"pigeonhole principle" — partial credit only
Formal Principle
If \(n\) items are placed into \(m\) containers and \(n>m\), at least one container has \(\ge2\) items. \[\text{Minimum to guarantee a duplicate}=m+1\]
Informal
First 6 draws could each be a different color. The 7th must repeat — like 7 pigeons into 6 holes.
✓
Answer

7 socks. Worst case: first 6 are all different colors. The 7th must match one.

Q 04 Sets and Cardinality
Medium9 pts
Concept Cardinality & Bijections — Sipser §0.4
\(E=\{0,2,4,6,\dots\}\) (even naturals) · \(F=\{0,4,8,12,\dots\}\) (multiples of 4)
Your Answer
"\(F\) is a subset of \(E\). \(E\) and \(F\) have the same [incomplete]"
Formal Definition
Cantor — Equal Cardinality: Two sets have the same cardinality iff there exists a bijection (one-to-one and onto) between them.
Informal
Infinite sets can be the same size as their proper subsets. Pair each \(2k\in E\) with \(4k\in F\) — a perfect matching.
Solution
Define \(f:E\to F\) by \(f(x)=2x\).
One-to-one: \(f(a)=f(b)\Rightarrow a=b\).
Onto: For \(y=4k\in F\), let \(x=2k\in E\); then \(f(x)=4k=y\).
✓
Answer

\(E\) and \(F\) have the same cardinality — both are countably infinite.

Q 05 Relations and Functions
Easy8 pts
ConceptRelations & Functions
\(S\) = set of students. Define a binary relation on \(S\) that is also a function, and justify.
Formal Definition
A relation \(R\subseteq S\times T\) is a function from \(S\) to \(T\) if for every \(x\in S\) there exists exactly one \(y\in T\) with \((x,y)\in R\).
Informal
A function gives each input exactly one output. "Student maps to their student ID" works — every student has exactly one ID.
✓
Answer

Let \(R=\{(x,y)\mid y\text{ is }x\text{'s assigned desk partner}\}\).

This is a function: every student has exactly one desk partner (existence + uniqueness).

Q 06 Equivalence Relations
Medium10 pts
Concept Equivalence Relations Modular Arithmetic
Set \(E=\{0,2,4,6,\dots\}\) · Relation: \(a\sim b\) iff \(a\equiv b\pmod{4}\)
Definition
  1. Reflexive: \(a\sim a\) for all \(a\)
  2. Symmetric: \(a\sim b\Rightarrow b\sim a\)
  3. Transitive: \(a\sim b\) and \(b\sim c\Rightarrow a\sim c\)
Informal
Groups even numbers by remainder mod 4. Like mutual friendship: reflexive, symmetric, transitive.
Verification
Reflexive: \(a-a=0\), divisible by 4 ✓
Symmetric: \(4\mid(a-b)\Rightarrow4\mid(b-a)\) ✓
Transitive: \(a-b=4k,\ b-c=4m\Rightarrow a-c=4(k+m)\) ✓
✓
Answer

\(a\sim b\) iff \(a\equiv b\pmod{4}\) is an equivalence relation on \(E\).

Classes: \([0]=\{0,4,8,\dots\}\) · \([2]=\{2,6,10,\dots\}\)

Q 07 Probability
Easy11 pts
ConceptDiscrete Probability
Fair coin \(P(H)=P(T)=\tfrac{1}{2}\) · fair six-sided die \(P(k)=\tfrac{1}{6}\)
Part (a) · At least one head in three tosses
Complement Rule: \(P(\text{at least one})=1-P(\text{none})\) \[P(\text{no heads})=\left(\tfrac{1}{2}\right)^3=\tfrac{1}{8}\]
"All tails" is \(\tfrac{1}{8}\), so "at least one head" is everything else.
✓
Answer (a)

\(P(\text{at least one head})=\dfrac{7}{8}\)

Part (b) · Even die AND tail
Multiplication Rule (independent): \(P(A\cap B)=P(A)\cdot P(B)\) \[P(\text{even})=\tfrac{1}{2},\quad P(\text{tail})=\tfrac{1}{2}\]
Die and coin are independent — multiply.
✓
Answer (b)

\(P(\text{even and tail})=\dfrac{1}{4}\)
