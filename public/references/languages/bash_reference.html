Syntax & Structure

Every Bash script begins with a shebang line telling the kernel which interpreter to use. Use #!/usr/bin/env bash for portability (finds bash in PATH regardless of install location).

#!/usr/bin/env bash # This is a comment set -euo pipefail # strict mode: exit on error, undefined vars, pipe fails echo "Hello, $USER" exit 0

String Operations

Quoting Rules

FormBehavior
'literal'No expansion at all — completely literal
"double"Expands $vars, $(cmd), $((expr)), and \ escapes
$'escape'ANSI-C quoting: interprets \n, \t, \xNN, etc.

Common String Patterns

str="Hello, World!" echo ${#str} # 13 (length) echo ${str:7} # World! (from index 7) echo ${str:7:5} # World (5 chars from index 7) echo ${str/World/Bash} # Hello, Bash! (replace first) echo ${str,,} # hello, world! (lowercase all) echo ${str^^} # HELLO, WORLD! (uppercase all) # Strip extension/prefix file="script.sh" echo ${file%.sh} # script (strip .sh suffix) echo ${file##*/} # script.sh (basename equivalent) # Check if empty [[ -z "$str" ]] && echo "empty" [[ -n "$str" ]] && echo "not empty"

Here Strings & Here Docs

# Here string — feed a string as stdin grep "foo" <<< "$myvar" # Here document — multiline stdin block cat <<EOF Line one Line two: $USER EOF # Here doc with no expansion (quoted delimiter) cat <<'EOF' No $expansion here EOF # Here doc with indentation stripping (tab only, use <<-) cat <<-EOF indented content tabs stripped EOF

Arrays & Associative Arrays

Indexed Arrays

fruits=("apple" "banana" "cherry") # declare + assign fruits[3]="date" # assign by index echo ${fruits[0]} # apple echo ${fruits[@]} # all elements (separate words) echo ${fruits[*]} # all elements (single word, avoid) echo ${#fruits[@]} # 3 (number of elements) echo ${!fruits[@]} # 0 1 2 (indices) fruits+=("elderberry") # append element unset fruits[1] # remove element at index 1 # Slice echo ${fruits[@]:1:2} # elements at index 1 and 2 # Loop over array for f in "${fruits[@]}"; do echo "$f" done # Safely copy array copy=("${fruits[@]}")

Associative Arrays (dicts)

declare -A colors # must declare explicitly colors[red]="#ff0000" colors[green]="#00ff00" colors["blue"]="#0000ff" echo ${colors[red]} # #ff0000 echo ${!colors[@]} # all keys echo ${colors[@]} # all values echo ${#colors[@]} # number of entries unset colors[red] # remove key # Loop for key in "${!colors[@]}"; do echo "$key = ${colors[$key]}" done
Note: Always quote array expansions: "${arr[@]}" preserves elements with spaces. ${arr[*]} joins everything into one word — usually not what you want.

Arithmetic

Bash arithmetic is integer-only. For floats, use bc, awk, or python3.

Arithmetic Expansion & Evaluation

SyntaxUse
$(( expr ))Arithmetic expansion — returns result as string
(( expr ))Arithmetic evaluation — sets exit code (0 if non-zero result)
let "expr"Evaluate arithmetic expression (avoid; prefer ((…)))
expr a + bExternal expr command — slow, avoid in scripts

FlagTrue when…
-e filefile exists (any type)
-f filefile is a regular file
-d filefile is a directory
-L filefile is a symlink

Loops

# for-in loop for item in one two three; do echo "$item" done # C-style for for (( i=0; i<5; i++ )); do echo "$i" done # Loop over array for f in "${arr[@]}"; do echo "$f"; done # Loop over files for f in /etc/*.conf; do [[ -f "$f" ]] && echo "$f" done # Loop over lines of a file while IFS= read -r line; do echo "$line" done < input.txt # Loop over command output while IFS= read -r line; do echo "$line" done < <(find . -name "*.sh") # until loop (opposite of while) until [[ "$done" == "yes" ]]; do do_work done # Loop control break # exit loop continue # skip to next iteration break 2 # break out of 2 nested loops

Functions

# Declaration (two equivalent syntaxes) greet() { local name="$1" # local scope echo "Hello, $name" return 0 # explicit exit code } function greet { … } # alternate syntax (avoid — less portable) # Call greet "World" # Capture output result=$(greet "World") # Return value via stdout (best practice) add() { echo $(( $1 + $2 )); } sum=$(add 3 4) # sum=7 # Return code only (for boolean checks) is_even() { (( $1 % 2 == 0 )); } is_even 4 && echo "even" # Named references (Bash 4.3+) fill_array() { local -n arr_ref=$1 # nameref to caller's array arr_ref=(a b c) } fill_array myarr echo "${myarr[@]}" # a b c

Regex & Pattern Matching

Bash supports extended regular expressions (ERE) in [[ =~ ]]. Matches populate the $BASH_REMATCH array.

str="user@example.com" if [[ "$str" =~ ^([^@]+)@(.+)$ ]]; then echo "user: ${BASH_REMATCH[1]}" # user echo "domain: ${BASH_REMATCH[2]}" # example.com fi # Validate integer [[ "$n" =~ ^-?[0-9]+$ ]] && echo "is integer" # Match version number [[ "$ver" =~ ^([0-9]+)\.([0-9]+) ]] major=${BASH_REMATCH[1]} minor=${BASH_REMATCH[2]}

Scripting Best Practices

Script Template

#!/usr/bin/env bash set -euo pipefail IFS=$'\n\t' # safer word splitting readonly SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)" readonly SCRIPT_NAME="$(basename "$0")" usage() { cat <<EOF Usage: $SCRIPT_NAME [OPTIONS] arg1 arg2 Options: -h, --help Show this help -v, --verbose Verbose output -o FILE Output file EOF exit 0 } die() { echo "[ERROR] $*" >&2 exit 1 } log() { echo "[$(date '+%H:%M:%S')] $*" >&2 } main() { local verbose=false local output="" while [[ $# -gt 0 ]]; do case "$1" in -h|--help) usage ;; -v|--verbose) verbose=true; shift ;; -o) output="$2"; shift 2 ;; --) shift; break ;; -*) die "Unknown option: $1" ;; *) break ;; esac done [[ $# -lt 1 ]] && die "Missing required argument" local arg1="$1" log "Starting with arg: $arg1" # main logic here } main "$@"

Argument Parsing with getopts

while getopts ":hvf:" opt; do case "$opt" in h) usage; exit 0 ;; v) VERBOSE=true ;; f) FILE="$OPTARG" ;; :) die "Option -$OPTARG requires an argument" ;; ?) die "Unknown option: -$OPTARG" ;; esac done shift $(( OPTIND - 1 )) # shift past parsed options

Temporary Files

tmpfile=$(mktemp) # create temp file tmpdir=$(mktemp -d) # create temp directory # Always clean up cleanup() { rm -rf "$tmpfile" "$tmpdir"; } trap cleanup EXIT # runs on exit, signal, or error

Tips & Gotchas

Common Mistakes

GotchaCorrect approach
x = 5 (spaces)x=5 — no spaces around = in assignment
if [ $x == 5 ]Use [[ "$x" == 5 ]] or (( x == 5 ))
Unquoted $varAlways quote: "$var" — unquoted splits on IFS and globs
for f in $(ls)Use for f in * or find — ls output breaks on spaces
Forgetting -r in readread -r — without it, backslashes are consumed
[ -z $var ][[ -z "$var" ]] — unquoted breaks on empty
Using == in [ ]Use = in [ ]; == works in [[ ]]
Forgetting set -o pipefailWithout it, cmd | false exits 0
Modifying loop var in subshellPipes create subshells — vars set inside don't propagate
[ $a == $b ] with empty varBecomes [ == $b ] — always quote vars in tests

Useful Idioms

# Default value : "${VAR:=default}" # set VAR to default if unset # Require variable : "${REQUIRED_VAR:?Variable REQUIRED_VAR must be set}" # Script's own directory (robust) DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)" # Check if command exists command -v docker &> /dev/null || die "docker not installed" # Print to stderr echo "error message" >&2 # Discard output but check exit code if grep -q "pattern" file; then …; fi # Trim whitespace (Bash 4.0+) trimmed="${var#"${var%%[![:space:]]*}"}" trimmed="${trimmed%"${trimmed##*[![:space:]]}"}" # Join array with delimiter IFS=',' arr_str="${arr[*]}" # Read file into variable content=$(< file.txt) # faster than $(cat file.txt) # Parallel with max jobs for item in "${items[@]}"; do process "$item" & while (( $(jobs -r | wc -l) >= MAX_JOBS )); do sleep 0.1; done done wait
