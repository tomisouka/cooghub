Basics & Structure

Python uses indentation (4 spaces) to define blocks — no curly braces. It's interpreted, dynamically typed, and garbage-collected.

# Hello World print("Hello, World!") # Variables — no type declaration needed name = "Alice" age = 30 pi = 3.14159 # Multiple assignment x, y, z = 1, 2, 3 a = b = c = 0 # all point to same 0

Classes & OOP

Python supports full OOP. Everything is an object — classes are objects too. Default inheritance is from object.

class Animal: species = "Unknown" # class variable (shared) def __init__(self, name, age): self.name = name # instance variable self.age = age def speak(self): # instance method return "..." @classmethod def from_dict(cls, d): # class method — gets cls, not self return cls(d["name"], d["age"]) @staticmethod def is_mammal(cls_name): # static method — no cls or self return cls_name in ["Dog", "Cat"] def __repr__(self): # official string representation return f"Animal({self.name!r})" def __str__(self): # human-readable string return self.name class Dog(Animal): # inherits from Animal def __init__(self, name, age, breed): super().__init__(name, age) # call parent __init__ self.breed = breed def speak(self): # override parent method return "Woof!"

Collections

Python's four main built-in collection types: list, tuple, dict, set. Each has different mutability and ordering guarantees.

List — ordered, mutable, allows duplicates

lst = [1, 2, 3, "mixed", True] lst.append(4) # add to end lst.insert(1, 99) # insert at index lst.extend([5, 6]) # add multiple items lst.remove(99) # remove first occurrence of value lst.pop() # remove & return last item lst.pop(0) # remove & return by index lst.sort() # sort in-place lst.reverse() # reverse in-place lst.index(3) # find index of value lst.count(1) # count occurrences len(lst) # length lst[0] # first item lst[-1] # last item lst[1:4] # slice [start:stop:step] lst[::-1] # reversed copy

Tuple — ordered, immutable

t = (1, 2, 3) t = 1, 2, 3 # parens optional single = (42,) # comma needed for single-element tuple a, b, c = t # unpacking a, *rest = t # starred unpacking

Dict — key-value pairs, ordered (3.7+), mutable

d = {"name": "Alice", "age": 30} d["email"] = "a@b.com" # add/update d.get("missing", None) # safe get with default d.pop("age") # remove & return d.keys() # view of keys d.values() # view of values d.items() # view of (key, value) pairs d.update({"x": 1}) # merge another dict {**d, "extra": 99} # merge via unpacking (3.5+) d | {"new": 1} # merge operator (3.9+)

Set — unordered, unique values, mutable

s = {1, 2, 3} s.add(4) s.remove(1) # raises KeyError if missing s.discard(99) # safe remove s | {4, 5} # union s & {2, 3, 9} # intersection s - {2} # difference s ^ {2, 4, 5} # symmetric difference frozenset({1,2,3}) # immutable set

Comprehensions

Comprehensions are Python's concise, readable way to create collections from iterables. They're usually faster than equivalent loops.

List Comprehension

# [expression for item in iterable if condition] squares = [x**2 for x in range(10)] evens = [x for x in range(20) if x % 2 == 0] flat = [x for row in matrix for x in row] # nested pairs = [(x, y) for x in [1,2] for y in [3,4]]

Dict Comprehension

# {key: value for item in iterable if condition} squared_map = {x: x**2 for x in range(5)} flipped = {v: k for k, v in original.items()} filtered = {k: v for k, v in d.items() if v > 0}

Set Comprehension

# {expression for item in iterable if condition} unique_lengths = {len(word) for word in words}

Generator Expression

# (expression for item in iterable if condition) # Lazy — computes one item at a time, memory efficient gen = (x**2 for x in range(1_000_000)) # no list built! total = sum(x**2 for x in range(100)) # no parens needed here

Dict compbuild a dict{k: v for x in it}dict
Set compbuild a set{expr for x in it}set

Exceptions

Python uses EAFP style (Easier to Ask Forgiveness than Permission) — try it, catch errors. More Pythonic than checking conditions first.

try: result = 10 / x value = my_dict["key"] except ZeroDivisionError: print("Can't divide by zero") except KeyError as e: print(f"Missing key: {e}") except (TypeError, ValueError) as e: # multiple exceptions print(f"Type or Value error: {e}") except Exception as e: # catch-all (avoid if possible) print(f"Unexpected: {e}") raise # re-raise the same exception else: print("No exception occurred!") # runs only if no exception finally: print("Always runs — cleanup here") # always executes # Raising exceptions raise ValueError("x must be positive") raise RuntimeError("something went wrong") from original_err # chaining # Custom exception class MyError(Exception): def __init__(self, msg, code): super().__init__(msg) self.code = code

File I/O & Context Managers

Always use context managers (with) for files — they guarantee the file is closed even if an error occurs.

# Reading files with open("file.txt", "r", encoding="utf-8") as f: content = f.read() # entire file as string lines = f.readlines() # list of lines (with \n) line = f.readline() # one line at a time # Iterate line by line (memory efficient) with open("big.txt") as f: for line in f: process(line.strip()) # Writing files with open("out.txt", "w") as f: # "w" overwrites, "a" appends f.write("Hello\n") f.writelines(["line1\n", "line2\n"]) # File modes # "r" — read (default) # "w" — write (truncates file) # "a" — append # "rb" — read binary # "wb" — write binary # "r+" — read+write # pathlib (modern, preferred) from pathlib import Path p = Path("data") / "file.txt" # path joining with / p.read_text(encoding="utf-8") p.write_text("content") p.exists() p.stem # filename without extension p.suffix # ".txt" list(p.parent.glob("*.csv")) # glob patterns

Operator Precedence

Higher = evaluated first. Comparisons can be chained: 1 < x < 10. When in doubt, use parentheses.

  1. Parentheses: (expr), [expr], {expr}
  2. Subscript / call / attribute: x[i], f(), x.attr
  3. Exponentiation: ** (right-associative)
  4. Unary: +x, -x, ~x
  5. Multiplicative: *, /, //, %
  6. Additive: +, -
  7. Bitwise shift: <<, >>
  8. Bitwise AND: &
  9. Bitwise XOR: ^
  10. Bitwise OR: |
  11. Comparisons: ==, !=, <, >, <=, >=, is, is not, in, not in
  12. Boolean NOT: not x
  13. Boolean AND: and
  14. Boolean OR: or
  15. Walrus: :=
  16. Conditional: x if C else y (ternary)
  17. Lambda: lambda (lowest non-assignment)

Pro Tips

Common Pitfalls — Context Matters!

  • == vs isx == y compares values; x is y compares identity. Never write x is 5 — use == for values. Only use is for None, True, False.
  • Mutable defaultsNever use mutable objects as default args! def f(lst=[]) shares the same list across all calls. Use def f(lst=None): lst = lst or [] instead.
  • 7 / 2 vs 7 // 2Python 3: 7/2 == 3.5 always. Use // for integer division: 7//2 == 3.
  • list copyb = a makes b point to the same list. Use b = a[:] or b = a.copy() for shallow copy; import copy; copy.deepcopy(a) for deep.
  • String concatDon't build strings with + in a loop — it's O(n²). Use "".join(parts) instead.
  • except ExceptionCatch specific exceptions, not bare except: (catches SystemExit & KeyboardInterrupt). At worst use except Exception.
  • for i in rangeIf you just need values, use for x in lst:. Only use range(len(lst)) when you need the index — then prefer enumerate(lst).
  • global / nonlocalReading a variable from outer scope is fine. You only need global x or nonlocal x if you want to assign to the outer variable.
  • TruthinessFalsy: 0, 0.0, "", [], {}, set(), None, False. Everything else is truthy. Write if lst: not if len(lst) != 0:.
  • f-stringsPrefer f-strings over % or .format(). Faster, more readable: f"x = {x:.2f}". For debug: f"{x = }" (3.8+).
