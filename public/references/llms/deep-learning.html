01 — What is Deep Learning?

Machine Learning with many layers of abstraction

Deep Learning is a subset of Machine Learning where the model is a neural network with multiple hidden layers — "deep" means many layers, not profound. Each layer transforms its input into a progressively more abstract representation.

A shallow model (1 layer) can only learn simple linear patterns. Add layers, and the network can learn hierarchical features: a vision model's first layers detect edges, middle layers detect shapes, late layers detect faces or objects. This automatic feature learning is what replaced decades of hand-crafted feature engineering.

What changed between the 1980s (when the math existed) and 2012 (when it took off)? Three things: massive datasets (ImageNet, Common Crawl), GPU compute, and regularization tricks like dropout. The math was always there — the hardware and data weren't.

02 — Neurons & Layers

The artificial neuron — the basic unit

An artificial neuron loosely mimics the biological neuron. It takes multiple inputs, multiplies each by a learned weight, sums them, adds a bias, then passes the result through an activation function.

Mathematically: output = σ(Σ wᵢxᵢ + b)

Alone, a neuron is weak. Stack thousands per layer, stack dozens of layers — and the network can learn arbitrarily complex functions. The Universal Approximation Theorem proves that even a single hidden layer can approximate any continuous function given enough neurons. Depth makes this efficient in practice.

Why "deep"?

A network with 1 hidden layer is "shallow." Networks with 10, 50, 100+ hidden layers are "deep." Depth enables hierarchy — each layer builds on the previous layer's features rather than raw input.

03 — Backpropagation

How the network learns — error flowing backward

Backpropagation is the algorithm that makes deep learning trainable. After a forward pass produces a prediction, the error (loss) is computed. Backprop then uses the chain rule of calculus to compute the gradient of the loss with respect to every weight in the network — working backward from output to input.

These gradients tell us exactly how much each weight contributed to the error. Gradient descent then nudges every weight in the direction that reduces the loss. Repeat this millions of times across your dataset, and the network converges to weights that produce accurate predictions.

Key insight: the chain rule works perfectly through arbitrary depth. A 100-layer network can be trained with backprop just as easily as a 2-layer one — in theory. In practice, vanishing gradients (where gradients become tiny as they propagate backward) was the key obstacle that prevented deep networks from working until the 2010s.

04 — Activation Functions

The non-linearity that makes depth work

Without an activation function, stacking layers is pointless — multiplying linear transformations gives you a single linear transformation. Activation functions introduce non-linearity, enabling networks to learn curved, complex decision boundaries.

The history of activations tracks the history of deep learning itself. Sigmoid (1980s) squashes everything to 0–1 but kills gradients in deep networks. tanh improved on it. ReLU (2010) — just max(0, x) — is simple, fast, and solved vanishing gradients almost overnight. Modern networks use GELU (used in GPT/BERT) or SiLU/Swish.

06 — Training Dynamics

Watching a network learn over time

Training a deep network is an optimization problem: find the weights that minimize a loss function on the training data. The loss curve shows how this unfolds over training steps.

Overfitting is the central challenge: the model can memorize the training set perfectly but fail on new data. Signs: training loss keeps dropping while validation loss climbs. Solutions: dropout, weight decay, early stopping, more data, data augmentation.

Learning rate is the most critical hyperparameter — how big a step to take in weight-space each update. Too high: unstable, diverges. Too low: trains forever. Modern approaches use learning rate schedules (warmup + cosine decay) and adaptive optimizers like Adam.

The Bitter Lesson

Richard Sutton's 2019 essay: "General methods that leverage computation always win in the end." Every clever architectural trick eventually loses to simply scaling up a simpler approach with more data and compute. This is why LLMs work.

Optimizer
Adam
Adaptive Moment Estimation — the default optimizer for most deep learning. Adapts the learning rate per-parameter based on past gradients. Combines momentum + RMSprop. Almost always better than plain SGD for deep networks.
Regularization
Dropout
During training, randomly zero out a fraction (e.g. 20%) of neurons at each forward pass. Forces the network to learn redundant representations — no single neuron can be relied upon. Invented by Hinton (2012). Dramatically reduces overfitting.
Normalization
Batch Norm
Normalizes activations within each mini-batch to zero mean and unit variance. Stabilizes training, allows much higher learning rates, reduces sensitivity to initialization. Enabled reliably training networks with 50–100+ layers before Transformers.
07 — History

The long road to the current era

Deep learning went through two "AI winters" — periods where funding dried up and progress stalled. The field persisted through the work of a small group of researchers (Hinton, LeCun, Bengio — the "Godfathers of AI") who kept working on neural networks when most of academia had moved on.

The 2012 breakthrough wasn't an algorithm change — it was AlexNet showing that a deep CNN trained on GPUs could crush all other approaches on ImageNet by 10 percentage points. That single result changed everything and triggered the modern AI era.
