Sampling Distributions & CLT

Central Limit Theorem
For large n (n ≥ 30)X̄ ~ N(μ, σ²/n) z = (X̄ − μ) / (σ/√n)
Sampling dist of proportionp̂ ~ N(p, p(1−p)/n) z = (p̂ − p) / √(p(1−p)/n)
t-Distribution
Use when σ unknown, small nt = (X̄ − μ) / (s/√n) df = n − 1
df →∞t approaches Z (normal)
Heavier tailsmore uncertainty than Z

Hypothesis Testing Framework
1. State H₀ and Hₐ
2. Choose α (usually 0.05)
3. Compute test statistic
4. Find p-value
5. Reject H₀ if p-value < α

H₀: μ = μ₀  (or ≤, ≥)
Hₐ: μ ≠ μ₀  (two-tailed)
    μ > μ₀  (right-tailed)
    μ < μ₀  (left-tailed)
Type I errorα = P(reject H₀ | H₀ true)
Type II errorβ = P(fail to reject H₀ | H₀ false)
Power1 − β
