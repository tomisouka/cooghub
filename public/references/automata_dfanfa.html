Regular Languages & Regular Expressions

WHAT IS REGULAR · REGEX SYNTAX · IS / ISN'T REGULAR

regular
What is a Regular Language? recognized by a DFA · closed class
A language L is regular if and only if some DFA recognizes it. Equivalently, L is regular iff some NFA recognizes it, iff some regular expression describes it. These three characterizations are all equivalent — converting between them is exactly what GNFA / state ripping and subset construction do.
Is it regular? — quick guide

✓ Regular — a DFA can count / track it

  • All finite languages (any finite set of strings)
  • Strings ending in a fixed pattern — …01
  • Strings with an even number of 0s
  • Strings containing a fixed substring — …011…
  • Any language described by a regex

✗ Not Regular — needs unbounded memory

  • {0ⁿ1ⁿ | n ≥ 0} — equal counts, no finite bound
  • {ww | w ∈ Σ*} — must remember first half
  • {aⁿbⁿcⁿ | n ≥ 0} — three matched counts
  • Balanced parentheses
  • Any language requiring unbounded counting or matching
The test: if a DFA would need to remember an unbounded amount of information (an ever-growing counter, a matching of arbitrary depth), the language is not regular. Use the Pumping Lemma to prove it formally.

Key theorem (Kleene): A language is regular ↔ some regular expression describes it. The proof goes both ways: regex → NFA (Thompson's construction), DFA → regex (GNFA / state ripping).

Finite Automata

DFA · NFA · ε-CLOSURE · SUBSET CONSTRUCTION · EQUIVALENCE

regular
Deterministic Finite Automaton (DFA) 5-tuple · total function · no ε-moves
Definition
A DFA is a 5-tuple (Q, Σ, δ, q₀, F) where Q is a finite set of states, Σ is the input alphabet, δ: Q × Σ → Q is a total transition function (exactly one next state per symbol), q₀ ∈ Q is the start state, and F ⊆ Q is the set of accept states. A string w is accepted iff reading w from q₀ lands in F.
State diagram — accepts strings ending in "01" over {0,1}
DFA · 3 states · q₂ is the sole accept state · double ring = accept
Key property: Always halts after exactly |w| steps. For every (state, symbol) pair there is exactly one next state — no ambiguity, no guessing.
Nondeterministic Finite Automaton (NFA) ε-moves · 𝒫(Q) transitions · same power
Definition
An NFA is a 5-tuple (Q, Σ, δ, q₀, F) where δ: Q × Σ_ε → 𝒫(Q). Each transition now returns a set of states; zero or many choices are allowed. ε-transitions (no symbol consumed) are permitted. The machine accepts if at least one computation path ends in F. NFAs recognize exactly the same class of languages as DFAs — the regular languages.
State diagram — accepts strings over {0,1} containing "01" as a substring
NFA · 3 states · nondeterministic branch on 0 at q₀
ε-Closure algorithm
ε-Closure(S)all states reachable from S on ε alone
1result ← S; stack ← list(S)
2while stack not empty
3q ← stack.pop()
4for each r ∈ δ(q, ε): if r ∉ result → result.add(r); stack.push(r)
5return result
Union construction (ε-NFA visual)
New start state q_s with ε → q₀_A and ε → q₀_B
Exponential blowup: An n-state NFA may require up to 2ⁿ DFA states after subset construction. Same languages, potentially far fewer states in NFA form.

GNFA & State Ripping

GENERALIZED NFA · REGEX EDGES · DFA → REGEX CONVERSION

regex equiv
Generalized NFA (GNFA) transitions carry regular expressions
Definition
A GNFA is like an NFA but every transition is labeled with a regular expression instead of a single symbol. It has a unique start state with no incoming edges and a unique accept state with no outgoing edges (start ≠ accept). Every pair of states has exactly one edge label (∅ if no direct path). GNFAs are used to convert any DFA into an equivalent regular expression via state ripping.
State diagram — GNFA with regex-labeled edges
GNFA · dashed start state · double-ring accept · regex on every edge
The rip formula
When ripping state q_rip, for every remaining pair of states (qᵢ, qⱼ) where neither is q_rip, update the edge label:

R(qᵢ, qⱼ) ← R(qᵢ, qⱼ) ∪ R(qᵢ, q_rip) · R(q_rip, q_rip)* · R(q_rip, qⱼ)

In plain English: keep any direct path from qᵢ to qⱼ, plus any path that goes through q_rip — entering via R₁, looping on q_rip's self-loop zero or more times (R₂*), then exiting via R₃.
Before and after ripping q_rip
3 edges involving q_rip collapse into 1 merged label on qᵢ → qⱼ
DFA → Regex — step by step
Convert DFA to Regex via State Rippingresult = single regex on q_s → q_acc
1Add new start q_s with ε → q₀. Add new accept q_acc with ε ← each old accept state.
2Label each existing transition with its symbol as a regex. Fill ∅ for all missing pairs.
3while |Q| > 2 more than just q_s and q_acc remain
4Pick any q_rip ∉ {q_s, q_acc}
5for each pair (qᵢ, qⱼ) ≠ q_rip:
6R(qᵢ,qⱼ) ← R(qᵢ,qⱼ) ∪ R(qᵢ,q_rip) · R(q_rip,q_rip)* · R(q_rip,qⱼ)
7Remove q_rip and all its edges
8return R(q_s, q_acc) this single label IS the regex
Key theorem: A language is regular if and only if it is described by a regular expression. State ripping constructs the proof of the (→) direction.

Pumping Lemma & Non-Regularity Proofs

PROOF BY CONTRADICTION · ADVERSARIAL GAME · NON-REGULARITY · NON-CFL

proofs
Pumping Lemma — Regular Languages s = xyz · pigeonhole on states
Statement
If A is a regular language then there exists a pumping length p ≥ 1 such that every string s ∈ A with |s| ≥ p can be written as s = xyz satisfying three conditions:

(1) xyⁱz ∈ A for all i ≥ 0  ·  (2) |y| ≥ 1  ·  (3) |xy| ≤ p
Why it's true — visual (pigeonhole on states)
Path of length ≥ p through p states must repeat some state — that cycle is y
Proof template — proof by contradiction
Non-Regularity Proofadversarial game · you pick s, adversary picks split
1Assume A is regular. Let p be its pumping length (given by the lemma).
2Choose s ∈ A with |s| ≥ p. pick cleverly to force contradiction
3For all ways to write s = xyz with |y| ≥ 1 and |xy| ≤ p:
4Find some i ≥ 0 such that xyⁱz ∉ A. pump up or pump down
5This contradicts condition (1). Therefore A is not regular. □
Worked example — L = {0ⁿ1ⁿ | n ≥ 0}
Assume L is regular; let p be its pumping length. Choose s = 0ᵖ1ᵖ (length 2p ≥ p, so s ∈ L). Since |xy| ≤ p, both x and y lie entirely within the block of 0s. Write y = 0ᵏ (k ≥ 1). Pump up with i = 2: xy²z = 0^(p+k) 1ᵖ — now there are more 0s than 1s, so this string ∉ L. Contradiction. Therefore L is not regular. □
Remember: You must handle every valid split xyz (every choice the adversary could make), not just one. Condition (3) |xy| ≤ p is what forces y into a specific region — use it.
Pumping Lemma — Context-Free Languages s = uvxyz · parse tree · tall path
Statement
If A is a CFL then there exists a pumping length p such that every s ∈ A with |s| ≥ p can be written as s = uvxyz satisfying:

(1) uvⁱxyⁱz ∈ A for all i ≥ 0  ·  (2) |vy| ≥ 1  ·  (3) |vxy| ≤ p

Intuition: if a parse tree is tall enough, some variable must repeat on a root-to-leaf path. You can copy or delete that subtree (pumping v and y together) and stay in the language.
Classic non-CFL: L = {aⁿbⁿcⁿ | n ≥ 0}. Choose s = aᵖbᵖcᵖ. Any valid split forces v and y to land within at most two of the three blocks — pumping then unbalances at least one count. Contradiction.

GNFA & State Ripping

Generalized NFA · DFA → Regex

Generalized NFA (GNFA)

regex edges · unique start/accept
A GNFA is an NFA whose transitions are labeled with regular expressions. It has a unique start (no incoming edges) and a unique accept (no outgoing edges). Every pair of states has exactly one edge label (∅ if no path). Used to convert any DFA into a regular expression.
State diagram — GNFA
GNFA · dashed start · double-ring accept · regex on every edge
The rip formula
When ripping q_rip, for every remaining pair (qᵢ, qⱼ):

R(qᵢ,qⱼ) ← R(qᵢ,qⱼ) ∪ R(qᵢ,q_rip) · R(q_rip,q_rip)* · R(q_rip,qⱼ)

Keep direct path plus any path through q_rip (enter R₁, loop R₂*, exit R₃). Then delete q_rip. Repeat until only q_s and q_acc remain — the final edge label is the regex.
State Ripping — DFA to RegexO(k³) rips for k interior states
1Add q_s → q₀ (ε) and accepts → q_acc (ε). Fill ∅ for missing edges.
2while interior states remain:
3Pick q_rip. Update all (qᵢ,qⱼ) pairs using the rip formula.
4Delete q_rip and its edges.
5return R(q_s, q_acc)
Theorem: L is regular ↔ L is described by a regular expression. State ripping proves the (→) direction constructively.

Pumping Lemma & Proof by Contradiction

Regular · CFL · Non-regularity proofs

Pumping Lemma — Regular Languages

s = xyz · pigeonhole · contradiction
If A is regular, ∃ pumping length p s.t. every s ∈ A with |s|≥p can be written s = xyz: (1) xyⁱz ∈ A ∀i≥0 · (2) |y|≥1 · (3) |xy|≤p. Use to prove non-regularity by contradiction.
Pigeonhole visual — repeated state forces pumping
Path of length ≥ p must repeat a state → that cycle is y
Non-Regularity Proofproof by contradiction
1Assume A regular; p = pumping length.
2Choose s ∈ A with |s| ≥ p. # pick to force contradiction
3For all splits s=xyz with |y|≥1, |xy|≤p:
4Find i ≥ 0 s.t. xyⁱz ∉ A.
5Contradiction. A is not regular. □
Classic: L={0ⁿ1ⁿ}. s=0ᵖ1ᵖ. Since |xy|≤p, y=0ᵏ. Pump up: 0^(p+k)1ᵖ ∉ L. Contradiction.

Pumping Lemma — Context-Free Languages

s = uvxyz · parse tree
If A is CFL, ∃ pumping length p s.t. every s ∈ A with |s|≥p can be written s=uvxyz: (1) uvⁱxyⁱz ∈ A ∀i≥0 · (2) |vy|≥1 · (3) |vxy|≤p. Intuition: a repeated variable on a tall parse tree path can be pumped. Classic non-CFL: {aⁿbⁿcⁿ}.

operations on languages as sets of strings

GNFA & State Ripping

Generalized NFA · DFA → Regex

Generalized NFA (GNFA)

regex edges · unique start/accept
GNFA — NFA with transitions labeled by regular expressions. Unique start (no incoming) and unique accept (no outgoing). Every state pair has exactly one edge label (∅ if no path). Used to convert DFAs to regular expressions.
State ripping — the formula
When ripping q_rip, for every remaining pair (qᵢ, qⱼ):

R(qᵢ,qⱼ) ← R(qᵢ,qⱼ) ∪ R(qᵢ,q_rip) · R(q_rip,q_rip)* · R(q_rip,qⱼ)
Before & after ripping q_rip
3 edges through q_rip collapse into 1 merged label
State RippingO(k³) rips · result = single regex
1Add q_s →(ε) q₀ and each accept →(ε) q_acc. Fill ∅ for missing pairs.
2while interior states remain: pick q_rip, apply formula, remove q_rip.
3return R(q_s, q_acc)
Theorem: L is regular ↔ L is described by a regular expression. State ripping proves (→).

Pumping Lemma & Proof by Contradiction

Regular · CFL · Non-regularity

Pumping Lemma — Regular Languages

s = xyz · pigeonhole
If A is regular, ∃ pumping length p s.t. every s ∈ A with |s|≥p can be written s = xyz: (1) xyⁱz ∈ A ∀i≥0 · (2) |y|≥1 · (3) |xy|≤p.
Proof by contradiction — template
Non-Regularity Proofcontradiction · adversarial game
1Assume A regular; p = pumping length (given).
2Choose s ∈ A with |s| ≥ p. -- pick to force contradiction
3for all splits s=xyz with |y|≥1, |xy|≤p:
4find i ≥ 0: xyⁱz ∉ A. -- pump up or down
5Contradiction → A not regular. □
Classic: L={0ⁿ1ⁿ}. s=0ᵖ1ᵖ. |xy|≤p → y=0ᵏ. xy²z = 0^(p+k)1ᵖ ∉ L. Contradiction.

Pumping Lemma — Context-Free Languages

s = uvxyz · parse tree
If A is CFL, ∃ p s.t. every s ∈ A with |s|≥p can be written s=uvxyz: (1) uvⁱxyⁱz ∈ A ∀i≥0 · (2) |vy|≥1 · (3) |vxy|≤p. Classic non-CFL: {aⁿbⁿcⁿ}.

Closure Properties

Regular · CFL · NFA constructions

NFA Constructions for Regular Languages

union · concatenation · star · intersection
Union — new start q_s with ε to both machines
New q_s with ε → q₀_A and ε → q₀_B. Accept states of both machines unchanged. Accepts if M_A or M_B accepts.
Concatenation — ε from F_A to q₀_B
Wire M_A's accept states to M_B's start via ε. F_A becomes non-accepting. Only F_B accepts. Machine accepts xy where x ∈ A, y ∈ B.
Kleene Star — new accept-start + loop-back ε
New q_s is start AND accept (handles ε). Add ε: q_s → q₀_A, and F_A → q₀_A (loop). Machine accepts zero or more strings from A concatenated.
Intersection — product DFA
States = Q_A × Q_B. Transition: δ((p,q),a) = (δ_A(p,a), δ_B(q,a)). Accept iff p ∈ F_A AND q ∈ F_B. For difference: accept iff p ∈ F_A AND q ∉ F_B.

✓ Regular — Closed Under

  • Union, Concatenation, Kleene Star
  • Complement (flip F in complete DFA)
  • Intersection (product DFA)
  • Difference A \ B = A ∩ B̄

CFL — NOT Closed Under

  • Intersection of two CFLs
  • Complement · Difference

CFL — Closed Under

  • Union, Concat, Star, ∩ with regular
