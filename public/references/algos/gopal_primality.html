Primality Checking

A natural number n > 1 is prime if divisible only by 1 and itself. A foundational problem in cryptography and number theory.
IsPrime — Naive (Algorithm 1)
IsPrime(n):
  for i = 2 to n−1:
    if i divides n:
      return False
  return True
TimeO(n) — checks every divisor
Worst caseWhen n is prime — loops n−2 times
Correctness✓ Faithful to definition
FastIsPrime — Improved (Algorithm 2)
FastIsPrime(n):
  for i = 2 to ⌊√n⌋:
    if i divides n:
      return False
  return True
TimeO(√n) — only check up to √n
Key insightIf n has factor >√n, there must be one ≤√n
vs IsPrimeMuch faster — √n vs n iterations
The Pseudo-Polynomial Trap (Gopal Section 1.6)
AlgorithmRuntime (in n)Input size b = ⌈log n⌉Runtime (in b)Class
IsPrime O(n) b bits O(2ᵇ) Exponential ✗
FastIsPrime O(√n) b bits O(2^(b/2)) Exponential ✗
⚠ These are pseudo-polynomial: polynomial in the value of n, but exponential in the size (number of bits). Efficient algorithms must be polynomial in input size. A true polynomial-time primality test (AKS) was only discovered in 2002.

1. Understand
Define input/output precisely. Study small cases. Understand constraints.
2. Design
Apply a design technique (D&C, DP, Greedy). Write pseudocode. Describe clearly.
3. Analyze
Prove correctness. Analyze time & space complexity. Implement efficiently.
