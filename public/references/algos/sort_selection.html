1 — The Idea
Divide the array into a sorted left region and unsorted right region. Each pass: scan the entire unsorted region to find the minimum, then swap it into the next sorted position. One swap per pass — never more.

Key Properties
Minimum Per Pass
Each pass scans the unsorted region, finds the minimum, and places it at the front. Exactly one swap (or zero) per pass.
find min → place
O(n) Swaps
At most n−1 swaps total. Good when write operations are expensive (e.g., writing to flash memory).
minimal writes
Unstable
The swap to place the minimum can jump over equal elements, breaking their relative order.
unstable ✗
No Early Exit
Always does n(n−1)/2 comparisons regardless of input. Even a sorted array takes O(n²).
no best case win
