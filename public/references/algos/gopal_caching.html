Caching & Demand Paging

Given a cache of size k and a sequence of page requests, minimize cache misses. LFD (Furthest-in-Future) is optimal — proved by exchange argument.
Problem Setup
Cache sizek slots
Cache hitPage already in cache — free
Cache missFetch page + evict one — costs 1
GoalMinimize total cache misses
Demand pagingPages fetched only when requested
Eviction Strategies
LFD ✓ OPTIMALEvict page used furthest in future
LRU (practical)Evict least recently used
FIFOEvict first-in, first-out
LFUEvict least frequently used
LFD is offline (needs future knowledge). LRU approximates it online.
Proof of LFD Optimality (Gopal Theorem 6.2) — Exchange Argument
Technique: Take any optimal algorithm OPT. Show it can be modified step-by-step to behave like LFD without increasing cost.

1. Let pᵢ be the first request where OPT and LFD differ. OPT evicts page u, LFD evicts page v (where v is requested further in future than u).
2. Create OPT* = OPT but evict v instead (like LFD). Show OPT* is also optimal:
   Phase 1: Before u is requested — OPT* mimics OPT. When u is requested, OPT incurs a fault, OPT* does not (saved one fault).
   Phase 2: When v is requested — OPT* incurs a fault, OPT does not (one extra fault).
   Phase 3: Caches re-synchronized, continue.

Net: OPT* has the same total faults as OPT. Repeat until OPT* = LFD. ∎
