Tree Traversals

Four ways to visit every node in a tree. Each produces a different order and serves a different purpose.

Traversal Rules
Preorder
Root → Left → Right
Use: copy tree, prefix expressions
Inorder
Left → Root → Right
Use: sorted output from BST
Postorder
Left → Right → Root
Use: delete tree, postfix expressions
Level-Order (BFS)
Level by level, left to right
Use: shortest path in tree, serialization
Complexity
All DFS traversalsO(n) time, O(h) space
Level-order (BFS)O(n) time, O(w) space
h = heightO(log n) balanced, O(n) skewed
w = max widthO(n/2) at last level
BST inorder trick: Inorder on a BST gives nodes in sorted (ascending) order. This is a common interview technique.
Pseudocode
// Preorder
preorder(node):
  if node is null: return
  visit(node)          // Root first
  preorder(node.left)
  preorder(node.right)

// Inorder
inorder(node):
  if node is null: return
  inorder(node.left)
  visit(node)          // Root middle
  inorder(node.right)

// Postorder
postorder(node):
  if node is null: return
  postorder(node.left)
  postorder(node.right)
  visit(node)          // Root last

// Level-order
levelOrder(root):
  queue ← [root]
  while queue:
    node ← queue.dequeue()
    visit(node)
    if node.left:  queue.enqueue(node.left)
    if node.right: queue.enqueue(node.right)
