Graph Algorithms · DFS

Depth-First Search

Go as deep as possible down one branch before backtracking to explore others.
Complexity
TimeO(V + E)
SpaceO(V) stack depth
Data structureStack (or recursion)
Shortest path?✗ Not guaranteed
Complete?✓ Finite graphs
Properties
Graph typeDirected or Undirected
Recursion depth⚠ Stack overflow risk
TraversalPre/In/Post-order
Cycle detection✓ Track back-edges
Topo sort✓ Post-order DFS
Algorithm Steps
  1. Push/call source node, mark visited
  2. Explore first unvisited neighbor (recurse/push)
  3. If no unvisited neighbors → backtrack
  4. Repeat until all reachable nodes visited

Connected components
Trace: Graph A→B,C / B→D,E / C→F
depth 0Avisit
depth 1Bvisit (first neighbor of A)
depth 2Dvisit (first neighbor of B)
depth 2Ebacktrack → visit next of B
depth 1Cbacktrack → visit next of A
depth 2Fvisit (first neighbor of C)
Order: A → B → D → E → C → F
Pseudocode (Recursive)
DFS(graph, node, visited):
  visited.add(node)
  process(node)

  for neighbor in graph[node]:
    if neighbor not in visited:
      DFS(graph, neighbor, visited)

// Iterative (explicit stack):
DFS_iter(graph, start):
  stack ← [start]
  visited ← {}
  while stack:
    node ← stack.pop()
    if node not in visited:
      visited.add(node)
      for neighbor in graph[node]:
        stack.push(neighbor)
