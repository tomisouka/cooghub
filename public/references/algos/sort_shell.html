Shell.

Generalized Insertion Sort · In-Place · Gap Sequence
best O(n log n)
average O(n^1.3) — gap dependent
worst O(n^1.5) typical
space O(1)
1 — The Idea
Insertion sort is slow because it only moves elements one step at a time — a small element near the end has to travel all the way left one step per pass. Shell sort fixes this by running insertion sort on widely-spaced subsequences first (large gap), then progressively narrowing the gap until it reaches 1 (a normal insertion sort). By then, elements are nearly in place and the final pass is fast.

Key Properties
Gap Sequence
The gap sequence determines performance. Common ones: Shell's (n/2), Knuth's (3^k−1)/2, Ciura's empirical sequence. No universally optimal sequence known.
gap → gap/2 → 1
Better Than Insertion
Avoids the O(n²) pathology of insertion sort. Elements move long distances early, so the final O(n) pass has little work left.
O(n^1.3) typical
Complex Complexity
Exact complexity depends on gap sequence and is unsolved for some sequences. Better than O(n²), worse than O(n log n) guaranteed.
gap-dependent
Used In
Some embedded systems and standard libraries (uClibc). Simple to implement, no recursion, O(1) space.
embedded, simple
