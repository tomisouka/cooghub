1 — The Idea
Think of sorting a hand of cards. Pick up one card at a time and slide it left until it's in the right position among cards you've already sorted. The left portion is always sorted. The right portion is untouched. Each step inserts one element into its correct position.

3 — Online Algorithm
Insertion sort is online — it can sort a stream of incoming elements without seeing them all first. Each new element gets inserted into the already-sorted prefix immediately.
Key Properties
Shifts Not Swaps
Moves elements by shifting rather than swapping. Fewer writes than bubble sort for the same number of comparisons.
shift → insert
Best in Class for Small n
Low overhead makes it faster than O(n log n) sorts for small arrays. Timsort uses insertion sort on subarrays of size ≤ 64.
fast for small n
Adaptive
Nearly-sorted input approaches O(n). Each element only shifts past elements larger than it — few shifts if mostly sorted.
O(n) nearly sorted
Stable + Online
Equal elements keep their order. Can process a stream — no need to see the full array before starting.
stable + online
