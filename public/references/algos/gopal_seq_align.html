Sequence Alignment

Find the best alignment of two strings s (length m) and t (length n). Foundational in bioinformatics (DNA/protein comparison). DP: O(mn).
Complexity
TimeO(mn)
SpaceO(mn) table, O(min(m,n)) optimized
SubproblemsO(mn) — all (i,j) pairs
Brute forceO(2ⁿ) — exponential gap insertions
Scoring
Match (same char)+1 (or score[x,x])
Mismatch (diff chars)0 (or score[x,y])
Gap (char vs space)-1
Goal: maximize total alignment score (similarity).
Example — s=GACGGATTAG, t=GATCGGAATAG
s = GA_CGGATTAG
t = GATCGGAATAG
Score: 1+1-1+1+1+1+1+0+1+1+1 = 8  (best alignment)
Recurrence — sim(s[1..i], t[1..j])
Base cases:
  sim(s[1..i], "")  = -i     (align all of s with gaps)
  sim("", t[1..j])  = -j     (align all of t with gaps)
  sim("", "")       = 0

Recursive case (three choices for last character):
  sim(i, j) = max(
    score[s[i], t[j]] + sim(i-1, j-1),   // align s[i] with t[j]
    -1 + sim(i-1, j),                      // gap in t (skip s[i])
    -1 + sim(i, j-1)                       // gap in s (skip t[j])
  )
DP Table (Bottom-Up)
Fill a (m+1) × (n+1) table row by row (or column by column).
Base row/column: sim(i,0) = -i, sim(0,j) = -j.
Each cell computed in O(1) from neighbors.
Traceback from sim(m,n) to reconstruct alignment.
