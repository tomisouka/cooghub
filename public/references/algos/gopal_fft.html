FFT & DFT

Fast Fourier Transform: evaluate a degree n−1 polynomial at n special points in O(n log n) using roots of unity. Enables O(n log n) polynomial multiplication.

Why FFT Enables O(n log n) Polynomial Multiplication
Step 1 — Evaluate (Coefficient → Point-Value)
Use FFT to evaluate A(x) and B(x) at n roots of unity. Cost: O(n log n) each.
Step 2 — Multiply Point-Wise
C(xᵢ) = A(xᵢ)·B(xᵢ) for each point. Cost: O(n) — just n multiplications.
Step 3 — Interpolate (Point-Value → Coefficient)
Use inverse FFT to recover coefficient vector of C. Cost: O(n log n).
Total: O(n log n) + O(n) + O(n log n) = O(n log n)
Key Idea — Why Roots of Unity?
Split A(x) into even/odd coefficients:
A[0](x) = a₀ + a₂x + a₄x² + ...
A[1](x) = a₁ + a₃x + a₅x² + ...

Then: A(x) = A[0](x²) + x·A[1](x²)

If evaluation points come in ± pairs (±x₀, ±x₁,...), then A(x₀) and A(−x₀) both need A[0](x₀²) and A[1](x₀²) — we compute them once. This halves the work each level → O(n log n) total.
nth Roots of Unity
The n complex nth roots of unity are:
ωₙ = e^(2πi/n) (principal root)
Others: ωₙ⁰, ωₙ¹, ωₙ², ..., ωₙⁿ⁻¹

Key property: They come in ±pairs.
ωₙ^(k+n/2) = −ωₙᵏ

Squaring n nth roots → n/2 distinct (n/2)th roots. The ± pairing persists at every level of recursion.
DFT Definition & FFT Algorithm (Gopal Algorithm 21)
// DFT: y = DFT_n(a) where y[k] = A(ωₙᵏ) = Σ a[j]·ωₙᵏʲ  (j=0..n-1)

FFT(a):      // a = coefficient vector, n = len(a) must be power of 2
  if n == 1: return a

  a_even = [a[0], a[2], a[4], ...]    // even-indexed coefficients
  a_odd  = [a[1], a[3], a[5], ...]    // odd-indexed coefficients

  y_even = FFT(a_even)              // DFT_{n/2} of even part
  y_odd  = FFT(a_odd)               // DFT_{n/2} of odd part

  w = e^(2πi/n)                        // principal nth root of unity
  for k = 0 to n/2 - 1:
    y[k]       = y_even[k] + w^k · y_odd[k]
    y[k + n/2] = y_even[k] - w^k · y_odd[k]   // ± pair property

  return y
Interpolation (Inverse FFT)
Given point-values at roots of unity, recover coefficients. The inverse DFT uses ωₙ⁻¹ = e^(−2πi/n) as principal root, then divides by n: 
InverseFFT(y):
  a = FFT(y, w = e^(-2πi/n))   // same FFT, conjugate root
  return [x/n for x in a]        // divide every element by n
Works because V_n · V_n* = n·I (Vandermonde matrix is orthogonal up to scaling). So V_n⁻¹ = V_n*/n.
