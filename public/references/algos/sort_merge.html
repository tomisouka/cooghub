1 — The Idea
Split the array in half recursively until every piece is size 1 (trivially sorted). Then merge sorted pieces back together — comparing front elements and taking the smaller one each time. The work is entirely in the merge step.

3 — The Merge Step
Merging two sorted arrays: use two pointers — one per array. Compare front elements, take the smaller, advance that pointer. When one array is exhausted copy the rest of the other.

Key Properties
Guaranteed O(n log n)
Best, average, and worst case are all O(n log n). Input order has no effect. The only major sort with this guarantee.
always O(n log n)
Stable
Equal elements from the left subarray are always taken before the right, preserving original relative order.
stable ✓
O(n) Extra Space
Needs a temporary array for merging. Can't merge in-place efficiently. The main tradeoff vs. quicksort.
O(n) space
Great for Linked Lists
Linked lists can be merged in O(1) extra space by relinking nodes. No random access needed — no index math.
ideal for lists
