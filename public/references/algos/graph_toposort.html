Topological Sort

Order nodes of a DAG so every directed edge u→v has u before v. Models dependencies.
Complexity
TimeO(V + E)
SpaceO(V)
Graph typeDAG only (directed, acyclic)
Unique order?Not always — multiple valid
Cycle → no solution✗ Only works on DAGs
Two Approaches
Kahn's (BFS)Track in-degrees, add 0s
DFS Post-orderPush to stack on finish
Both are O(V+E). Kahn's also detects cycles (if output length < V, cycle exists).

Kahn's Algorithm (BFS)
  1. Compute in-degree for every node
  2. Enqueue all nodes with in-degree 0
  3. Dequeue node → add to result
  4. Reduce in-degree of neighbors; if 0, enqueue
  5. If result length < V → cycle detected

Pseudocode — Kahn's
TopologicalSort(graph):
  indegree ← {v: 0 for v in graph}
  for u in graph:
    for v in graph[u]: indegree[v]++

  queue ← [v for v if indegree[v] == 0]
  result ← []

  while queue:
    u ← queue.dequeue()
    result.append(u)
    for v in graph[u]:
      indegree[v]--
      if indegree[v] == 0: queue.enqueue(v)

  if len(result) < V: raise CycleError()
  return result
