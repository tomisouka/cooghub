RAM Model of Computation

The theoretical machine we use to analyze algorithm runtime. Single processor, sequential, unit-cost memory access.
RAM Model — 4 Key Features
  • A computing unit (processor) plus unlimited memory
  • Instructions execute sequentially — one at a time, in program order
  • Accessing any memory cell takes one step — regardless of location (hence "random access")
  • Any simple operation (add, compare, assign) takes one step
What We Count
We usually only bound the costly operations — those that dominate runtime.

For example:
• Sorting → count comparisons
• Graph algorithms → count edge traversals
• Number algorithms → count arithmetic ops

Bounding costly ops bounds total runtime up to a constant factor.
Input Size vs Input Value — Critical Distinction
Complexity is a function of input size (number of bits), NOT input value.

RAM vs Real Machines
ProcessorsRAM = 1 processor. Real = multiple (parallel).
Word sizeBasic arithmetic on ≤64-bit ints = O(1). n-bit numbers can take O(n) steps.
MemoryRAM assumes unlimited cells, each accessed in O(1)
