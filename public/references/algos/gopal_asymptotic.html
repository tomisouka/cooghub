Asymptotic Notation

Big-O, Big-Ω, Big-Θ, little-o, little-ω — the language of algorithm analysis. We care about growth rate, not constants.
The Five Notations
Big-O — Upper Bound
f(n) = O(g(n)) if f(n) ≤ c·g(n) for all n ≥ n₀
Limit: lim f(n)/g(n) < ∞
Big-Ω — Lower Bound
f(n) = Ω(g(n)) if f(n) ≥ c·g(n) for all n ≥ n₀
Limit: lim f(n)/g(n) > 0
Big-Θ — Tight Bound
f(n) = Θ(g(n)) if c₁g(n) ≤ f(n) ≤ c₂g(n)
Limit: 0 < lim f(n)/g(n) < ∞
little-o — Strictly Slower
f(n) = o(g(n)) if for ALL c > 0, f(n) < c·g(n)
Limit: lim f(n)/g(n) = 0
little-ω — Strictly Faster
f(n) = ω(g(n)) if for ALL c > 0, f(n) > c·g(n)
Limit: lim f(n)/g(n) = ∞

Comparing Functions — Limit Trick
// To compare f(n) and g(n), compute lim f(n)/g(n):
//
//   limit = 0    →  f = o(g)   (f strictly slower)
//   limit = c>0  →  f = Θ(g)  (same order)
//   limit = ∞    →  f = ω(g)  (f strictly faster)
//   limit ≤ c    →  f = O(g)  (f at most as fast)
//   limit ≥ c    →  f = Ω(g)  (f at least as fast)
//
// L'Hôpital: if lim f/g → ∞/∞ or 0/0, take derivatives
//   lim f(n)/g(n) = lim f'(n)/g'(n)
//
// Log trick: if log f(n) ≤ c·log g(n), then f(n) = O(g(n)ᶜ)
