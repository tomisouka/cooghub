Recurrences & Master Theorem

Two techniques: Guess-and-Verify (induction) and the DC Recurrence Theorem (Master Theorem). Solve T(n) = aT(n/b) + f(n).
DC Recurrence Theorem (Gopal Theorem 3.5)
T(n) = aT(n/b) + f(n)
Where a ≥ 1, b > 1, and af(n/b) = c·f(n):
c < 1 (leaves dominate)T(n) = Θ(f(n))
c > 1 (top level dominates)T(n) = Θ(n^log_b(a))
c = 1 (all levels equal)T(n) = Θ(f(n) · log n)

Guess-and-Verify Method
1. Guess the solution form: T(n) = O(f(n))
2. Plug into induction: assume T(k) ≤ ck for k < n
3. Show T(n) ≤ cn using the recurrence
4. If it doesn't work: strengthen the guess (e.g., T(n) ≤ cn − b) 
// Example: T(n) = 2T(n/2) + n
Guess: T(n) = O(n log n), show T(n) ≤ cn log n
By hypothesis: T(n/2) ≤ c(n/2)log(n/2)
T(n) ≤ 2·c(n/2)log(n/2) + n
     = cn·log(n/2) + n
     = cn log n - cn + n ≤ cn log n  (if c ≥ 1) ✓
Change of Variables Technique
When recurrence doesn't fit standard form, substitute to transform it. 
// Example: T(n) = 2T(√n) + 1
Let m = log n → n = 2^m
T(2^m) = 2T(2^(m/2)) + 1
Let S(m) = T(2^m):
S(m) = 2S(m/2) + 1
By DC Theorem: S(m) = O(m)
→ T(n) = T(2^m) = S(m) = O(log n)
Recursion Tree Visualization
The DC Recurrence Theorem is proved by drawing a recursion tree of depth L = log_b(n):

• Level 0: cost f(n)
• Level 1: a nodes, each cost f(n/b) → total af(n/b) = c·f(n)
• Level i: aⁱ nodes, each cost f(n/bⁱ) → total cⁱ·f(n)
• Level L (leaves): a^L = n^(log_b a) nodes, each O(1)

Total = f(n)·Σcⁱ. If c<1: geometric series converges → Θ(f(n)). If c>1: last term dominates → Θ(n^log_b a). If c=1: L+1 equal levels → Θ(f(n)·log n).
