Breadth-First Search

Explore all neighbors at the current depth before going deeper. Level by level.

Level-by-Level Traversal
Starting from node A, BFS visits all neighbors before going deeper:
Level 0: A
Level 1: B C D
Level 2: E F G
Queue: [ B, C, D ] → dequeue B → enqueue E, F → [ C, D, E, F ]

Algorithm Steps
  1. Start: enqueue source node, mark visited
  2. Dequeue front node → process it
  3. Enqueue all unvisited neighbors, mark visited
  4. Repeat until queue is empty

Pseudocode
BFS(graph, start):
  queue ← [start]
  visited ← {start}

  while queue not empty:
    node ← queue.dequeue()
    process(node)

    for neighbor in graph[node]:
      if neighbor not in visited:
        visited.add(neighbor)
        queue.enqueue(neighbor)
BFS vs DFS
BFS (Queue)
✓ Shortest path (unweighted)
✓ Level-order traversal
✗ More memory for wide graphs
✗ Slower for deep targets
DFS (Stack)
✓ Less memory (deep graphs)
✓ Cycle detection, topo sort
✗ No shortest path guarantee
✗ Can get lost in deep branches
