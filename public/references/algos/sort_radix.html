Non-Comparison Sort · Stable · Digit by Digit
time O(d × (n + k))
space O(n + k)
d = number of digits
k = digit range (10 for decimal)
1 — The Idea
Sort the numbers one digit at a time — least significant digit first (LSD). Each pass uses a stable sort (Counting Sort) on just that digit. Because each pass is stable, the order from previous passes is preserved. After d passes (one per digit), the array is fully sorted.

Key Properties
LSD First
Sort least significant digit first. After d passes of stable counting sort, the full number ordering is correct.
LSD → MSD
Linear for Fixed Width
For fixed-width integers (e.g. 32-bit), d is constant → O(n). Faster than O(n log n) in theory for large n.
O(n) fixed width
Stability Required
Each digit-pass must be stable. This is why Counting Sort is used as the subroutine — it's stable when done right-to-left.
needs stable sort
Works on Strings Too
Can sort strings of fixed length by sorting character by character. Used in suffix arrays and DNA sequence sorting.
strings + ints
