Dijkstra's Algorithm

Greedy shortest path from a source to all nodes. Always picks the nearest unvisited node.
Complexity
Time (basic)O(V²)
Time (min-heap)O((V+E) log V)
SpaceO(V)
Data structureMin priority queue
Negative weights?✗ Use Bellman-Ford
Algorithm Steps
  1. dist[src]=0, all others ∞; push src to PQ
  2. Pop node with minimum dist
  3. For each neighbor: if dist[u]+w < dist[v], update
  4. Push updated neighbors to PQ
  5. Repeat until PQ empty

Pseudocode
Dijkstra(graph, src):
  dist ← {node: ∞ for node in graph}
  dist[src] ← 0
  pq ← MinPQ([(0, src)])

  while pq not empty:
    (d, u) ← pq.pop_min()
    if d > dist[u]: continue  // stale entry

    for (v, weight) in graph[u]:
      if dist[u] + weight < dist[v]:
        dist[v] ← dist[u] + weight
        pq.push((dist[v], v))

  return dist
⚠ Limitation: Dijkstra fails with negative edge weights. A single negative edge can make the greedy "take the minimum" choice incorrect. Use Bellman-Ford for negative weights.
