Graph Algorithms · All-Pairs Shortest Path

Floyd-Warshall

All-pairs shortest paths using dynamic programming. Try every node as an intermediate.
Complexity
TimeO(V³)
SpaceO(V²)
Negative weights?✓ Yes
Negative cycles?✓ Detects (dist[i][i] < 0)
Single vs All pairsAll pairs
Core Recurrence
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
For each intermediate node k: can we shorten i→j by going through k?
Three nested loops over k (intermediate), i (source), j (destination). Order matters: k must be outermost.

Pseudocode
FloydWarshall(graph, V):
  dist ← V×V matrix initialized from adjacency matrix
  dist[i][i] ← 0 for all i

  for k in 0..V:             // intermediate node
    for i in 0..V:           // source
      for j in 0..V:         // destination
        if dist[i][k] + dist[k][j] < dist[i][j]:
          dist[i][j] ← dist[i][k] + dist[k][j]

  // Detect negative cycles
  for i in 0..V:
    if dist[i][i] < 0: return Error("Negative cycle")

  return dist
