          Pumping Lemma (Sipser Thm 1.70) If L is regular, ∃ p ≥ 1 (the pumping length) such that for every w ∈ L with |w| ≥ p, we can write w = xyz satisfying: (1) |y| ≥ 1, (2) |xy| ≤ p, (3) xyiz ∈ L for all i ≥ 0. To prove L is not regular: assume it is, pick w cleverly, show that every valid decomposition pumps out of L — contradiction.

          DFA & NFA — Theory

          Both models recognise exactly the regular languages, though NFAs are more concise to construct.

          Deterministic Finite Automaton

          A DFA is a 5-tuple (Q, Σ, δ, q₀, F):

          • Q — finite set of states
          • Σ — finite input alphabet
          • δ : Q × Σ → Q — total transition function
          • q₀ ∈ Q — unique start state
          • F ⊆ Q — set of accept states

          Every (state, symbol) pair has exactly one next state. Computation is fully deterministic.

          Nondeterministic Finite Automaton

          An NFA is a 5-tuple (Q, Σ, δ, q₀, F):

          • Q — finite set of states
          • Σ — finite input alphabet
          • δ : Q × Σε → 𝒫(Q) — transition relation
          • q₀ ∈ Q — start state
          • F ⊆ Q — set of accept states

          A state may have zero, one, or many transitions per symbol. Accepts if any branch reaches F.
