Programming Assignments
All in C or C++, submitted to Moodle. Assignments posted a month early — start early.
PA 1 · 10% Processes and Threads Due 2/16

Building process trees with fork() and creating multithreaded programs with POSIX pthreads. Expect parent-child process coordination and basic thread synchronization.

  • fork() — returns PID to parent, 0 to child, -1 on error
  • exec() family — replace process image
  • wait() / waitpid() — reap child processes
  • pthread_create / join — thread lifecycle
  • pthread_mutex — protect shared data between threads
PA 2 · 15% Interprocess Communication Due 3/30

Implementing communication between processes using the Unix IPC toolkit. Expect multiple IPC mechanisms — likely pipes + shared memory or message queues.

  • pipe() — anonymous pipes for parent-child comm
  • mkfifo() — named pipes for unrelated processes
  • shmget / shmat / shmdt — shared memory segments
  • msgget / msgsnd / msgrcv — message queues
  • Sockets — possibly TCP sockets for IPC
PA 3 · 15% Interprocess Synchronization Due 4/27

Classic synchronization problems implemented with semaphores, mutexes, and condition variables. Likely producer-consumer or readers-writers.

  • sem_init / sem_wait / sem_post / sem_destroy — POSIX semaphores
  • pthread_cond_wait / pthread_cond_signal — condition variables
  • Bounded buffer pattern — producer-consumer with semaphores
  • Deadlock avoidance — lock ordering, no circular wait
Essential Code Patterns
Memorize these — they show up in every PA
/* PA1 Pattern: fork() + exec() */
#include <unistd.h>
#include <sys/wait.h>

pid_t pid = fork();
if (pid == -1) { /* error */ }
else if (pid == 0) {
    /* child process */
    execl("/bin/ls", "ls", "-l", NULL);
} else {
    /* parent — wait for child */
    waitpid(pid, NULL, 0);
}
/* PA1 Pattern: POSIX thread + mutex */
#include <pthread.h>

pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER;
int shared = 0;

void* worker(void* arg) {
    pthread_mutex_lock(&lock);
    shared++;                        /* critical section */
    pthread_mutex_unlock(&lock);
    return NULL;
}

// In main:
pthread_t t;
pthread_create(&t, NULL, worker, NULL);
pthread_join(t, NULL);
/* PA2 Pattern: anonymous pipe */
int pipefd[2];
pipe(pipefd);  /* pipefd[0]=read end, pipefd[1]=write end */

if (fork() == 0) {
    close(pipefd[1]);              /* child: close write end */
    char buf[128];
    read(pipefd[0], buf, sizeof(buf));
} else {
    close(pipefd[0]);              /* parent: close read end */
    write(pipefd[1], "hello", 5);
}
/* PA3 Pattern: semaphore producer-consumer */
#include <semaphore.h>

sem_t empty, full;
pthread_mutex_t mutex;

sem_init(&empty, 0, BUFFER_SIZE);  /* N empty slots */
sem_init(&full,  0, 0);             /* 0 full slots */

void* producer(void* arg) {
    sem_wait(&empty);               /* wait for space */
    pthread_mutex_lock(&mutex);
    /* insert item */
    pthread_mutex_unlock(&mutex);
    sem_post(&full);                /* signal item ready */
}
