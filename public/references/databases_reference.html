Databases History

From punch-card file systems to distributed cloud-native stores

Timeline
1950s
Flat File & Tape Storage
Data stored as sequential records on magnetic tape. No querying — programs read files top to bottom. Updating meant rewriting the entire file.
1960
Hierarchical Model — IMS
IBM's Information Management System, built for NASA's Apollo program. Data stored as parent-child trees. Fast for known access paths, catastrophic for unexpected queries. Still runs some banking systems today.
1969
Network Model — CODASYL
Proposed by Charles Bachman. Records linked via pointers in a graph. More flexible than hierarchical but required developers to navigate relationships manually.
1970
Relational Model Born
Edgar F. Codd at IBM publishes "A Relational Model of Data." Proposes tables with rows and columns. Data accessed by what it is, not where it's stored. Revolutionizes the field.
1974–1979
SQL & First Relational Systems
IBM's System R implements SEQUEL (later SQL). Oracle releases the first commercial SQL RDBMS in 1979. IBM follows with DB2.
1980s–1990s
RDBMS Dominance
Oracle, Sybase, SQL Server, and PostgreSQL mature. ACID transactions become the gold standard. MySQL becomes the go-to for web apps.
2004–2009
NoSQL Movement
Google's Bigtable and Amazon's Dynamo papers spark a revolution. MongoDB, Cassandra, Redis emerge. CAP theorem enters the conversation.
2010s
NewSQL & Polyglot Persistence
Google Spanner and CockroachDB combine SQL's ACID guarantees with NoSQL's horizontal scale. Teams use multiple database types for different workloads.
2020s
Cloud-Native & Serverless
PlanetScale, Supabase, Neon bring serverless relational databases. Vector databases (Pinecone, pgvector) emerge for AI workloads.
