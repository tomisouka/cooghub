Proof Techniques

Direct Proof
-- Prove P → Q
Assume P is true
  ... logical steps ...
Conclude Q is true  ∎
Proof by Contradiction
-- Prove Q
Assume ¬Q
  ... derive contradiction ...
Conclude Q must be true  ∎
Contrapositive
-- Prove P → Q via ¬Q → ¬P
Assume ¬Q is true
  ... logical steps ...
Conclude ¬P is true  ∎
Mathematical Induction
-- Prove P(n) for all n ≥ 1
Base: show P(1) is true
IH:   assume P(k) is true
Step: show P(k) → P(k+1)
∴ P(n) holds for all n ≥ 1  ∎
