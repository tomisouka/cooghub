Core Language
The mechanics behind Python's "everything is an object" model
Data Types
Everything is an object
Immutable: int, float, str, tuple, frozenset, bytes — cannot be changed after creation.
Mutable: list, dict, set, bytearray — can be modified.

Immutability makes something hashable (usable as dict key).
References & Identity
Variables are labels, not boxes
a = [1,2,3]; b = a — both a and b point to the same list. Modifying b modifies a.

is checks identity (same object). == checks equality (same value).
copy() = shallow copy. deepcopy() = full independent copy.
List Comprehensions
Compact, readable transformations
[expr for x in iterable if condition]

More readable and often faster than a for-loop + append. Dict/set comprehensions work the same way.

{ k: v for k, v in d.items() if v > 0 }

Generator expressions: (x**2 for x in range(10)) — lazy, no list built.
Unpacking
Elegant multi-assignment
a, b = 1, 2 — swap: a, b = b, a
first, *rest = [1,2,3,4] — rest = [2,3,4]
**kwargs — dict unpacking in function calls

Star unpacking works anywhere an iterable is expected: [*list1, *list2] merges two lists.

Iteration Tools
Loop smarter
enumerate(it) → (index, value) pairs.
zip(a, b) → paired iteration, stops at shortest.
zip_longest → fills with None.
reversed(seq) → reverse iterator.
sorted(it, key=fn, reverse=True) — stable sort.
any(it) / all(it) — short-circuit boolean tests.
dict patterns
The most-used data structure
d.get(k, default) — no KeyError.
d.setdefault(k, []) — insert if missing.
collections.defaultdict(list) — auto-insert.
collections.Counter(iterable) — frequency map.
d | other — merge dicts (Python 3.9+).
dict(zip(keys, values)) — build from two lists.
String Methods
Strings are immutable sequences
s.split(sep), sep.join(list) — split/join.
s.strip() / lstrip() / rstrip() — whitespace.
s.startswith() / endswith().
f"Hello {name!r}" — f-strings (3.6+). Use !r for repr, !s for str, :.2f for formatting.
OOP in Python
Python's object model — everything you need, nothing you don't
Dunder Methods
Magic methods power the language
__init__ constructor, __repr__ developer string, __str__ user string, __len__ for len(), __getitem__ for indexing, __iter__/__next__ for iteration, __enter__/__exit__ for with, __eq__/__lt__ for comparisons.
Decorators
Functions that wrap functions
A decorator is just a callable that takes a function and returns a function.

@property — getter with dot-access syntax.
@staticmethod — no self, no cls.
@classmethod — receives cls, for alternate constructors.
@functools.cache — memoize (3.9+).
dataclasses
Auto-generate boilerplate
@dataclass auto-generates __init__, __repr__, __eq__. @dataclass(frozen=True) makes it immutable (hashable).

Use field(default_factory=list) for mutable defaults. Combine with __post_init__ for validation. Modern Python's preferred way to write simple classes.
from dataclasses import dataclass, field

@dataclass
class Student:
    name:    str
    grades:  list[int] = field(default_factory=list)

    @property
    def average(self):
        return sum(self.grades) / len(self.grades) if self.grades else 0
Functional Patterns
Generators, closures, and the tools that make Python expressive
Generators
Lazy sequences — yield one at a time
A function with yield returns a generator. Executes until yield, pauses, resumes on next().

Why use them: process infinite sequences, huge files, or expensive computations without loading everything into memory. yield from delegates to a sub-generator.
itertools
Combinatorial and infinite iterators
chain(*iterables) — flatten.
islice(it, n) — take first n from any iterator.
groupby(it, key) — group consecutive runs.
combinations(it, r) / permutations.
product(*its) — cartesian product.
count(start) / cycle(it) — infinite iterators.
Context Managers
with — guaranteed cleanup
with open(f) as file: — file closes even if exception.

Implement with __enter__/__exit__ or @contextmanager from contextlib (use yield instead of __enter__/__exit__).

Use for: file handles, locks, DB connections, timing blocks.
Standard Library Essentials
Batteries included — know what exists before reaching for a package
pathlib
Filesystem paths as objects
Path("dir") / "file.txt" — join paths with /.
p.read_text(), p.write_text(), p.exists(), p.glob("*.py"), p.stem, p.suffix, p.parent. Use pathlib everywhere — forget os.path.
collections
Beyond list/dict/set
Counter — frequency map with most_common().
defaultdict — auto-insert missing keys.
OrderedDict — insertion-ordered (regular dicts too since 3.7).
deque — O(1) append/popleft from both ends. Use deque for BFS, not a list.
typing
Type hints (Python 3.5+)
def f(x: int) -> str: — hints are not enforced at runtime but enable static analysis (mypy, pyright).

Optional[T] = T | None. Union[A,B]. list[int] (3.9+). TypeVar for generics. Protocol for structural typing (duck typing formalized).
History of Python
From a Christmas project to the world's most popular language
1989
Christmas Project
Guido van Rossum starts Python during Christmas holidays while working at CWI in the Netherlands. Wanted a scripting language for the Amoeba OS that was better than shell but more readable than C.
1991
Python 0.9.0 Released
First public release. Already had functions, exception handling, classes, and the core data types. Named after Monty Python's Flying Circus, not the snake. Posted to alt.sources newsgroup.
1994
Python 1.0 — Lambda, map, filter
Functional programming features added. Lambda expressions, map(), filter(), and reduce() arrive — borrowed from Lisp. Guido later regretted some of these additions as un-Pythonic.
2000
Python 2.0 — List comprehensions
Garbage collection via cycle detection, Unicode support, and list comprehensions (borrowed from Haskell). Team moves from CWI to BeOpen.com, then Digital Creations. Python Software Foundation formed.
2008
Python 3.0 — The Great Schism
Python 3 breaks backward compatibility to fix fundamental design mistakes. print() becomes a function, str becomes Unicode by default, integer division fixed. Takes 12 years for the ecosystem to fully migrate. Python 2 EOL: January 1, 2020.
2015–2018
AI/ML Domination
NumPy, Pandas, Scikit-learn, then TensorFlow (2015) and PyTorch (2016) make Python the default language for machine learning. The language's expressiveness and ecosystem make it the ideal glue for numerical computing.
2018
Guido Steps Down
After a contentious PEP debate over the walrus operator (:=), Guido van Rossum steps down as "Benevolent Dictator For Life." Python adopts a steering council governance model. The walrus operator ships in Python 3.8 (2019).
2023–present
#1 Language & Speed Focus
Python tops all major language popularity indexes. Python 3.11 (2022) delivers 60% speedup. Python 3.13 (2024) adds experimental free-threaded mode (removing the GIL). The Faster CPython project, funded by Microsoft, continues improving performance.
