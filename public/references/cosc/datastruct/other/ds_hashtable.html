A hash function takes your key, does math on it, and produces an index. You store the value at that index. Lookup is O(1) — no searching, just compute and jump.

Slot 3 holds a linked list with both alice and dave. Lookup: hash to slot 3, walk the list comparing keys.
Worst case: all keys collide → O(n). Average with good hash function: O(1).
5 — Collision Strategy: Linear Probing
If the target slot is taken, try the next slot, then the next, until you find an empty one. All entries stay in the main array — no linked lists.
Inserting "dave" — hash = 3, but slot 3 is taken. Probe forward:
bob[0]
—[1]
—[2]
alice[3] ✕
—?[4] try
dave[4] ✓
carol[5]
—[6]
Probe sequence: (hash + i) % capacity for i = 0, 1, 2...
Risk: clustering — a run of filled slots forms, making future probes longer.
6 — Collision Strategy: Quadratic Probing
Same idea as linear but probe at increasing distances — 1, 4, 9, 16... This spreads entries out and reduces clustering.
Inserting "dave" — hash = 3, occupied. Probe at +1², +2², +3²:
—[0]
bob[1]
—[2]
alice[3] ✕
—?[4] +1²
—?[7] +2²
dave[4] ✓
Probe sequence: (hash + i²) % capacity for i = 0, 1, 2...
Reduces primary clustering. Still possible to miss empty slots if table is too full — keep load factor below 0.5.
7 — Load Factor
Load factor = n / capacity — the fraction of slots that are filled. Too high and collisions skyrocket. When it crosses a threshold the table resizes.
0.0 — empty0.5 — ideal1.0 — full
0.43
3 entries / 7 slots = 0.43 — healthy. Most implementations resize at 0.7–0.75.

Key Properties
Hash Function
Converts a key into an array index. Good hash functions distribute keys uniformly to minimize collisions.
key → index
Average O(1)
With a good hash function and low load factor, insert, search, and delete are all constant time on average.
O(1) average
Collisions
Unavoidable — more keys than slots exist. Handled by chaining (linked lists) or open addressing (probing).
O(n) worst case
Load Factor
n / capacity. Controls when to resize. High load factor = more collisions. Resize doubles the array and rehashes all entries.
α = n / capacity
