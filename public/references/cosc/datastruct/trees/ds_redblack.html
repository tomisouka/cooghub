1 — The Five Rules
Every node is colored red or black. The colors aren't decoration — they enforce five rules that keep the tree balanced without being as strict as AVL.
1Every node is either red or black.
2The root is always black. After any operation, the root gets recolored black if needed.
3All null pointers (leaf sentinels) are considered black. Every path eventually ends at a black null.
4No two reds in a row. A red node cannot have a red parent or red child — they must be separated by a black node.
5Black height is uniform. Every path from any node down to a null leaf passes through the same number of black nodes.
2 — A Valid Red-Black Tree
Black nodes shown in blue-grey, red nodes in red. Every path from root to null has black height = 2.

3 — Insert — New Nodes Are Always Red
New nodes are always inserted as red. If the parent is black — done. If the parent is red — violation. Fix with recoloring or rotation.
Fix: Uncle is Red → Recolor
Fix: Uncle is Black → Rotate + Recolor
Uncle red → recolor parent + uncle to black, grandparent to red. Propagate up if needed.
Uncle black → rotate (1 or 2 rotations) + recolor. At most 2 rotations total per insert.
