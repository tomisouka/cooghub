2 — Structure and Terminology
A tree of 7 nodes. Each level is a depth. The longest path from root to a leaf is the tree's height.

4 — Types of Binary Trees
Different constraints on shape and fill give different trees — each with different height and performance guarantees.
Full Binary Tree
Every node has either 0 or 2 children. No node has exactly 1 child.
Complete Binary Tree
All levels filled except possibly the last, which fills left to right. Used in heaps.
Perfect Binary Tree
All internal nodes have 2 children and all leaves are at the same level. Exactly 2ʰ⁺¹ − 1 nodes.
Key Properties
At Most 2 Children
Every node has a left child, right child, or both — or neither (leaf). Never more than two.
left + right
Inorder = Sorted
On a BST, inorder traversal visits nodes in ascending sorted order. Left → Root → Right.
L → Root → R
Preorder
Root first, then left subtree, then right subtree. Used to copy or serialize the tree structure.
Root → L → R
Postorder
Both subtrees first, then root. Used to delete a tree safely or evaluate expression trees.
L → R → Root
Height
Balanced tree → O(log n) height. Degenerate (like a linked list) → O(n). Height drives all other operation costs.
