Pumping Lemma — Regular Languages

STATEMENT · PIGEONHOLE · s = xyz · THREE CONDITIONS

regular
Formal Statementif regular → pumpable
If A is a regular language, then there exists a pumping length p ≥ 1 such that every string s ∈ A with |s| ≥ p can be written as s = xyz satisfying all three conditions simultaneously:

(1)  xyⁱz ∈ A  for all i ≥ 0
(2)  |y| ≥ 1                                      (y is non-empty)
(3)  |xy| ≤ p                                   (y falls within first p characters)
What each condition means
COND.PLAIN ENGLISHFORMALHOW YOU USE IT
(1)any pump is still in Axyⁱz ∈ A ∀i≥0i=0 removes y entirely; i=2 duplicates it. Either must stay in A.
(2)y is not empty|y| ≥ 1Guarantees pumping actually changes the string. You get to use this.
(3)y lives in the first p chars|xy| ≤ pForces y into a specific region of s. This is your most powerful constraint.
Why It's True — Pigeonhole on Statesp = number of states · repeated state = y
Let M be a DFA with p states that recognizes A. For any string s ∈ A with |s| ≥ p, reading s visits p+1 or more states — but M has only p states, so by the pigeonhole principle some state qᵣ must be visited at least twice. The portion of the string between the two visits is y. Since the DFA returns to qᵣ after reading y, it can repeat y any number of times (pumping up) or skip it entirely (pumping down, i=0) and still accept.
Pigeonhole visual — state qᵣ repeats, creating a pumpable cycle
Reading s from q₀: after p+1 steps some state must repeat — that loop is y

The Adversarial Game & Proof Template

YOU vs. ADVERSARY · PROOF BY CONTRADICTION · STRUCTURE

method
How to think about the proofyou choose s · adversary chooses split · you find bad pump
Think of the Pumping Lemma as a two-player game. You want to prove A is not regular. Your opponent (the adversary) is trying to defeat you by showing A is pumpable.

Adversary's moves: gives you p (the pumping length), then chooses how to split your s into xyz (as long as |y|≥1 and |xy|≤p).
Your moves: choose s ∈ A with |s|≥p, then for every split the adversary makes, find an i that breaks condition (1).

You win if you can always find a bad pump — meaning A is not regular.
Proof template — step by step
Non-Regularity Proofproof by contradiction via pumping lemma
1Assume A is regular. Let p be the pumping length given by the lemma.
2Choose string s ∈ A with |s| ≥ p. ▷ pick to exploit condition (3)
3Consider ALL ways to write s = xyz with |y| ≥ 1 and |xy| ≤ p.
4Use condition (3) to determine where y must lie in s.
5For each possible y in that region, find i ≥ 0 such that xyⁱz ∉ A.
6This contradicts condition (1). ∴ A is not regular. □
Choosing s — strategy

What makes a good s

  • Must be in A (so the assumption holds)
  • |s| ≥ p (so PL applies)
  • Chosen so that condition (3) forces y into a "bad" region — one where any pump breaks membership
  • Common choice: set length = p exactly, load the front of s with one symbol type

Pump up or pump down?

  • Pump up (i=2): xyyz — adds more of y. Use when extra symbols break the pattern.
  • Pump down (i=0): xz — removes y entirely. Use when balance requires y to be present.
  • Sometimes i=0 and i=2 both work — pick whichever is cleaner to argue.
Critical mistake to avoid: you must show the contradiction holds for every valid split xyz — not just for one particular split you chose. Condition (3) limits where y can be, but within that region the adversary picks the split. Your argument must cover all cases.

Worked Examples — Regular Languages

0ⁿ1ⁿ · ww · 1^(n²) · MULTIPLE WORKED PROOFS

examples
Example 1 — L = {0ⁿ1ⁿ | n ≥ 0}equal counts · classic
Proof
Assume L is regular; let p be its pumping length. Choose s = 0ᵖ1ᵖ ∈ L, |s| = 2p ≥ p. ✓

By condition (3), |xy| ≤ p, so x and y both lie entirely within the first p characters — the block of 0s. Write y = 0ᵏ for some k ≥ 1 (guaranteed by condition 2).

Pump up with i = 2:  xy²z = 0^(p+k) 1ᵖ
This has p+k zeros and p ones — unequal counts — so xy²z ∉ L.

Contradiction with condition (1). ∴ L is not regular. □
y must lie in the 0-block (|xy|≤p) · pumping up creates imbalance
Example 2 — L = {ww | w ∈ {0,1}*}doubled strings · harder split
Proof
Assume L is regular; let p be its pumping length. Choose s = 0ᵖ1 0ᵖ1 ∈ L (w = 0ᵖ1, ww = 0ᵖ10ᵖ1), |s| = 2p+2 ≥ p. ✓

By condition (3), |xy| ≤ p, so y lies entirely within the first p+1 characters — within the first block of 0s. Write y = 0ᵏ, k ≥ 1.

Pump up with i = 2:  xy²z = 0^(p+k) 1 0ᵖ 1
For this to be in L it must equal ww for some w. But the first half has p+k zeros followed by 1, and the second half has exactly p zeros followed by 1. Since k ≥ 1, the halves are unequal length — no valid w exists. So xy²z ∉ L.

Contradiction. ∴ L is not regular. □
Key insight: choose s so that condition (3) forces y into a region where any pump destroys the structure you need. Here, loading the first block of 0s makes y inevitable fall there, and pumping changes the count asymmetrically.
Example 3 — L = {1^(n²) | n ≥ 0}perfect square lengths · pump skips squares
Proof
Assume L is regular; let p be its pumping length. Choose s = 1^(p²) ∈ L (length is a perfect square), |s| = p² ≥ p. ✓

By conditions (2) and (3): y = 1ᵏ where 1 ≤ k ≤ p. So xyⁱz = 1^(p² + (i−1)k).

Consider i = 2: length = p² + k. We need p² + k to be a perfect square. But:
p² < p² + k ≤ p² + p < (p+1)² = p² + 2p + 1
So p² + k lies strictly between consecutive perfect squares p² and (p+1)² — it cannot be a perfect square itself. Thus xy²z ∉ L.

Contradiction. ∴ L is not regular. □

Pumping Lemma — Context-Free Languages

s = uvxyz · PARSE TREE · TALL PATH · REPEATED VARIABLE

CFL
Formal Statementif CFL → 5-way pumpable
If A is a context-free language, then there exists a pumping length p ≥ 1 such that every string s ∈ A with |s| ≥ p can be written as s = uvxyz satisfying all three conditions:

(1)  uvⁱxyⁱz ∈ A  for all i ≥ 0
(2)  |vy| ≥ 1                                           (v and y not both empty)
(3)  |vxy| ≤ p                                         (v, x, y together fit in p chars)
Why it's true — repeated variable on a tall parse tree
Convert the CFG to Chomsky Normal Form (CNF). In CNF, every parse tree for a string of length n has height at least log₂n. If |s| ≥ p (chosen large enough based on the grammar size), some variable R must repeat on the path from root to a leaf. The portion of the string generated by the inner R is x; v and y are generated by the outer R but not the inner R. Repeating or deleting the outer subtree pumps v and y simultaneously.
Repeated variable R on a tall parse tree path — outer subtree can be pumped
CFL Pumping Lemma — Worked ExampleL = {aⁿbⁿcⁿ} · classic non-CFL
Proof that L = {aⁿbⁿcⁿ | n ≥ 0} is not context-free
Assume L is a CFL; let p be its pumping length. Choose s = aᵖbᵖcᵖ ∈ L, |s| = 3p ≥ p. ✓

By condition (3), |vxy| ≤ p, so v, x, y together span at most p consecutive characters. This means vxy cannot contain all three symbols a, b, c — it either sits within one block or straddles two adjacent blocks.

Case 1: v and y contain only a's (or only b's, or only c's).
Pumping up (i=2) increases only that count — the three counts become unequal. xyⁱz ∉ L.

Case 2: v and y each contain one type of symbol, spanning two adjacent blocks (e.g. v = aʲ, y = bᵏ).
Pumping up increases counts of a and b but not c — again unequal. xy²z ∉ L.

Every case leads to an imbalanced string not in L. Contradiction. ∴ L is not context-free. □
|vxy| ≤ p forces vxy to span at most two blocks — c's always left out

  • Some state qᵣ repeats — that loop is y
  • Machine can repeat y any number of times

Pumping Lemma — Context-Free

s = uvxyz · parse tree · repeated variable

Statement & Intuition

tall parse tree forces repeated variable
If A is CFL, ∃ p s.t. every s ∈ A with |s|≥p can be written s=uvxyz with:

(1) uvⁱxyⁱz ∈ A ∀i≥0  ·  (2) |vy|≥1  ·  (3) |vxy|≤p

Intuition: in CNF, tall parse trees must repeat a variable R on some path. The outer R generates uvxyz; the inner R generates x. Repeating (or deleting) the outer subtree pumps v and y simultaneously — always in equal quantity.
Worked example — L = {aⁿbⁿcⁿ} is not CFL
s = aᵖbᵖcᵖ. By condition (3), |vxy|≤p, so vxy spans at most two adjacent blocks. No matter which two blocks v and y touch, pumping changes at most two of the three counts — the third is always left unchanged → counts become unequal → ∉ L. □
The key is that v and y are pumped together (both multiplied by i). But vxy ≤ p means they can't span all three symbol types simultaneously — so one count always gets left behind.

Common Mistakes & Pitfalls

Wrong direction · one split · bad s · non-iff

Things That Will Lose You Points

read carefully

Wrong direction

  • PL cannot prove a language IS regular
  • It's a necessary condition only
  • Some non-regular languages satisfy PL

Only one split

  • Must handle ALL valid splits
  • Adversary picks xyz — you don't
  • Condition (3) limits the region; you cover all cases within it

Bad choice of s

  • If condition (3) doesn't pin y into a harmful region, pick a different s
  • Front-load s with the "dangerous" symbol type

Forgot i=0

  • Pumping down (removing y) is always valid
  • Sometimes xz ∉ A is easier to argue than xyyz ∉ A
  • Try both directions
The pumping lemma is not an if-and-only-if. Satisfying the conditions does not make a language regular. There exist non-regular languages that are "pumpable" by the lemma. PL is only a tool for proving non-regularity via contradiction.
