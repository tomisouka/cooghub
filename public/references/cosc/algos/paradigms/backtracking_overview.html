Algorithm Paradigm

Backtracking

Explore all possible solutions incrementally. Abandon (backtrack) a path the moment a constraint is violated.
Core Idea
  1. Choose: pick a candidate for the current step
  2. Constraint: if it violates rules → abandon, try next
  3. Goal: if solution is complete → record it
  4. Recurse: go deeper with the current choice
  5. Unchoose: undo the choice (backtrack)
Complexity
Worst caseO(n!) or O(2^n)
With pruningMuch better in practice
SpaceO(n) — recursion depth
Find all solutions?✓ Yes
Find one solution?✓ Yes (early exit)
Classic Problems
N-Queens
Place N queens so none attack each other. Check row/col/diag constraints.
O(N!) worst, much less with pruning
Sudoku Solver
Fill 9×9 grid. At each empty cell: try 1-9, check row/col/box, recurse.
O(9^m) where m = empty cells
Permutations
Generate all orderings of n elements. Swap-recurse-swap pattern.
O(n! · n)
Subset Sum
Find subsets that sum to target. Include/exclude each element.
O(2^n)
Knight's Tour
Visit all squares on chessboard exactly once using knight moves.
O(8^(n²)) brute, much less pruned
Combinations
Generate all size-k subsets. Pick or skip each element.
O(C(n,k) · k)
Template Pseudocode
backtrack(state, choices):
  if isGoal(state):
    result.add(copy(state))
    return                        // or return True for first-solution

  for choice in choices:
    if isValid(state, choice):  // PRUNE: skip bad choices
      makeChoice(state, choice) // choose
      backtrack(state, nextChoices)
      undoChoice(state, choice)  // unchoose (backtrack)

// N-Queens constraint check example:
isValid(board, row, col):
  for r in 0..row:
    if board[r] == col: return False          // same column
    if abs(board[r] - col) == row - r: return False  // diagonal
  return True
