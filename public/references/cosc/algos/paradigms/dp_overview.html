Algorithm Paradigm

Dynamic Programming

Break problems into overlapping subproblems, store results to avoid recomputation. Two conditions: overlapping subproblems + optimal substructure.
Two Conditions for DP
① Overlapping subproblems
Same subproblems are solved repeatedly (not independent like D&C)
② Optimal substructure
Optimal solution to the problem contains optimal solutions to subproblems
Memo vs Tabulation
Memoization (Top-Down)
Recursive + cache
Compute on demand
More intuitive
Stack overhead
Tabulation (Bottom-Up)
Iterative + table
Fill all states
No recursion
Often faster

0-1 Knapsack Pseudocode
// weights[], values[], capacity W, n items
knapsack(weights, values, W, n):
  dp ← (n+1) × (W+1) matrix of 0s

  for i in 1..n+1:
    for w in 0..W+1:
      if weights[i-1] > w:
        dp[i][w] ← dp[i-1][w]        // can't take item i
      else:
        dp[i][w] ← max(
          dp[i-1][w],                 // skip item
          values[i-1] + dp[i-1][w - weights[i-1]]  // take item
        )
  return dp[n][W]
