Jump.

Block Search · Sorted Array · Step = √n
best O(1)
average O(√n)
worst O(√n)
space O(1)
1 — The Idea
Jump ahead by √n steps at a time until you overshoot the target. Then linear search backwards in the block you overshot into. Two phases: jump phase (O(√n) jumps) + linear phase (O(√n) steps within the block). Total: O(√n). Sits between linear O(n) and binary O(log n).
2 — Why √n is Optimal
step = √n
Jump phase makes at most n/step = n/√n = √n jumps.
Linear phase backtracks at most step−1 = √n − 1 steps.
Total comparisons: √n + √n − 1 ≈ 2√n = O(√n).
Any other step size makes one of the phases worse. √n balances them perfectly.

Key Properties
Two Phases
Jump by √n until overshoot, then linear scan backward. Simple logic — no recursion, no pointer arithmetic beyond index math.
jump → linear
O(√n) Sweet Spot
Faster than linear O(n), simpler than binary O(log n). Good when binary search is overkill but linear is too slow.
O(√n)
Forward Only
Only jumps forward. Better than binary search when jumping backward (seeking) is expensive — e.g., magnetic tape storage.
forward-only
Sorted Required
Must be sorted. The jump decision (keep going or stop) depends on the array being ordered.
sorted only
