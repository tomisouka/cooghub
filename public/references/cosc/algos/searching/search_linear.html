1 — The Idea
Check every element one by one from left to right until the target is found or the array is exhausted. No requirement for sorted input. No setup cost. The simplest possible search.

Key Properties
No Prerequisites
Works on unsorted arrays, linked lists, any sequential structure. No sorting or preprocessing required.
any input
Early Exit
Stops the moment the target is found. If target is likely near the front, average case is much better than O(n).
stops on find
Worst Case
Target is last element or not present at all — must check every element. O(n) comparisons guaranteed.
O(n) worst
When to Use
Small arrays, unsorted data, one-off searches where sorting cost isn't worth it, or when searching linked lists.
small / unsorted
