Graph Algorithms · MST

Minimum Spanning Tree

Connect all V nodes with exactly V−1 edges, minimizing total weight. Two greedy approaches: Kruskal and Prim.

Add cheapest edge out

O(E log V)

Kruskal Pseudocode
Kruskal(graph):
  edges ← sorted(all edges by weight)
  uf ← UnionFind(all nodes)
  mst ← []

  for (u, v, w) in edges:
    if uf.find(u) ≠ uf.find(v):  // no cycle
      mst.append((u, v, w))
      uf.union(u, v)
    if len(mst) == V − 1: break
  return mst
