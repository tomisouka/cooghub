Bellman-Ford

Shortest path with negative weights. Relaxes all edges V−1 times. Detects negative cycles.
Complexity
TimeO(V · E)
SpaceO(V)
Negative weights?✓ Yes
Negative cycles?✓ Detects them
Slower than Dijkstra?✗ Yes, but more powerful
Key Idea
In any shortest path with V nodes, there are at most V−1 edges.

So: relax every edge exactly V−1 times.

After that, if any edge can still be relaxed, a negative cycle exists.

Pseudocode
BellmanFord(graph, edges, src):
  dist ← {node: ∞ for node in graph}
  dist[src] ← 0

  // Relax all edges V-1 times
  for i in range(V − 1):
    for (u, v, w) in edges:
      if dist[u] + w < dist[v]:
        dist[v] ← dist[u] + w

  // Check for negative cycles (V-th relaxation)
  for (u, v, w) in edges:
    if dist[u] + w < dist[v]:
      return Error("Negative cycle detected")

  return dist
