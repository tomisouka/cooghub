Tree Queries

Height, Lowest Common Ancestor (LCA), and Diameter — essential tree query algorithms.
Complexity Summary
HeightO(n) time, O(h) space
LCA (naive)O(h) per query
LCA (binary lifting)O(log n) per query
DiameterO(n) — two DFS/BFS
Balance checkO(n)
Key Definitions
Height
Longest path from node to a leaf. Height of null = −1, leaf = 0.
LCA
Lowest Common Ancestor of p and q — deepest node that has both p and q as descendants.
Diameter
Longest path between any two nodes (may not pass through root).
Pseudocode — All Three
// Height of a binary tree
height(node):
  if node is null: return -1
  return 1 + max(height(node.left), height(node.right))

// LCA — works on BST or general binary tree (general version)
LCA(node, p, q):
  if node is null: return null
  if node == p or node == q: return node
  left  ← LCA(node.left, p, q)
  right ← LCA(node.right, p, q)
  if left and right: return node   // p on one side, q on other
  return left if left else right

// Diameter — track max across all nodes
diameter ← 0
diameterHelper(node):
  if node is null: return 0
  L ← diameterHelper(node.left)
  R ← diameterHelper(node.right)
  diameter ← max(diameter, L + R)  // path through this node
  return 1 + max(L, R)             // height contribution

// Balance check — O(n)
isBalanced(node):
  if node is null: return True
  L, R = height(node.left), height(node.right)
  return abs(L - R) <= 1 and isBalanced(node.left) and isBalanced(node.right)
LCA in a BST (Simpler)
LCA_BST(root, p, q):
  if p.val < root.val and q.val < root.val:
    return LCA_BST(root.left, p, q)
  if p.val > root.val and q.val > root.val:
    return LCA_BST(root.right, p, q)
  return root  // split point = LCA
BST property lets us decide left/right at each step. O(h) time.
Diameter Example
Tree: 1→2→4, 1→2→5, 1→3
height(4)=0, height(5)=0
At node 2: L=1, R=1 → diam=2
At node 1: L=2, R=1 → diam=3
Diameter = 3 (path: 4→2→1→3 or 5→2→1→3)
