Bubble.

Comparison Sort · In-Place · Stable
best O(n) — already sorted
average O(n²)
worst O(n²)
space O(1)
1 — The Idea
Walk through the array comparing adjacent pairs. If the left is bigger than the right, swap them. After each full pass the largest unsorted element bubbles to its final position at the end. Repeat until no swaps occur.

4 passes on 5 elements. Each pass shrinks the unsorted region by 1. Early exit when a full pass produces zero swaps.
3 — The Shrinking Boundary
After pass i, the last i elements are guaranteed sorted. No need to compare into that region. The inner loop runs n−1, n−2, n−3... comparisons each pass.
Key Properties
Adjacent Swaps Only
Only ever swaps neighbors. This is why it's stable — equal elements never pass each other.
stable ✓
Early Exit
If a full pass produces zero swaps the array is sorted. Best case O(n) on already-sorted input.
O(n) best
Worst Case
Reverse-sorted input. Every comparison is a swap. n−1 + n−2 + ... + 1 = n(n−1)/2 swaps.
O(n²) worst
In Practice
Rarely used. Insertion sort is strictly better — same complexity but far fewer writes on average.
mostly educational
