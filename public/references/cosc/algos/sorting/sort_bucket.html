Bucket.

Distribution Sort · Average O(n) · Floating Point Friendly
best / avg O(n + k)
worst O(n²) — all in one bucket
space O(n + k)
1 — The Idea
Divide the value range into equal-width buckets. Scatter each element into its bucket. Sort each bucket individually (usually insertion sort — buckets are small). Concatenate all buckets. Works best when input is uniformly distributed — each bucket gets ~n/k elements.

With uniform distribution: ~n/k elements per bucket, each bucket sorted in O(n/k)² time. Total: k × O(n/k)² = O(n²/k). With k=n: O(n) average.
Key Properties
Distribution Dependent
Average O(n) assumes uniform distribution. If all elements fall into one bucket, degrades to O(n²) (the inner sort's complexity).
O(n) if uniform
Floating Point Friendly
Naturally suited for floats in [0,1). Counting sort handles integers; bucket sort handles real numbers.
works on floats
Worst Case
Skewed input — all values in the same bucket. The inner sort becomes O(n²). Choose bucket count wisely.
O(n²) skewed
Parallelizable
Each bucket can be sorted independently on separate cores. Naturally parallel — good for distributed sorting.
parallel friendly
