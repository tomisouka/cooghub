GCD & Euclidean Algorithm

2000+ years old. gcd(a,b) = gcd(b, a mod b). Recurse until b = 0. One of the oldest algorithms known.
Algorithm (Gopal Algorithm 8)
gcd(a, b):
  if b == 0:          // base case
    return a
  else:
    return gcd(b, a mod b)  // recursive call
TimeO(log b) recursive calls
SpaceO(log b) call stack
Age~300 BCE — attributed to Euclid
Key Theorem (Gopal Theorem 3.1)
gcd(a, b) = gcd(b, a mod b)
Proof sketch: Write a = b·d + (a mod b).
Any x dividing both a and b also divides a mod b = a − b·d.
Any x dividing b and (a mod b) also divides a = b·d + (a mod b).
So the set of common divisors of (a,b) = set of common divisors of (b, a mod b).
Trace — gcd(8, 5)
gcd(8, 5)→8 mod 5 = 3
gcd(5, 3)→5 mod 3 = 2
gcd(3, 2)→3 mod 2 = 1
gcd(2, 1)→2 mod 1 = 0
gcd(1, 0)→return 1
gcd(8, 5) = 1
Runtime Analysis (Theorem 3.2)
Number of recursive calls ≤ 1 + 2⌈log₂(b)⌉ = O(log b)

Why? After two calls, the second argument drops by at least half:
gcd(a,b) → gcd(b, a mod b) → gcd(a mod b, b mod (a mod b))

The argument b/2ᵗ ≤ 1 after t = log₂(b) steps.
Two Key Features of Recursive Functions
1. Termination Condition
Every recursive function must have a base case where it stops calling itself. Without it: infinite recursion. In gcd: when b = 0.
2. Smaller Subproblem
Each recursive call must be on a strictly smaller input. In gcd: b decreases each call. Guarantees termination.
