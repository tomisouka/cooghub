Mathematical Induction for Algorithms

The single most useful proof technique in algorithm analysis. Used to prove correctness AND analyze performance.
The Three Steps
1. Base Case
Prove the statement is true for the smallest input (usually n=1 or n=0). This is trivially true in most algorithms.
2. Induction Hypothesis
Assume the statement is true for all inputs of size < n (or for some specific k). This is your "free" assumption.
3. Induction Step
Using the hypothesis, prove the statement is true for size n (or k+1). This is where the real work happens.
Strong vs Weak Induction
Weak (simple)Assume true for k, prove for k+1
StrongAssume true for ALL j <= k, prove for k+1
When to use strongDivide & Conquer — subproblems not n-1
D&C algorithms call themselves on n/2 (not n-1), so strong induction is needed — the hypothesis must cover ALL smaller sizes.
Celebrity Problem — Correctness by Induction (Gopal Theorem 2.1)
Strategy: Ask "Does A know B?" If yes, eliminate A (can't be celebrity). If no, eliminate B. After n-1 questions, one person remains — check if they are the celebrity. 
Base case (n=1): Trivially correct — one person is the celebrity.
Induction hypothesis: Strategy correctly finds celebrity for n-1 people.
Induction step (n people):
  Ask A about B:
    - If A knows B: A cannot be celebrity. By hypothesis, strategy finds
      celebrity in remaining n-1 people. Celebrity must be among them.
    - If A does not know B: B cannot be celebrity (a celebrity is known
      by all). By hypothesis, strategy finds celebrity in remaining n-1.
Tiling Problem — Recurrence
T(n) = number of L-tiles to cover 2ⁿ×2ⁿ board.

Recurrence: T(n) = 4T(n-1) + 1
Base case: T(1) = 1

Solution by induction: T(n) = (4ⁿ - 1) / 3
Induction + Recursion Connection
Recursion is the algorithmic counterpart to mathematical induction:

• Base case = recursion termination
• Induction step = recursive call on smaller input
• Hypothesis = trust the recursive call returns correct result

If you can prove correctness by induction, the recursive algorithm is correct.
Standard Induction Proofs in Algorithms
Sum Formula
1+2+...+n = n(n+1)/2
Base: n=1. Step: assume for k, prove k+1.
Loop Invariant
A property that holds before & after each loop iteration. Proved by induction on iteration count.
Recurrence
Guess-and-verify: guess T(n)=O(f(n)), then prove using induction on the recurrence.
