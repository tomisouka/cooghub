Maximum Subarray (Maxsum)

Find contiguous subarray with maximum sum. Gopal uses this to teach the DP design process step-by-step.
Complexity
Brute forceO(n³) — all pairs, sum each
Smarter bruteO(n²) — prefix sums
DP (Kadane's)O(n) time, O(1) space
Subproblems2n (Min[i] and Mout[i])
Gopal's DP Decomposition
Let M[i] = max sum in A[1..i]

Decompose into two cases:
Min[i] = max sum ending AT index i (includes A[i])
Mout[i] = max sum in A[1..i] NOT ending at i

Then: M[i] = max(Min[i], Mout[i])
Recurrence
Mout[i] = M[i-1]                        // skip A[i]
Min[i]  = max(Min[i-1] + A[i], A[i])    // extend or start fresh
M[i]    = max(Min[i], Mout[i])
Base: Min[1] = A[1], Mout[1] = -∞, M[1] = A[1]
Algorithm MaxsumDP (Gopal Algorithm 24) — Kadane's Algorithm
MaxsumDP(A):
  M[1] = A[1]
  Min[1] = A[1]
  Mout[1] = -∞
  for i = 2 to n:
    Mout[i] = M[i-1]                        // exclude A[i]
    Min[i]  = max(Min[i-1] + A[i], A[i])   // include A[i]
    M[i]    = max(Min[i], Mout[i])
  return M[n]
Space-optimized: only keep previous M and Min values → O(1) space.

Why This Teaches DP
Gopal uses maxsum to demonstrate all 7 DP steps:
1. Identify subproblems
2. Focus on solution value
3. Introduce auxiliary variables
4. Recursive formulation
5. Correctness proof (induction)
6. Runtime analysis
7. Convert to iterative algorithm
