A* Algorithm

A heuristic variant of Dijkstra optimized for single-pair shortest path. Uses an admissible heuristic to guide search toward the target.
Complexity
Worst caseO((V+E) log V) — same as Dijkstra
In practiceMuch faster — explores fewer nodes
Optimal?✓ Yes, if heuristic is admissible
Problem typeSingle-pair (source s → target t)
Key Idea
Dijkstra expands nodes in order of d[v] (distance from source).

A* expands nodes in order of:
d[v] + h[v]

where h[v] is a heuristic estimate of distance from v to target t.

This guides search toward t, skipping irrelevant nodes.
Admissibility — Required Property
h[v] ≤ true_dist(v, t) for all v
h must be a lower bound on true distance. Never overestimate.

Example: Euclidean (straight-line) distance is always ≤ road network distance → admissible for maps.

Algorithm (Modification of Dijkstra)
AStar(G, s, t, h):
  d[v] = ∞ for all v; d[s] = 0
  pq ← MinPQ keyed by d[v] + h[v]
  pq.push((h[s], s))           // key = d[s]+h[s] = h[s]

  while pq not empty:
    (_, u) ← pq.pop_min()
    if u == t: return d[t]     // found shortest path to t

    for (v, w) in Adj[u]:
      if d[u] + w < d[v]:
        d[v] = d[u] + w
        pq.push((d[v] + h[v], v)) // key includes heuristic

  return ∞  // t unreachable
