Gopal Appendix B · Section B.4

Union-Find (Disjoint Sets)

Maintains a collection of disjoint sets. Supports Make-Set, Find, and Union efficiently. Core to Kruskal's MST algorithm.
Operations
Make-Set(x)Create new singleton set {x}
Find(x)Return representative of x's set
Union(x, y)Merge sets containing x and y
Time (basic)O(log n) per op — union-by-rank
Time (optimized)O(α(n)) — with path compression
Implementation
Each set stored as a directed rooted tree.
Each node points to its parent. Root points to itself.
Root = set representative.

Union-by-rank: smaller tree's root points to larger tree's root.

Path compression: on Find, make every node on path point directly to root.
Algorithms (Gopal Algorithms 57–59)
MakeSet(x):
  parent[x] = x; rank[x] = 0

Find(x):
  if x != parent[x]:
    parent[x] = Find(parent[x])  // path compression
  return parent[x]

Union(x, y):
  rx = Find(x); ry = Find(y)
  if rx == ry: return           // same set already
  if rank[rx] > rank[ry]:        // union-by-rank
    parent[ry] = rx
  else:
    parent[rx] = ry
    if rank[rx] == rank[ry]:
      rank[ry]++
Height Bound (Gopal Theorem B.2)
Lemma B.1: For any tree rooted at x: size(x) ≥ 2^rank[x]

Since total nodes = n and each tree starts with 1 node, doubling can happen at most log n times.

Height = rank ≤ log n.

Find = O(log n) with union-by-rank alone.
Use in Kruskal's MST
1. MakeSet for each vertex
2. Sort all edges by weight
3. For each edge (u,v):
   if Find(u) ≠ Find(v): add to MST, Union(u,v)

Union-Find ensures we never create a cycle — exactly what Kruskal's needs.
