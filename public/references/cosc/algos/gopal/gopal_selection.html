Selection — Median of Medians

Find the k-th smallest element in O(n) time using a carefully chosen pivot. Median of Medians guarantees a balanced split.
Complexity
TimeO(n) — linear!
vs SortingSorting: O(n log n). Selection is easier.
ComparisonsO(n) — no sorting needed
RecurrenceT(n) ≤ T(n/5) + T(7n/10) + αn
SpaceO(log n) stack
Algorithm Select — Steps
1. Divide into groups of 5
Split n elements into ⌈n/5⌉ groups of at most 5 elements each.
2. Find median of each group
Sort each group (O(1) per group since size ≤ 5) → ⌈n/5⌉ medians.
3. Recursively find "median of medians"
Call Select recursively on the ⌈n/5⌉ medians to find their median p.
4. Partition around p, recurse
Partition S into S₁ < p and S₂ > p. Recurse on the correct side.
Why Groups of 5? The Pivot Guarantee
Choosing p = median of medians guarantees:
• At least 3n/10 - 6 elements are smaller than p
• At least 3n/10 - 6 elements are larger than p
So the recursive call is on at most 7n/10 + 6 elements — a constant fraction.

Recurrence: T(n) ≤ T(⌈n/5⌉) + T(7n/10 + 6) + O(n)
This solves to T(n) = O(n) because 1/5 + 7/10 = 9/10 < 1.
Pseudocode (Gopal Algorithm 19)
Select(S, k):   // find k-th smallest in S
  if |S| ≤ 5:
    return sort(S)[k-1]   // base case

  groups ← partition S into groups of 5
  medians ← [median(g) for g in groups]
  p ← Select(medians, ⌈|medians|/2⌉)  // median of medians

  S1 ← {x ∈ S | x < p}
  S2 ← {x ∈ S | x > p}

  if k == |S1| + 1: return p
  elif k ≤ |S1|:    return Select(S1, k)
  else:             return Select(S2, k - |S1| - 1)
