Gopal Ch. 5 · Section 5.4

Matrix Chain Multiplication

Find the optimal parenthesization of A₁A₂...Aₙ to minimize scalar multiplications. Order matters — result is the same, cost differs.
Complexity
Naive (all parenthesizations)O(2ⁿ) — exponential
DP solutionO(n³) time, O(n²) space
SubproblemsO(n²) — all (i,j) pairs
Each subproblemO(n) — try all splits k
Key Example
A₁(10×1000), A₂(1000×100), A₃(100×200):

(A₁A₂)A₃: 10·1000·100 + 10·100·200 = 1,200,000
A₁(A₂A₃): 1000·100·200 + 10·1000·200 = 22,000,000

Same result, 18× cost difference!
Recurrence — m(i,j) = min cost to multiply Aᵢ...Aⱼ
m(i, j) = 0                                          if i == j
m(i, j) = min over i ≤ k < j of:
           m(i,k) + m(k+1,j) + p[i-1]·p[k]·p[j]    if i < j

where Aᵢ has dimensions p[i-1] × p[i]
The split k determines which two subchains to multiply last. Try all k, take minimum.
DP Algorithm (Bottom-Up)
MatrixChain(p, n):       // p[0..n] = dimensions
  m[i][i] = 0 for all i

  for len = 2 to n:        // chain length
    for i = 1 to n-len+1:
      j = i + len - 1
      m[i][j] = ∞
      for k = i to j-1:   // try all splits
        cost = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]
        if cost < m[i][j]:
          m[i][j] = cost
          s[i][j] = k       // track split for reconstruction
  return m[1][n]
