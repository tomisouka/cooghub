Basics & Structure

Every C program starts with main(). Source files end in .c; headers in .h. C is a compiled, procedural language — close to the metal, no runtime overhead.

/* Hello World — the C classic */ #include <stdio.h> int main(void) { printf("Hello, World!\n"); return 0; /* 0 = success */ }

Control Flow

Conditionals

/* if / else if / else */ if (x > 0) { /* positive */ } else if (x < 0) { /* negative */ } else { /* zero */ } /* switch — jump table on integer or char */ switch (day) { case 1: printf("Mon"); break; case 2: printf("Tue"); break; default: printf("Other"); break; /* omitting break causes fall-through — often a bug! */ } /* ternary operator */ int abs_x = (x < 0) ? -x : x;

Loops

/* for loop — classic counter */ for (int i = 0; i < 10; i++) { /* runs 10 times */ } /* iterate over array */ int arr[5] = {1, 2, 3, 4, 5}; for (int i = 0; i < 5; i++) { printf("%d ", arr[i]); } /* while — check before each iteration */ while (x > 0) { x--; } /* do-while — runs body at least once */ do { /* body executes, then condition checked */ } while (condition);

Jump Statements

KeywordPlain EnglishUse
breakexit the loop nowExits nearest enclosing loop or switch immediately
continueskip to next iterationJumps to loop's condition/update without finishing the body
returnleave this functionreturn value; exits function; return; for void functions
gotojump to a labelCan jump within a function; avoid — but useful for cleanup in C (no exceptions)
/* goto for error cleanup — one of its few accepted uses in C */ int process(void) { FILE *f = fopen("data.txt", "r"); if (!f) goto err_f; char *buf = malloc(1024); if (!buf) goto err_buf; /* ... do work ... */ free(buf); fclose(f); return 0; err_buf: fclose(f); err_f: return -1; }

Functions

Functions must be declared before use. Use a prototype in a header file or at the top of the source file. C does not support overloading — each function name must be unique.

/* Prototype (declaration) — tells compiler about the function */ int add(int a, int b); /* Definition — the actual code */ int add(int a, int b) { return a + b; } /* Pass by value — caller's variable is NOT changed */ void byValue(int x) { x = 99; } /* Pass by pointer — caller's variable IS changed */ void byPointer(int *x) { *x = 99; } /* call: byPointer(&myVar); */ /* Returning multiple values via pointers */ void minmax(int *arr, int n, int *out_min, int *out_max) { *out_min = *out_max = arr[0]; for (int i = 1; i < n; i++) { if (arr[i] < *out_min) *out_min = arr[i]; if (arr[i] > *out_max) *out_max = arr[i]; } } /* Variadic function (any number of args) */ #include <stdarg.h> double average(int count, ...) { va_list ap; va_start(ap, count); double sum = 0; for (int i = 0; i < count; i++) sum += va_arg(ap, double); va_end(ap); return sum / count; } /* Function pointer */ int (*fp)(int, int) = add; /* fp points to add */ int result = fp(3, 4); /* call through pointer */

Pointers & Arrays

Pointers are one of C's most powerful — and dangerous — features. A pointer holds a memory address. Arrays and pointers are deeply related: an array name decays to a pointer to its first element.

int x = 42; int *p = &x; /* p points to x */ *p = 99; /* x is now 99 */ /* Pointer arithmetic */ int arr[5] = {10, 20, 30, 40, 50}; int *q = arr; /* q points to arr[0] */ q++; /* now points to arr[1] */ printf("%d\n", *q); /* prints 20 */ /* Array indexing == pointer arithmetic */ arr[2] == *(arr + 2) /* exactly equivalent */ /* NULL pointer — points to nothing */ int *ptr = NULL; if (ptr != NULL) { /* always check before dereferencing */ } /* Pointer to pointer */ int **pp = &p; **pp = 7; /* changes x to 7 */ /* const pointer varieties */ const int *cp = &x; /* can't change value through cp */ int * const pc = &x; /* can't change what pc points to */ const int * const cpc = &x; /* can't change either */ /* void pointer — generic pointer, no type */ void *vp = &x; int *ip = (int *)vp; /* must cast to use */

Pointer Concepts

ConceptPlain EnglishNotes
Dereferencefollow the address*p gives the value at the address p holds
Address-ofget the address&x gives the address where x lives in memory
Pointer arithmeticmove through memoryp + n advances by n * sizeof(*p) bytes
Array decayarray becomes pointerint arr[10] → int * when passed to a function; size info is lost
NULL pointerpoints to nothingDereferencing NULL is undefined behavior (usually a crash)
Dangling pointerpoints to freed memoryUsing after free is UB — set to NULL after freeing
void *untyped pointerUsed by malloc/memcpy; must cast before arithmetic

Arrays

/* Stack arrays — fixed size at compile time */ int arr[10]; /* 10 ints; indices 0..9 */ int mat[3][4]; /* 3 rows, 4 columns */ char str[] = "hello"; /* size inferred: 6 (includes \0) */ /* Variable-length arrays (VLA) — C99, optional in C11 */ int n = 10; int vla[n]; /* size determined at runtime; lives on stack */ /* Passing arrays to functions — always pass size separately! */ void print_arr(int *arr, int n) { for (int i = 0; i < n; i++) printf("%d ", arr[i]); } /* arr[n] decays to int*, sizeof(arr) inside function is wrong! */

Structs, Unions & Enums

Structs group related data under one name — C's primary way to build custom data types. Unions share memory between members. Enums name integer constants.

/* Struct definition */ struct Point { double x; double y; }; /* typedef to avoid writing 'struct' every time */ typedef struct { char name[64]; int age; float score; } Person; Person p = {"Alice", 30, 95.5f}; /* designated or positional init */ Person q = {.name = "Bob", .age = 25, .score = 88.0f}; /* C99 designated */ printf("%s is %d years old\n", p.name, p.age); /* Pointer to struct — use -> */ Person *ptr = &p; printf("%s\n", ptr->name); /* Nested struct */ typedef struct { struct Point origin; struct Point corner; } Rect; /* Self-referential struct (linked list node) */ typedef struct Node { int value; struct Node *next; /* must use 'struct Node' here, not just Node */ } Node;

Union

/* All members share the same memory address */ union Data { int i; float f; char bytes[4]; }; union Data d; d.f = 3.14f; /* d.i and d.bytes now contain raw bits of 3.14f — only d.f is valid! */ printf("%zu bytes\n", sizeof(union Data)); /* 4 — max of members */

Enum

/* Enum — named integer constants */ enum Direction { NORTH, SOUTH, EAST, WEST }; /* 0, 1, 2, 3 */ enum Color { RED = 1, GREEN = 2, BLUE = 4 }; /* custom values */ enum Direction dir = NORTH; if (dir == NORTH) printf("Heading north!\n");

Bit Fields

/* Pack multiple small values into a struct */ typedef struct { unsigned int is_active : 1; /* 1 bit */ unsigned int priority : 3; /* 3 bits (0-7) */ unsigned int flags : 4; /* 4 bits */ } Control; Control c = {1, 5, 0b1010}; printf("active=%d priority=%d\n", c.is_active, c.priority);

Memory Management

C gives you complete manual control over memory. You allocate with malloc and release with free. Every allocation must be freed exactly once. No garbage collector, no safety net.

Memory Regions

RegionPlain EnglishLifetime
Stackfast local storageAutomatic; freed when scope exits. Typically 1–8 MB limit
Heapbig dynamic storageManual: malloc / free. You must free what you allocate
Static / Globallives whole programInitialized to zero at startup; freed at exit
Code (Text)your compiled instructionsRead-only; lives for the whole program

Heap Allocation Functions (<stdlib.h>)

FunctionPlain EnglishNotes
malloc(size)allocate n bytesReturns void * or NULL on failure; memory is uninitialized
calloc(n, size)allocate n items, zero themZero-initializes; safer for arrays
realloc(ptr, size)resize an allocationMay move pointer; old pointer invalid after call
free(ptr)release the memoryMust free exactly once; free(NULL) is safe
/* Allocate a single int on heap */ int *p = malloc(sizeof(int)); if (p == NULL) { /* ALWAYS check for NULL! */ exit(1); } *p = 42; free(p); p = NULL; /* good habit: null the pointer after free */ /* Dynamic array */ int n = 100; int *arr = malloc(n * sizeof(int)); if (!arr) exit(1); for (int i = 0; i < n; i++) arr[i] = i; /* Grow the array */ arr = realloc(arr, 200 * sizeof(int)); /* Note: realloc can return NULL — use temp pointer! */ free(arr); /* Zero-initialized array */ int *zeroed = calloc(n, sizeof(int)); /* all zeros */ free(zeroed); /* 2D dynamic array (array of pointers) */ int rows = 4, cols = 5; int **mat = malloc(rows * sizeof(int *)); for (int i = 0; i < rows; i++) mat[i] = malloc(cols * sizeof(int)); /* ... use mat[i][j] ... */ for (int i = 0; i < rows; i++) free(mat[i]); free(mat);

Strings

C strings are null-terminated arrays of char. There is no built-in string type. The null terminator '\0' marks the end — always account for it when sizing buffers.

/* String literals live in read-only memory */ char *s1 = "hello"; /* pointer to literal — do not modify! */ char s2[] = "hello"; /* copy on stack — modifiable, size = 6 */ char s3[10] = "hello"; /* buffer of 10, first 6 chars set */ printf("Length: %zu\n", strlen(s2)); /* 5, not 6 — excludes \0 */ /* Character access */ s2[0] = 'H'; /* s2 is now "Hello" */ /* String as pointer */ char *p = s2; while (*p != '\0') { printf("%c", *p); p++; }

Tips & Gotchas

  • = vs ==The classic bug: if (x = 0) assigns 0 and is always false. Use if (x == 0). Enable warnings to catch this.
  • integer overflowSigned integer overflow is undefined behavior. Use unsigned types or check bounds before arithmetic. INT_MAX + 1 is not defined.
  • sizeof arraysizeof(arr) gives total bytes in the array — but only in the scope where the array is declared. Once passed to a function, it decays to a pointer and sizeof gives pointer size, not array size.
  • strcmp not ==Never compare strings with == — that compares pointer addresses. Use strcmp(a, b) == 0 to compare content.
  • null terminatorC strings end with '\0'. Always allocate strlen(s) + 1 bytes. strncpy may not add it — always terminate manually.
  • check mallocAlways check the return value of malloc. On failure it returns NULL; dereferencing it is undefined behavior (usually a crash).
  • free onceEvery malloc must be paired with exactly one free. Double-free is UB. Set pointer to NULL after freeing to prevent accidental reuse.
  • switch fallthroughForgetting break in a switch case causes fall-through to the next case — almost always a bug. Always write break or explicitly comment /* fall through */.
  • use -WallAlways compile with -Wall -Wextra -pedantic. C will happily compile dangerous code without warnings unless you ask for them.
  • snprintf not sprintfsprintf does not check buffer size — it will overflow. Always use snprintf(buf, sizeof(buf), ...) instead.
  • UBUndefined Behavior (signed overflow, null deref, out-of-bounds, use-after-free) lets the compiler do anything. Use ASan (-fsanitize=address) and UBSan (-fsanitize=undefined) to catch it.
  • const correctnessUse const for pointer parameters that shouldn't be modified: void print(const char *s). It documents intent and helps the compiler.
  • realloc safetyNever do p = realloc(p, size) — if it returns NULL, you've lost the original pointer and leaked memory. Use a temp: void *tmp = realloc(p, size); if (tmp) p = tmp;
  • int vs size_tUse size_t (not int) for array indices and sizes. Mixing signed and unsigned can cause subtle comparison bugs.
