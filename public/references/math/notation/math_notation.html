Set Builder Notation

{x | P(x)}    or    {x : P(x)}

Read: "The set of all x such that P(x) is true"

  • {x | x ∈ ℕ ∧ x < 5} = {0,1,2,3,4}
  • {x² | x ∈ {1,2,3}} = {1,4,9}
  • {n | n ≡ 0 (mod 2)} = the even numbers

Reading Complex Expressions

∀ε > 0, ∃N ∈ ℕ, ∀n > N: |aₙ − L| < ε
"For all epsilon greater than zero, there exists N in the natural numbers such that for all n greater than N, the absolute value of a_n minus L is less than epsilon"
L = {w ∈ Σ* | |w|ₐ = |w|_b}
"L is the set of all strings w in Sigma star such that the number of a's equals the number of b's"
A ≤ₚ B ⟹ (B ∈ P ⟹ A ∈ P)
"If A is polynomial-time reducible to B, then if B is in P, then A is in P"

Pro Tips

Ambiguous Symbols — Context Matters!

  • |x|could mean: absolute value, cardinality, length, determinant
  • f'could mean: derivative or complement
  • *could mean: Kleene star, convolution, or multiplication
  • ()could mean: grouping, ordered pair, or open interval
  • { }could mean: a set literal, set-builder notation, or code block grouping
  • [ ]could mean: closed interval, matrix row, array index, or equivalence class
