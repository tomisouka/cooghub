Topic 1 Matrices, Systems & Gaussian Elimination

Key Concepts

Matrix
Rectangular array of numbers. An m×n matrix has m rows and n columns. Entry in row i col j written aᵢⱼ.
System of equations
A set of linear equations; written compactly as A𝐱 = 𝐛 where A is the coefficient matrix, 𝐱 is the vector of unknowns, 𝐛 is the right-hand side.
Augmented matrix
[A | 𝐛] — write the coefficient matrix with 𝐛 appended as a column. Row operations on this represent operations on the system.
Gaussian Elimination
Use row operations to bring [A|𝐛] to Row Echelon Form (REF), then back-substitute to solve. Three legal row ops: swap Rᵢ ↔ Rⱼ, scale cRᵢ, replace Rᵢ + cRⱼ.
REF
Row Echelon Form — leading entry (pivot) of each nonzero row is to the right of the one above; all-zero rows at bottom.
RREF
Reduced Row Echelon Form — each pivot is 1, and it's the only nonzero entry in its column. Unique for any matrix.
Pivot / leading variable
Variable corresponding to a pivot column. Free variables correspond to non-pivot columns; they parameterize the solution set.
Consistency
System A𝐱 = 𝐛 is consistent (has ≥1 solution) iff 𝐛 is in the column space of A. Inconsistent iff RREF has row [0 … 0 | c] with c ≠ 0.
💡

Reading A𝐱 = 𝐛: "Matrix A times vector x equals vector b." The solution is unique when A is square and invertible; it has infinitely many when there are free variables; it has none when the system is inconsistent.

Topic 2 Vector Spaces, Independence, Span & Bases

Key Concepts

Vector space ℝⁿ
Set of all n-tuples of real numbers. Closed under addition and scalar multiplication. Standard example: ℝ³ = all (x, y, z).
Linear combination
c₁𝐯₁ + c₂𝐯₂ + ⋯ + cₖ𝐯ₖ — a weighted sum of vectors using scalar coefficients c₁…cₖ.
Span
span{𝐯₁,…,𝐯ₖ} = all linear combinations of those vectors. It's the smallest subspace containing them. Read: "the span of v1 through vk."
Linear independence
Vectors 𝐯₁,…,𝐯ₖ are independent iff c₁𝐯₁ + ⋯ + cₖ𝐯ₖ = 𝟎 ⟹ all cᵢ = 0. Otherwise dependent.
Basis
A set of vectors that is (1) linearly independent AND (2) spans the space. Every vector in the space has a unique representation as a linear combination of basis vectors.
Dimension dim(V)
Number of vectors in any basis for V. All bases for the same space have the same size. dim(ℝⁿ) = n.
Standard basis for ℝⁿ
The vectors e₁ = (1,0,…,0), e₂ = (0,1,…,0), …, eₙ = (0,…,0,1).
⚠️

Independence test via matrix: Form a matrix with the vectors as columns. They are independent iff RREF has no free variables (every column is a pivot column). Equivalently, the only solution to A𝐜 = 𝟎 is 𝐜 = 𝟎.

Topic 3 Abstract Vector Spaces & Linear Maps

Key Concepts

Abstract vector space
Any set V with addition and scalar multiplication satisfying the 8 axioms (associativity, commutativity, identity, inverse, distributivity, etc.). Examples: polynomials, matrices, function spaces.
Linear transformation T
A map T: V → W satisfying T(𝐮+𝐯) = T(𝐮)+T(𝐯) and T(c𝐯) = cT(𝐯). Every matrix multiplication is a linear transformation; every LT has a matrix representation.
Kernel ker(T)
ker(T) = {𝐯 ∈ V | T(𝐯) = 𝟎} — all inputs mapped to zero. Also called null space. Read: "kernel of T."
Image im(T)
im(T) = {T(𝐯) | 𝐯 ∈ V} — all possible outputs. Also called range or column space. Read: "image of T."
Rank-Nullity Theorem
dim(ker T) + dim(im T) = dim(V) i.e. nullity(A) + rank(A) = n (number of columns). Crucial for understanding solution structure.
Isomorphism
A linear transformation that is bijective (1-1 and onto). Two spaces are isomorphic iff they have the same dimension. Essentially "the same" space up to labeling.
ℹ

Rank-Nullity in words: "The dimension of what gets killed plus the dimension of what can be hit equals the dimension of the whole domain." If rank = n, the map is injective (1-1). If rank = m (num rows), it's surjective (onto).

Topic 4 The Determinant

Key Concepts

det(A) or |A|
A scalar computed from a square matrix. Read "determinant of A." For 2×2: det([[a,b],[c,d]]) = ad − bc.
Cofactor expansion
Expand along any row or column: det(A) = Σⱼ aᵢⱼ · Cᵢⱼ where Cᵢⱼ = (−1)^(i+j) · Mᵢⱼ is the cofactor, Mᵢⱼ is the (i,j) minor (det of submatrix with row i and col j removed).
Row reduction & det
Swapping rows negates det. Scaling row by c multiplies det by c. Adding a multiple of one row to another leaves det unchanged. Upper triangular: det = product of diagonal.
Invertibility criterion
A is invertible iff det(A) ≠ 0. If det(A) = 0, A is singular (not invertible).
det(AB)
det(AB) = det(A) · det(B). Also det(Aᵀ) = det(A) and det(A⁻¹) = 1/det(A).
Geometric meaning
|det(A)| = volume of the parallelepiped formed by the column (or row) vectors. Sign indicates orientation.

Topic 5 Eigenvalues & Eigenvectors

Key Concepts

Eigenvalue equation
A𝐯 = λ𝐯 (𝐯 ≠ 𝟎) — A times v equals lambda times v. λ is the eigenvalue, 𝐯 is the eigenvector. A only stretches/flips 𝐯, never rotates it.
Characteristic polynomial
p(λ) = det(A − λI). Eigenvalues are the roots. Read: "det of (A minus lambda I)." Set to zero and solve for λ.
Eigenspace Eλ
Eλ = ker(A − λI) — all eigenvectors for eigenvalue λ, plus 𝟎. Find it by row-reducing A − λI and solving the homogeneous system.
Algebraic multiplicity
How many times λ appears as a root of the characteristic polynomial.
Geometric multiplicity
dim(Eλ) — dimension of the eigenspace. Always ≤ algebraic multiplicity.
💡

Algorithm: (1) Compute det(A − λI) = 0 to find eigenvalues. (2) For each λ, solve (A − λI)𝐱 = 𝟎 to find the eigenspace. The free variables give the basis vectors for Eλ.

⚠️

tr(A) = Σλᵢ (sum of eigenvalues) and det(A) = Πλᵢ (product of eigenvalues). Great for checking arithmetic.

Topic 6 Diagonalization & Analytic Functions of Matrices

Key Concepts

Diagonalization
A is diagonalizable if A = PDP⁻¹ where D is diagonal (with eigenvalues on diagonal) and P's columns are the corresponding eigenvectors.
When diagonalizable?
A (n×n) is diagonalizable iff it has n linearly independent eigenvectors — equivalently, geometric multiplicity = algebraic multiplicity for every eigenvalue. n distinct eigenvalues ⟹ always diagonalizable.
Change of basis
Matrix P changes basis: [T]_B = P⁻¹[T]_ₛP. Similar matrices B = P⁻¹AP represent the same transformation in different bases.
Matrix powers
If A = PDP⁻¹, then Aᵏ = PDᵏP⁻¹ and Dᵏ is trivial (just raise diagonal entries to k). Makes computing Aᵏ easy.
Matrix exponential
eᴬ = PeᴰP⁻¹ where eᴰ = diag(eˡ¹, eˡ², …). Defined via power series: eᴬ = I + A + A²/2! + ⋯. Used in ODEs.
Analytic functions f(A)
For diagonalizable A: f(A) = Pf(D)P⁻¹ where f(D) = diag(f(λ₁),…,f(λₙ)). Applies to sin, cos, √, log, etc.

Topic 7 The 2×2 Jordan Form

Key Concepts

Defective matrix
A matrix that is NOT diagonalizable — geometric multiplicity < algebraic multiplicity for some eigenvalue. There aren't enough independent eigenvectors.
Jordan block J(λ,n)
An n×n matrix with λ on diagonal, 1s on the superdiagonal, zeros elsewhere. Example 2×2: [[λ,1],[0,λ]].
Jordan canonical form
Every matrix is similar to a block diagonal matrix of Jordan blocks. For 2×2 defective: J = [[λ,1],[0,λ]]; then A = PJP⁻¹.
Generalized eigenvectors
When eigenvectors aren't enough, find 𝐯₂ such that (A − λI)𝐯₂ = 𝐯₁ (where 𝐯₁ is an eigenvector). These fill the columns of P alongside eigenvectors.
ℹ

2×2 case: If A has repeated eigenvalue λ but only one independent eigenvector, then A ~ [[λ,1],[0,λ]]. Find P = [𝐯₁ | 𝐯₂] by solving (A−λI)𝐯₁ = 𝟎 for eigenvector, then (A−λI)𝐯₂ = 𝐯₁ for the generalized one.

Topic 8 Gram-Schmidt, Orthogonal Matrices & Schur's Lemma

Key Concepts

Inner product ⟨𝐮,𝐯⟩
Generalization of dot product. For ℝⁿ: ⟨𝐮,𝐯⟩ = 𝐮·𝐯 = uᵀv. Read: "inner product of u and v" or "u dot v."
Orthogonality
𝐮 ⊥ 𝐯 iff ⟨𝐮,𝐯⟩ = 0. An orthogonal set has every pair of distinct vectors orthogonal. Orthonormal if also each ‖𝐯ᵢ‖ = 1.
Gram-Schmidt process
Given linearly independent vectors {𝐯₁,…,𝐯ₖ}, produce an orthonormal basis {𝐪₁,…,𝐪ₖ} for the same span. Project out previous directions at each step.
Projection formula
proj_𝐮 𝐯 = (𝐯·𝐮 / 𝐮·𝐮) 𝐮. Read: "projection of v onto u." Gram-Schmidt subtracts this to orthogonalize.
Orthogonal matrix Q
Square matrix whose columns are orthonormal. Key property: QᵀQ = I, so Q⁻¹ = Qᵀ. Preserves lengths and angles. Read: "Q inverse equals Q transpose."
QR decomposition
Any matrix with independent columns factors as A = QR where Q has orthonormal columns, R is upper triangular. Gram-Schmidt gives the Q.
Schur decomposition
Every square matrix A (over ℂ) satisfies A = QUQ* where Q is unitary and U is upper triangular with eigenvalues on its diagonal. Over ℝ, real Schur form applies.
Symmetric matrices
If A = Aᵀ, then A has real eigenvalues and an orthonormal basis of eigenvectors. So symmetric ⟹ orthogonally diagonalizable: A = QDQᵀ.
💡

Gram-Schmidt in 3 steps: (1) 𝐪₁ = 𝐯₁/‖𝐯₁‖. (2) Subtract projection: 𝐰₂ = 𝐯₂ − (𝐯₂·𝐪₁)𝐪₁, then 𝐪₂ = 𝐰₂/‖𝐰₂‖. (3) Repeat: subtract all previous projections, normalize. Result: orthonormal set spanning the same space.
