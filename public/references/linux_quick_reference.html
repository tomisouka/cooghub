Permissions & Ownership

Linux uses a User / Group / Other permission model. Each file has read (r), write (w), and execute (x) bits for each of the three classes.

-rwxr-xr-- 1 alice staff 4096 Jan 10 script.sh
Owner (alice) can rwx · Group (staff) can rx · Others can only r

chmod — Change Mode

CommandEffect
chmod 755 <file>rwxr-xr-x — owner full, others read+exec
chmod 644 <file>rw-r--r-- — owner read+write, others read only
chmod 600 <file>rw------- — private file (keys, secrets)
chmod +x <file>Add execute bit for all
chmod -R 755 <dir>Apply recursively to directory
chmod u+x,g-w <file>Symbolic: user add exec, group remove write

chown / chgrp

CommandEffect
chown alice <file>Change owner to alice
chown alice:staff <file>Change owner and group
chown -R alice: <dir>Recursively change owner (keep group)
chgrp staff <file>Change group only

Special Bits

BitOctalEffect
setuid4000Run as file owner (e.g., sudo, passwd)
setgid2000Run as file group; on dirs: new files inherit group
sticky bit1000Only owner can delete files in dir (e.g., /tmp)

Input, Arguments & Menus

#!/usr/bin/env bash # Reading user input read -rp "Enter your name: " name echo "Hello, $name" # Secret input (passwords) read -rsp "Password: " pass echo # newline after hidden input # Script arguments echo "Script: $0" echo "First arg: $1" echo "All args: $@" echo "Arg count: $#" # Shift through arguments while [[ $# -gt 0 ]]; do case "$1" in -v|--verbose) VERBOSE=1 ;; -o|--output) OUTPUT="$2"; shift ;; --) shift; break ;; -*) die "Unknown option: $1" ;; *) POSITIONAL+=("$1") ;; esac shift done # Simple select menu PS3="Pick an option: " select opt in "Start" "Stop" "Status" "Quit"; do case $opt in Start) echo "Starting..."; break ;; Stop) echo "Stopping..."; break ;; Status) echo "Checking..."; break ;; Quit) exit 0 ;; *) echo "Invalid choice" ;; esac done

String Manipulation

str="Hello, World!" echo "${str,,}" # hello, world! (lowercase) echo "${str^^}" # HELLO, WORLD! (uppercase) echo "${str/World/Linux}" # Hello, Linux! echo "${str:0:5}" # Hello (substring: start, length) echo "${str: -6}" # orld! (last 6 chars) echo "${#str}" # 13 (length) path="/var/log/nginx/access.log" echo "${path##*/}" # access.log (basename) echo "${path%/*}" # /var/log/nginx (dirname) echo "${path%.log}.gz" # /var/log/nginx/access.gz

Logging & Output

Redirection & Pipes

Every process has three standard streams: stdin (0), stdout (1), and stderr (2). Redirection wires these to files or other commands.

SyntaxEffect
cmd > fileRedirect stdout to file (overwrite)
cmd >> fileRedirect stdout to file (append)
cmd < fileUse file as stdin for cmd
cmd 2> err.logRedirect stderr to file
cmd 2>&1Merge stderr into stdout
cmd > out.log 2>&1Redirect both stdout and stderr to file
cmd >/dev/nullDiscard stdout
cmd1 | cmd2Pipe stdout of cmd1 to stdin of cmd2
cmd1 |& cmd2Pipe both stdout and stderr (bash)
tee fileWrite to file AND pass through to stdout

total used free shared buff/cache available Mem: 15Gi 4.2Gi 1.1Gi 512Mi 9.8Gi 10.8Gi Swap: 2.0Gi 0B 2.0Gi # "available" = what apps can actually use (free + reclaimable cache) # "buff/cache" = disk cache — Linux uses spare RAM here intentionally # "free" being small is NORMAL — don't panic

journalctl --vacuum-time=7dDelete logs older than 7 days

Unit File Template

[Unit] Description=My Application After=network.target [Service] Type=simple User=myapp WorkingDirectory=/opt/myapp ExecStart=/opt/myapp/bin/server Restart=always RestartSec=5 [Install] WantedBy=multi-user.target

Place in /etc/systemd/system/myapp.service, then run systemctl daemon-reload && systemctl enable --now myapp.

Pro Tips

  • set -euo pipefailPut this at the top of every bash script. -e exits on error, -u treats unset vars as errors, -o pipefail catches errors in piped commands.
  • sudo !!Repeat the last command with sudo. Saves retyping when you forgot to elevate.
  • Ctrl+RReverse-search your shell history. Start typing to narrow results, press Ctrl+R again to cycle through matches.
  • 2>&1 | teeCapture both stdout and stderr to a file while still seeing output: command 2>&1 | tee output.log
  • && vs ;cmd1 && cmd2 runs cmd2 only if cmd1 succeeds. cmd1 ; cmd2 always runs both. Use && for dependency chains.
  • aliasPut frequently-used long commands in ~/.bashrc: alias ll='ls -lah'. Run source ~/.bashrc to reload.
  • xargsConvert lines of stdin to arguments: find . -name "*.bak" | xargs rm. Use -P 4 to parallelize with 4 workers.
  • screen / tmuxTerminal multiplexers let you detach sessions that keep running after logout. Essential for long-running remote tasks.
  • chmod 600 keysSSH keys must be owner-read-only. SSH will refuse to use keys that are too permissive.
  • dmesg | tailSee recent kernel messages — useful for diagnosing hardware issues, driver errors, or OOM kills.
  • /dev/nullThe void. Redirect anything here to silence it. command > /dev/null 2>&1 suppresses all output.
  • strace / ltraceTrace system calls (strace) or library calls (ltrace) for a running process. Invaluable for debugging mystery failures.
